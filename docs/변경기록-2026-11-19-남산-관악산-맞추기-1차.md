## 4. 산 고유라 남산에 넣지 않는 것 (추천안, 대표 미확인)

공통 기능은 「판단 필요」였던 것(즐길거리·스테미너·앉기·라디오 등)까지 모두 넣는 것을 기본으로 함. 아래만 관악산 장소에 묶인 것이라 뺌.

| 관악산 기능 | 빼는 이유 | 남산에서는 |
|---|---|---|
| 약수 마시기 | 관악산 약수터 자리 하나에 묶인 상호작용 | 없음 |
| 계곡 손 담그기 | 관악산 계곡 물줄기 자리(`STREAM_SPOTS`)에 묶임 | 없음(남산 코스에 계곡 없음) |
| 돌탑 돌 올리기 | 관악산 돌탑 공터 자리에 묶임 | 없음 |
| 정상석 앞 F로 정상 인증 | 연주대 정상석 방식 | 정상 광장에 들어서면 완등(지금 남산 방식 유지) |
| 관악산 체크포인트·스탬프 자리·출발 지점 이름(일주문·깔딱고개 등) | 관악산 장소 이름 | 기능(스탬프 수첩·출발 지점 고르기·구간 이동)은 넣고 자리는 남산 것(스탬프 4곳 등) |
| 관악산 안내판 글·쌍안경 랜드마크 관측점(연주대 기준) | 관악산 위치 기준 자료 | 기능은 넣고 글·관측점은 남산 정상 기준으로 새로(자료 필요) |
