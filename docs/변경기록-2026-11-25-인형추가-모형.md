# 변경기록 2026-11-25 — 인형 추가 14종 모형 (월드아트)

월드기획 지시: 대표가 고른 후보 14개(작은 8·큰 3·상자 3)를 게임용 모형으로. 연결(도감·뽑기·저장·기계)은 월드공통개발 몫, 커밋 안 함.

## 바꾼 것
- 새 그림 `src/claw/claw-plush-more.js`(작은 8 + 상자 안 전용 모양 3), `claw-plush.js`가 불러 씀. 무게 지금 인형 수준(평균 약 3,300 삼각형, 최대 4,240).
- 목록 `claw-palette.js` `PLUSH_ADD`·`BIG_PLUSH_ADD`·`BOX_PLUSH_ADD`·`BOX_SHAPES`(지금 목록과 따로), `plushInfo`·`isBigPlush`·`isBoxPlush`·`baseOfPlush`가 새 목록도 찾음. `claw-plush.js` `PLUSH_ADD_IDS`, `OUR_PLUSH_IDS`에 새 작은·큰 인형.
- 외곽선 껍질 어긋남 고침(`claw-plush.js` `flatten`): 바닥이 뜬 형상에서 껍질이 위로 밀리던 결함 = 반짝별 테두리선이 옅던 원인. 지금 인형 8종은 어긋남 0이라 그대로.
- 상자: 손에 드는 상자 `CARRY_ART.hand.box` 0.10×0.22×0.16 → 0.15×0.24×0.19m(대표 지적), `makeBoxPrize` 안 인형을 창·깊이 안에 맞춰 줄이고 세운 상자는 받침 위. 지금 8종 + 새 3종 모두 상자 밖으로 0mm(손 상자·봉 상자). 봉 기계 상자 크기(판정)는 그대로. 새 상자 색 3개(황금 해치는 짙은 단청 빨강).
- 들기: 넓은 인형은 `CARRY_ART.hand.wide`(0.25m) 넘는 폭만큼 손을 바깥으로(반짝별).
- 큰 산타 동동이 빛 = 실제 `CARRY_ART.glow` 특별(금빛 + 반짝이), 따로 칠하지 않음.
