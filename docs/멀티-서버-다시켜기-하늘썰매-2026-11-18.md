# 공개 멀티 서버 다시 켜기 — 하늘 썰매 (대표용)

작성: 월드개발 · 2026-11-18

## 왜 다시 켜야 하나
하늘 썰매는 서버가 두 가지를 새로 알아야 다른 사람에게 보입니다.
- 「하늘 썰매를 타는 중」이라는 표시(`hs`)
- 하늘에 떠 있는 높이(위치 메시지 `a`)
- 그리고 하늘에 있는 사람은 눈덩이에 맞지 않게 하는 판정

정원·비용은 바뀌지 않습니다.

**다시 켜기 전(옛 서버)에는:** 썰매를 탄 사람은 자기 화면에서는 잘 날지만, 다른 사람 화면에서는 썰매 없이 땅 위를 빠르게 미끄러지는 동동이로 보입니다. 오류는 나지 않습니다.

## 순서
1. 월드개발이 GitHub에 올린 뒤(대표님이 "푸시" 지시) 진행합니다.
2. 절차는 11-17 문서와 같습니다: `docs/멀티-서버-다시켜기-대표용-2026-11-17.md`
   - 다른 곳 맥에서 `cd ~/gwanak-hiking && git pull` 뒤 서버를 껐다 켭니다(자동 켜기면 `launchctl kickstart -k …`, 터미널 창이면 Ctrl+C 뒤 `npm run multi:up`).
3. 이 맥(사무실 맥)에서는 켜지 않습니다.

## 잘 적용됐는지 확인 (두 사람, 같은 광장 서버)
- 한 사람이 루돌프 썰매 정류장(지도 핀 「하늘 썰매」)에서 타고 날아오릅니다.
- 다른 사람 화면에 **루돌프 2마리가 끄는 썰매가 하늘 높이 보이고**, 지나간 자리에 별이 떨어지면 됩니다.
- 옛 서버면 썰매가 안 보이고 동동이가 땅에서 미끄러집니다 → 다시 켜기가 안 된 것입니다.
