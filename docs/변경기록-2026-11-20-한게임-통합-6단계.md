# 변경기록 2026-11-20 — 관악산·남산 한 게임 통합 6단계 (월드개발)

월드기획 지시(11-20): 6단계 = 관악산·남산이 같은 게임 본체를 쓰게 합치기. 남산 기능 스위치 `NAMSAN_FEATURES`를 본체가 읽고, 남산 페이지도 같은 화면 조각을 쓴다. 관악산 동작·화면은 그대로(기준 점검 28개로 대조), 남산 5단계 결과(자물쇠 3개 한도·버스 규칙 등)는 유지.
같은 날 지시 변경: 5단계 후속 사소 3건(약수 때 몸이 약수터 가림·휴대폰 세로 벤치 등·「3인칭」 칩 크기)은 프론트엔드 팀 정리드가 맡음 → 이번 단계에서 하지 않음(잠깐 넣었던 코드는 되돌림).

## 1. 무엇을 합쳤나

| 부분 | 전(5단계) | 후(6단계) |
|---|---|---|
| 남산 페이지 몸통 | 남산 전용 HTML(로딩 화면만) + game.js가 단추·탭을 직접 만듦 | 관악산과 같은 화면 조각 `src/frame/hiking-body.html`을 끼워 넣음(`<!--#include-->`). 두 페이지 몸통이 글자까지 같음(시험으로 확인) |
| 산마다 다른 글 | 남산 HTML에 직접 | `src/mountains/namsan-page.js` `NAMSAN_TEXT` → `src/mountains/page-text.js`가 로딩 화면 전에 바꿈(제목·로딩 문구·지도·출발 단추·정상 도장·쉬기 안내·출처) |
| 기능 스위치 | `NAMSAN_FEATURES` 표시만 | 화면 조각의 `data-feature` 자리를 `applyMountainFeatures`(src/mountain-text.js)가 숨김. 관악산은 모두 켜져 숨는 자리 0. 남산은 휴대폰 카메라·땅에 앉기·스테미너·스트레칭·수첩 탭·완등 기록 카드 숨김. 새 키 `book`·`summitCard`·`ambient`를 두 산에 더함 |
| HUD | 남산 전용 큰 단추·할 일 카드·알림·정상 카드·지도/설정 탭 | 관악산과 같은 수첩 HUD(`hud-notebook`·`hiking-frame`·`hud-toggle`·`gadget-ui`·`interaction-ui`). 남산 할 일 줄은 `hiking:interact-view`로 보내 같은 빨간 도장·상황 꼬리표가 그림. 도장 규칙에 남산 줄(정상석·자물쇠·벤치·순환버스·바로 가기·건너뛰기) 추가 |
| 공통 본체 부품 | 관악산 main.js 안에만 | `src/hiking-body.js`로 옮겨 두 산이 같이 씀: 소리(발소리·켜기/끄기·음량·라디오 ×0.7), WebGL 끊김 복구, 함께 걷기 HUD 3종 불러오기. main.js 쪽은 글자 그대로 옮김 |
| 산별 옵션 | — | `installHikingFrame({goal,barMode,features})`(알약 「정상까지」·막대 = 진행), `installNotebookHud(doc,win,{ticks})`(진행 눈금 = 남산 스탬프 4곳). 기본값 = 관악산 그대로 |

남산이 새로 얻은 것(관악산과 같은 것): 발소리(돌길·돌계단, 관악산과 같은 파일)·효과음(약수·스탬프 등 `interaction-sound`), 소리 켜기/끄기, 화질 고르기(같은 저장 키), 화면 숨기기(H), 도움말·마우스 잠금, 헤드랜턴 단추·L, 서울 이름표, 의견 보내기·후원, WebGL 끊김 복구, 개발용 구간 이동(설정 탭 「개발용」), 지도 탭(관악산과 같은 지도 칸·출발 위치 단추 「백범광장에서 시작」·「정상 앞에서 시작」), 정상 도착은 공통 정상 창(남산 도장 글).
남산 설정 탭에 「다른 산 고르기」는 남김(11-19 남산 판에 있던 것).

## 2. 바꾸지 않은 것
- 남산 세계·걷기(`namsan-walk.js`·`namsan-walker.js`)·자물쇠(최대 3개)·버스(2대·10m/s·정류장 12초·버스로 온 정상은 기록 안 함)·야경 벤치·저장 키(`namsan-hike:v1`·`namsan-interaction:v1`)·함께 걷기 방(`hiking:남산`)·서버 코드.
- 관악산: 걷기·상호작용·즐길거리·라디오 등 main.js 동작. 바뀐 줄은 소리·끊김 복구·함께 걷기 HUD를 부품 호출로 바꾼 것과 기능 스위치 한 줄뿐.
- 남산 환경음은 끔(`ambient:false`): 관악산 환경음 표는 관악산 구간(계곡 물 등) 기준이라 남산에 맞지 않음.

## 5. 남은 것·알게 된 것
- 공통 진행 알약 글(「정상까지 1.1 km · 고도 106 m」)이 휴대폰 세로에서 시점 칩에 거의 닿음. 관악산 걷는 중 글(「연주대까지 …」)도 길이가 같아 같은 모양(추정). 관악산 화면을 바꾸지 않는 원칙이라 이번엔 안 고침 → 프론트엔드 쪽 후속 제안(월드기획 확인 11-20).
- 7단계: `game.js`를 더 줄이기(지금은 남산 세계·버스·자물쇠·벤치 + 공통 HUD에 잇는 코드), 휴대폰 메모리 측정, 두 산 함께 걷기 섞임 시험.
