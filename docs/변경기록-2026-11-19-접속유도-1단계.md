## 2. 정한 것 (개발 결정·대표 미확인)

- 친구 부르기 주소에는 서버 목록에 있는 방만 넣습니다(1서버는 서버가 끝 번호를 뗀 이름 `옥상`으로 알려 줘도 `옥상-1`로). 이름·`?server=`·위치·지금 주소의 다른 옵션은 넣지 않습니다.
- 지금 서버는 각 체험이 이미 보내는 `hiking:`·`lounge:`·`xmas:multi-status` 이벤트로 압니다(체험 코드 안 고침). 서버에 붙어 있을 때(online·reconnecting)만 방을 넣고, 내 컴퓨터 모드·연결 중은 체험 주소만.
- 보낼 글은 초안입니다: 「나 지금 온라인 크리스마스 눈마을 2서버! 설치 없이 바로 들어와」, 혼자면 「온라인 크리스마스 같이 하자! 설치 없이 바로 들어와」. 월드디자인·월드기획 확인 필요.
- 친구 부르기 단추 모양: 초록 테두리 알약, 높이 48px(빨강은 큰 단추 몫이라 안 씀).
- 결과 창(썰매·눈싸움) 옆 작은 「친구 부르기」는 이번에 넣지 않았습니다(설계의 +0.5일 선택 몫). 메뉴 한 줄로 세 체험 모두 됩니다.
- 흡연장은 처음 들어오면 상황 고르기로 메뉴가 저절로 열리는 기존 동작 때문에, 친구 부르기 줄도 그때 같이 보입니다(상황 칸이 48px만큼 좁아짐).
