## 1. 눈썰매 직접 조작(조작감 3) — `src/christmas/sled.js`

- 기록: 화면이 보내는 조작감 `SLED_FEEL_VERSION` 3, 서버 기록판 `BOARD_FEEL` 3(`sled-race.js`). 예전 2 기록은 기록판에 안 섞임. **이 기기의 개인 최고 기록·고스트(`xmas-sled:v2`)는 지우지 않음.**
- 시뮬레이션(30코스, `tests/christmas-sled.test.mjs`): 보통 실력 30/30 완주·평균 61.9초·눈둑 10.7번 / 손 놓음 78.4초(+27%)·눈둑 40.5번(3.8배) / 잘 탐 51.4초. 헤어핀 2초 전 손을 떼면 8개 헤어핀 모두 바깥 눈둑에 닿음.

## 4. 눈싸움 직접 겨냥 — `snowfight.js`·`snowfight-play.js`·`main.js`·`hud.js`
- 없앤 것: 휴대폰 톡·PC F 톡 자동 조준(`autoAim`), 고리 0.5m 안 사람 쪽 0.4m 끌어당김(`assistPoint`), 맞은 눈덩이 몸 쪽 휘어짐(`homing`). 맞음 판정(서버, 지나가는 순간)은 그대로.
- 조준점 = 화면 가운데 방향 + 겨냥 거리(처음 9m, 4~14m, 마당 나갈 때까지 기억). 마당 안에서는 늘 연한 고리(흰색 40%, 사람에 닿으면 빨강 + 과녁 = 정보만).
- 마당 안: 걸어도 카메라가 몸 방향으로 저절로 돌지 않음, 몸은 늘 조준(카메라) 방향, 이동은 앞뒤·옆걸음, 조준 중 걷기 50%→85%.
- 휴대폰 ❄️: 톡 = 지금 고리로 바로, 누른 채 끌기 = 좌우 시야·조준 회전(1px 0.35°, 90px 넘게 대고 있으면 계속 돎 최대 120°/s) + 위아래 거리(위로 1px +0.08m), 떼면 던짐, 누른 곳 왼쪽 위 120px의 ✕(56px) 위에서 떼면 취소.
- PC: 마우스 왼쪽 누름 = 마우스 자리 고리·포물선(보정 없음), F 톡 = 가운데 고리로 바로, F 누르는 동안 = 게이지로 거리(0.2초부터 게이지 보임), 휠 = 가운데 고리 거리 ±1m.
