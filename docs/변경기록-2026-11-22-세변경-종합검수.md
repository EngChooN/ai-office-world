# 세 가지 변경 종합 검수 — 월드검수

판정: **일부 통과**. 관악산 가을 원경, 자물쇠 저장, 타워 출입의 주요 기능은 확인했습니다. 전망대 화면 문제 1건과 기존 검사 실패 3건이 남았습니다. 커밋·배포·운영 서버 재시작은 하지 않았습니다. 이번 검수에서 게임 코드를 바꾸지는 않았습니다.

## 확인 방법과 한계

- 직접 조작 도구는 브라우저 연결과 네이티브 연결이 모두 실패했습니다. 따라서 요청하신 **손으로 직접 플레이는 수행하지 못했습니다**. 실제 게임을 여는 Playwright 자동 조작 검사와 캡처를 눈으로 확인한 결과입니다.
- 자물쇠·타워: PC 1400×860, 휴대폰 세로 390×844, 별도 시험 서버와 서로 다른 두 브라우저 환경. 운영 데이터는 사용하지 않았습니다.
- 관악산: 정상 같은 자리에서 PC 1400×860와 휴대폰 390×844 사계절을 새로 촬영했습니다. 모두 페이지 재열기 1회, 그림 처리 오류 0건입니다.
- 남산 숲: 여름 낮 330m 지점 PC 1920×1080와 휴대폰 390×844를 추가 촬영했습니다. 숲 추가 촬영의 PC 폭은 1400이 아닙니다. 기존 전후 비교 자료도 함께 눈으로 확인했습니다.
- 실제 아이폰·안드로이드, 실제 휴대폰 키보드, 외부 공개 서버는 확인 못 했습니다. 세 변경 전 상태를 이번에 다시 실행한 것은 아니며, 앞 단계가 남긴 전후 사진을 사용했습니다.

## 남은 문제·실패

1. **전망대 시점, 화면으로 확인**: 휴대폰에서 창가에서 안쪽을 보면 시점이 유리 밖으로 나가, 바닥 끝과 지상 숲이 한 화면에 크게 보입니다. 앞 단계가 알린 한계가 이번 캡처에서도 보입니다. 기존 방식은 가까운 카메라가 머리에 붙는 문제를 피하려고 밖으로 내보낸 것으로 코드에 설명되어 있습니다. 유리 안쪽 제한과 캐릭터 근접 처리를 함께 검증해야 하므로 이번 검수에서 임의로 수치만 바꾸지 않았습니다.
2. **버스 검사 실패**: 오르는 길 급커브에서 버스 방향과 시점의 표본 간 최대 변화가 각각 6.66°로, 기준 3°를 넘었습니다. 정상 도착·페이지 오류 0은 통과. 표본 시간 간격에 따른 화면 지연 영향과 실제 시점 튐을 구분하지 못했으며 새 변경이 원인이라고 단정할 수 없습니다.
3. **휴대폰 다람쥐**: 정해진 대기 뒤 모자 상태가 아니라 `wander`였습니다. 이번 자동 검사에서는 미통과. 원인은 확인 못 했습니다.
4. **동물 놀람 전달**: 같은 출현 목록은 통과했지만 A의 놀람 이벤트 자체가 60초 안에 발생하지 않아 `startle:null`, B의 받은 목록도 빈 값이었습니다. 전송 자체가 고장났다고 단정할 수 없고, 놀람 유도 단계부터 다시 확인해야 합니다.

직접 조작 연결 불가 때문에 위 문제들을 손으로 재현하며 안전한 수정까지 검증하지 못했습니다. 이 상태를 전체 통과로 보고하지 않습니다.

## 실행 중 중단 기록

처음 제한된 환경에서는 시험 서버 열기가 차단되어 실행되지 않았습니다. 별도 허용 실행 뒤 전체 단위 시험은 통과했습니다. 남산 콘텐츠 첫 실행은 진단 기능을 못 찾았다는 오류로 중단됐고 뒤 검사들도 시작 대기 시간 초과가 났습니다. 새 브라우저 진단에서는 시작과 해당 기능이 정상이었으며, 중단된 검사만 다시 실행한 결과가 위 표입니다. 첫 중단의 원인은 확인 못 했습니다. 처음 실행 로그도 삭제하지 않았습니다.
