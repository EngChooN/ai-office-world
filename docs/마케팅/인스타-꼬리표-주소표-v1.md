# 인스타용 꼬리표 주소 표 v1 (2026-11-19, 월드개발)

접속 유도 1단계(대표 승인)의 「유입 구분」 몫입니다. 그대로 복사해서 쓰면 됩니다.

- 꼬리표(`utm_…`)는 사이트가 무시합니다. 붙여도 화면·입장 흐름이 바뀌지 않습니다(점검함, 아래 §4).
- 지금은 **인스타 앱 통계(링크 누른 수)**로만 봅니다. 우리 사이트에는 방문 기록 장치가 없습니다(대표 결정 11-19: 나중에 우리 서버가 숫자만 세는 방식으로 넘어감, 2단계).
- **프로필 링크 목적지는 대표 결정 대기 중**입니다. 이 문서는 바꾸지 않았고, 후보마다 쓸 주소만 적었습니다.

기본 주소: `https://engchoon.github.io/ai-office-world/`

## 2. 릴스별 스토리 링크 스티커 (그 장면 앞에서 바로 시작)

릴스 본문 링크는 눌리지 않으므로, 릴스별 구분은 스토리 링크 스티커로 합니다. `utm_campaign`에 릴스 번호를 넣습니다.

| 릴스 | 들어가면 | 주소 |
|---|---|---|
| R1 퇴근하고 관악산 정상 찍고 옴 | 정상 10m 앞(기존 `?start=summit`) | `https://engchoon.github.io/ai-office-world/hiking/?start=summit&utm_source=instagram&utm_medium=story&utm_campaign=R1` |
| R2 썰매 꼴찌가 붕어빵 쏘기 | 썰매 출발대 앞 | `https://engchoon.github.io/ai-office-world/christmas/?spot=sled&utm_source=instagram&utm_medium=story&utm_campaign=R2` |
| R3 이거 피하면 인정 | 눈싸움 마당 안 | `https://engchoon.github.io/ai-office-world/christmas/?spot=fight&utm_source=instagram&utm_medium=story&utm_campaign=R3` |
| R4 루돌프 썰매 내가 운전함 | 루돌프 썰매 정류장 | `https://engchoon.github.io/ai-office-world/christmas/?spot=sky&utm_source=instagram&utm_medium=story&utm_campaign=R4` |
| R5 금연 3주차 옥상 가서 한 대 | 옥상(바로가기 없음, 19세 확인 그대로) | `https://engchoon.github.io/ai-office-world/smoking/?utm_source=instagram&utm_medium=story&utm_campaign=R5` |

크리스마스 장면 바로가기 값 전체: `sled`(썰매 출발대) · `fight`(눈싸움 마당) · `rink`(스케이트장) · `tree`(트리) · `sky`(하늘 썰매) · `fire`(모닥불) · `mailbox`(우체통) · `snowman`(눈사람 마당) · `carousel`(회전목마) · `gondola`(케이블카) · `entrance`(입구). 모르는 값이면 평소처럼 입구에서 시작합니다.

## 3. DM·댓글 답, 친구 부르기

| 쓰는 곳 | 주소 |
|---|---|
| DM·댓글 답 | `https://engchoon.github.io/ai-office-world/<체험>/?utm_source=instagram&utm_medium=dm` (`<체험>` = `hiking`·`smoking`·`christmas`) |
| 게임 안 「친구 부르기」(자동) | `…/<체험>/?multi=<지금 서버 방>&utm_source=invite&utm_medium=share` — 혼자 하는 중이면 `?multi=` 없이 체험 주소만. 사람이 손으로 만들 일 없음 |

## 4. 확인한 것 / 못 한 것

- 확인함(내 맥, 휴대폰 크기 화면): `?spot=sled·fight·rink·tree·sky`로 들어가 그 시설 앞에 섬, 다른 사람 화면에도 같은 자리. 꼬리표가 붙은 「친구 부르기」 주소로 들어온 사람이 같은 서버에 들어감. 점검 `scripts/verify-growth-stage1.mjs`.
- 확인 못 함: 인스타 앱 안 브라우저에서 이 주소들을 열었을 때, 실제 아이폰. 등산 `?start=summit`은 기존 기능이라 이번에 다시 보지 않았습니다.
- 반영은 배포 뒤부터입니다(배포는 대표 확인 뒤).
