# 인스타 릴스 자동 올리기 — 대표가 처음 한 번 할 설정 (2026-11-28, 월드공통개발)

이 문서는 대표가 **처음 한 번** 하실 일입니다. 약 20~30분 걸립니다.
끝나면 이 맥에서 명령 한 줄로 릴스를 올릴 수 있습니다. 실행 방법은 `인스타-릴스-자동올리기-실행방법.md`에 있습니다.

> 화면 이름은 2026-11-28 공식 문서를 기준으로 적었습니다. 제가 직접 눌러 보지는 못했습니다(계정 로그인은 대표가 하기로 함). 메타가 메뉴 이름을 자주 바꾸니, 비슷한 이름을 찾아 주세요. 막히면 화면을 캡처해 주시면 됩니다.

## 0. 먼저 확인할 것
- 올릴 인스타 계정이 **프로페셔널 계정**(비즈니스 또는 크리에이터)이어야 합니다.
  - 인스타 앱 → 프로필 → ☰ → 「계정 유형 및 도구」 → 「프로페셔널 계정으로 전환」. 이미 프로페셔널이면 그대로 두세요.
- 페이스북 페이지 연결은 **필요 없습니다**(인스타그램 로그인 방식이라서).

## 1. 메타 개발자 계정 만들기
1. 컴퓨터에서 https://developers.facebook.com 에 들어가 페이스북 계정으로 로그인합니다.
2. 처음이면 「시작하기」를 눌러 개발자로 등록합니다(전화번호·이메일 확인).

## 2. 앱 만들기
1. 오른쪽 위 「내 앱」 → 「앱 만들기」.
2. 쓰임새(사용 사례)에서 **「Instagram에서 메시지 및 콘텐츠 관리」**(영문 *Manage messaging & content on Instagram*)를 고릅니다.
3. 앱 이름은 아무거나 괜찮습니다(예: `ai-office-reels`). 「앱 만들기」를 누릅니다.

## 3. 권한 3개 켜기
앱 화면 왼쪽 메뉴 「Instagram」 → **「Instagram 로그인을 통한 API 설정」**(영문 *API setup with Instagram login*)으로 갑니다. 아래 권한 세 개가 있는지 봅니다. 없으면 「권한 추가」로 넣습니다.
- `instagram_business_basic` — 계정 정보 보기
- `instagram_business_content_publish` — 릴스 올리기
- `instagram_business_manage_comments` — 첫 댓글 달기

## 4. 우리 인스타 계정 연결하고 토큰 받기
1. 같은 화면의 **「액세스 토큰 생성」** 칸에서 「계정 추가」를 누릅니다.
2. 인스타 로그인 창이 뜨면 올릴 계정으로 로그인하고, 권한을 **모두 허용**합니다.
3. 계정 옆 **「토큰 생성」**을 누르면 긴 글자(토큰)가 나옵니다. **복사**해 둡니다. 이 토큰은 60일 동안 씁니다.
   - 토큰은 비밀번호와 같습니다. 카톡·메일·문서에 붙여 넣지 마세요. 아래 5단계에서 바로 넣으면 됩니다.

> **안 될 때(앱이 「개발 모드」라서):** 「앱 역할」 → 「역할」 → 「Instagram 테스터 추가」에 우리 인스타 계정 이름을 넣습니다. 그다음 인스타(웹 instagram.com) → 설정 → 「앱 및 웹사이트」 → 「테스터 초대」에서 수락하고, 4단계를 다시 합니다.
>
> **확인 못 한 점:** 공식 문서에 「본인 계정은 앱 심사 없이 된다」는 문장이 있지만, 다른 문장과 어긋납니다. 실제로 해 봐야 확정됩니다. 4단계나 첫 게시에서 권한 오류가 나면 그 문구를 보내 주세요.

## 5. 앱 시크릿 코드 복사(있으면 좋음)
같은 화면 위쪽 **「Instagram 앱 시크릿 코드」** 옆 「표시」를 누르고 복사합니다.
- 4단계에서 받은 토큰이 1시간짜리여도, 이 코드가 있으면 프로그램이 60일짜리로 바꿉니다. 없으면 건너뛰어도 됩니다.

## 6. 이 맥에 토큰 넣기
1. 「터미널」 앱을 열고 아래 두 줄을 차례로 붙여 넣습니다.
   ```sh
   cd ~/gwanak-hiking && . ~/.nvm/nvm.sh && nvm use 24
   npm run insta:reels -- --토큰등록
   ```
2. `앱 비밀값` 질문 → 5단계 코드를 붙여 넣고 Enter(없으면 그냥 Enter).
3. `액세스 토큰` 질문 → 4단계 토큰을 붙여 넣고 Enter.
   - 붙여 넣어도 **화면에 글자가 안 보이는 것이 정상**입니다(비밀값 가림).
4. `저장했습니다: @계정이름`과 `토큰: 59일 남음`이 나오면 끝입니다.
   - 저장 위치는 `~/gwanak-hiking/.instagram/config.json` 한 곳입니다. 이 폴더는 GitHub에 올라가지 않게 막아 두었습니다.

## 7. 잘 됐는지 확인
```sh
npm run insta:reels -- --상태
```
`토큰: n일 남음`, `계정: @…`, `게시 한도: 최근 24시간 0 / 50개`(또는 100개)가 나오면 준비가 끝났습니다.

## 8. 60일마다 할 일
- 토큰은 60일이 지나면 끊깁니다. **릴스를 올릴 때 남은 날이 15일 이하이면 프로그램이 저절로 늘립니다.**
- 오래 안 올리면 직접 늘립니다: `npm run insta:reels -- --토큰갱신`. 토큰을 받은 지 24시간이 지나야 됩니다(인스타 규칙).
- `--상태`와 미리보기에 남은 날이 늘 나옵니다. 10일 이하이면 `⚠️ 만료 임박`이 뜹니다.
- 이미 끊겼으면 4·6단계를 다시 하면 됩니다.

## 토큰이 새었을 때
앱 화면 「앱 설정」 → 「기본 설정」에서 앱 시크릿 코드를 「재설정」하고, 4~6단계를 다시 합니다. 인스타 앱 → 설정 → 「앱 및 웹사이트」에서 이 앱의 접근을 끊어도 됩니다.
