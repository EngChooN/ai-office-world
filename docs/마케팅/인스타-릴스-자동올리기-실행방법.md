# 인스타 릴스 자동 올리기 — 실행 방법 (1페이지)

처음 한 번 할 설정은 `인스타-릴스-자동올리기-설정순서.md`에 있습니다. 터미널에서 먼저 아래 줄을 실행합니다.
```sh
cd ~/gwanak-hiking && . ~/.nvm/nvm.sh && nvm use 24
```

## 올리는 순서 (두 번 실행)
**① 미리보기 — 아무것도 올리지 않습니다**
```sh
npm run insta:reels
```
- 영상 검사 결과(100MB 이하·MP4 H.264+AAC·9:16·3초~15분), **본문 전문**, **첫 댓글 전문**, 올릴 계정, 토큰 남은 날, 오늘 게시 한도가 나옵니다.
- 맨 끝에 `확인 코드: 1a2b3c`가 나옵니다. 영상·글·댓글이 하나라도 바뀌면 코드도 바뀝니다.

**② 실제 게시 — 내용을 확인한 뒤에만**
```sh
npm run insta:reels -- --게시 --확인 1a2b3c
```
- 하는 일: 영상을 GitHub Pages에 잠깐 올림 → 인스타 준비 단계 → 1분마다 최대 5번 처리 확인 → 게시 → 첫 댓글 → 올린 영상 지움. 보통 3~8분 걸립니다.
- 끝나면 게시물 주소가 나옵니다. **인스타 앱에서 첫 댓글을 길게 눌러 「고정」해 주세요**(API로는 고정이 안 됩니다).

## 다른 영상·글을 올릴 때
```sh
npm run insta:reels -- --영상 artifacts/새폴더/영상.mp4 --글 docs/마케팅/새글.md
```
- 글 문서에는 `## 인스타 본문`과 `## 고정 댓글` 제목 아래에 ``` 로 감싼 덩어리가 하나씩 있어야 합니다(지금 `릴스-인형뽑기-v2.md`와 같은 모양).
- 기본값은 `artifacts/reels-claw-v2/온라인인형뽑기-릴스-v2.mp4` + `docs/마케팅/릴스-인형뽑기-v2.md`입니다.

## 그 밖의 명령
| 명령 | 하는 일 |
|---|---|
| `npm run insta:reels -- --상태` | 토큰 남은 날·계정·게시 한도·지우지 못한 임시 영상·끝나지 않은 게시 |
| `npm run insta:reels -- --토큰갱신` | 토큰 60일 연장(받은 지 24시간 뒤부터). 게시할 때 15일 이하면 저절로 함 |
| `npm run insta:reels -- --토큰등록` | 새 토큰 넣기(설정 순서 6단계) |
| `npm run insta:reels -- --정리` | GitHub Pages에 남은 임시 영상 지우기 |
| `--오프라인` | 미리보기에서 인스타 조회도 하지 않음 |

## 중간에 멈췄을 때
- **같은 명령을 다시 실행하면 멈춘 곳부터 이어 갑니다.** 진행 상태가 `.instagram/state.json`에 남아 같은 게시를 두 번 올리지 않습니다.
- 「5분 안에 처리가 끝나지 않았습니다」 → 몇 분 뒤 같은 명령. 같은 준비 단계로 다시 확인합니다.
- 「게시는 됐지만 첫 댓글을 달지 못했습니다」 → 같은 명령. 댓글만 다시 답니다.
- 「지난번 게시 요청의 결과를 알 수 없고…」 → 인스타 앱에서 올라갔는지 봅니다. **안 올라갔을 때만** 명령 끝에 `--다시시도`를 붙입니다.
- 「이미 게시했습니다」 → 같은 영상·글을 일부러 또 올리려면 미리보기에 `--새로`를 붙여 새 코드를 받습니다.
- 「오늘 게시 한도를 다 썼습니다」 → 24시간 뒤 다시.

## 알아 둘 점
- 토큰·앱 비밀값은 `.instagram/config.json`에만 있고 GitHub에 올라가지 않습니다. 화면·기록에는 찍히지 않습니다.
- 임시 영상은 공개 주소 `engchoon.github.io/ai-office-world/reels-tmp/…`에 몇 분 동안 있다가 지워집니다. 다만 gh-pages **지난 기록**에는 남습니다. 다음 `npm run deploy` 때 기록째 사라집니다. 어차피 공개할 영상이라 문제는 작습니다.
- 게시하는 동안 `npm run deploy`를 하지 마세요. 임시 영상이 사라져 인스타가 영상을 못 받습니다.
- 종료 코드: 0 정상 · 1 실패 · 2 옵션 오류 · 3 토큰 만료 임박(`--상태`만).
