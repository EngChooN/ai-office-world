# 변경기록 2026-11-19 — 세 체험 입장 흐름 정리 (월드개발)

월드기획 지시: 허브에서 이름·서버를 정하고 들어가도 게임에서 선택 화면이 또 나옴. 주소로 바로 들어오면 게임마다 입장 화면이 다름. 등산 입장 화면(산 고르기 + 이름)이 폰 가로에서 깨짐.

## 1. 원인(고치기 전 게임별 차이)
서버 고르기 창은 이미 세 게임이 같은 공용 코드(`src/server-pick.js`)였습니다. 다른 점은 그 **앞뒤에 붙은 게임별 화면**과 **기억하지 않는 것**이었습니다.

| | 등산 | 흡연장 | 크리스마스 |
|---|---|---|---|
| 허브에서 서버 골라 옴 | 서버 창은 건너뜀, 그러나 **산 고르기 + 닉네임 칸**이 또 뜸 | 서버 창은 건너뜀, 그러나 처음이면 **로비 카드(닉네임·금연 상태·옷)**가 또 뜸 | 바로 들어감 |
| 주소로 직접(처음) | 산 고르기 + 닉네임 → 서버 창(닉네임 또 있음) | 19세 확인 → 서버 창 → 로비 카드(닉네임 또) | 서버 창 |
| 다시 방문 | 매번 산 고르기 + 서버 창 | 매번 서버 창 | 매번 서버 창 |
| 이름 저장값 | 공용(`gwanak-multi-name`) | **따로**(흡연장 프로필 8자) + 공용 | 공용 |

허브에서 고른 값은 sessionStorage로 한 번만 넘기고(11-17), 주소로 오면 아무것도 기억하지 않아 매번 창이 떴습니다.

## 2. 바꾼 것
- **공통 입장 `src/entry.js`(새 파일)**: 이번 입장 선택 = 허브에서 고른 것 → 이 기기의 지난 선택(`localStorage aoworld:entry:v1`, 체험별 `{server}`/`{solo}`) → 없으면 공용 입장 창을 한 번. 세 게임이 같은 함수(`takeEntryChoice`·`enterWith`)를 씀
- **지난 선택 저장**: 공용 창에서 서버를 고르거나 혼자 하기를 누를 때마다(게임 안 서버 바꾸기·나가서 혼자 하기 포함) `server-pick.js`가 저장. 지난 서버가 꽉 찼으면 예전처럼 「방금 꽉 찼어요」 창
- **등산**: 산 고르기의 닉네임 칸을 없앰(이름은 공용 창 하나). 산 고르기는 **주소로 처음 올 때만** 보임(허브에서 왔거나 지난 선택이 있으면 건너뜀. `?pick=on`이면 늘 보임) → **같은 날 대표 결정으로 되돌림(아래 「추가」)**
- **흡연장**: 처음 와도 로비 카드를 띄우지 않고 기본값으로 바로 들어감. 금연 상태·금연 시작일·옷·닉네임은 ☰ 「내 정보」에서 언제든 고침. 흡연장 닉네임도 공용 저장값을 먼저 쓰고, 「내 정보」에서 고치면 공용 저장값에 씀(12자), 서버 창에서 들어갈 때 이름이 흡연장 프로필에도 들어감
- **크리스마스**: 공통 함수로 바꿈(동작은 지난 선택 기억만 더해짐)
- **그대로 둔 것**: 흡연장 19세 확인(법적 안내, 기기에 한 번 저장되면 다시 안 뜸), 멀티 서버 코드, 허브 화면, `?multi=` 옛 주소(창 없이 1서버)
- **이름·서버 바꾸기**: 게임 안 서버 창(등산 ☰ 설정 「👋 함께 걷기」, 흡연장 위 왼쪽 알약, 크리스마스 위 왼쪽 서버 칩)과 허브 설정의 닉네임에서

## 5. 못 한 것·남은 것
- 실제 휴대폰(아이폰 사파리) 손가락·키보드로는 확인하지 못했습니다(휴대폰 흉내 브라우저로만).
- 공개 멀티 서버로는 시험하지 않았습니다. 서버 코드는 바꾸지 않아 다시 켤 필요 없습니다.
- 산이 둘 이상이 되면 산 고르기가 다시 「주소로 처음」에 보입니다. 지난 선택이 있으면 지금처럼 건너뜁니다(마지막 산을 기억하는 것은 산이 늘 때 함께).
