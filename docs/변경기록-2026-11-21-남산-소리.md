# 변경기록 2026-11-21 · 남산 소리(환경음 + 순환버스) 연결 — 월드개발

업무: 「남산 소리 붙이기」 2/3단계(리더 월드기획). 설계는 월드디자인 `docs/남산/남산-환경음-구간별-설계-v1.md`(1/3단계) 숫자 그대로입니다. 모든 dB·시간 값은 **추정**(귀·현장 확인 전)입니다.

## 1. 무엇이 문제였나
- 대표 지적: "남산은 소리가 아예 없는 것 같다. 버스 소리도 안 들린다."
- 원인: 남산 기능 스위치 `ambient:false`(관악산 환경음 표뿐이라 일부러 끔), 순환버스에는 소리 코드가 전혀 없었음.

## 3. 버스 소리 파일이 없어서 한 것
- 월드디자인이 고른 녹음 3개(BigSoundBank s1145·s0909·s0644, CC0)는 아직 내려받지 못했습니다.
- 그동안 소리가 비지 않게 **게임 안에서 합성한 임시음**(엔진 36Hz 맥동·버스 안 웅웅·공기 빠지는 치익·문 미닫이와 쿵)을 씁니다. 세기는 파일 규격(엔진 RMS −24·안 −26·한 번 소리 피크 −3)과 같게 맞춰, 파일로 바꿔도 게임 쪽 dB 계산은 그대로입니다.
- 파일이 들어오면 `BUS_SOUND.files`에 이름 5개를 채우면 파일을 받아 쓰고, 못 받으면 합성음으로 남습니다. 메모리는 합성음 약 2.7MB(48kHz 모노, 엔진 4초·안 6초·한 번 소리 3개).

## 5. 가정(대표 미확인)
- 밤 정도는 화면 밤 값(0~1)을 그대로 써서 도시·사람 세기를 서서히 바꾸고, 새는 0.5를 넘으면 끔.
- 정상 광장 안이면 코스 거리와 상관없이 구간 6(설계 §1).
- 버스 문 열림은 「치익」 0.4초 뒤에 냄(시간표상 도착과 문 열기 시작이 같은 순간이라 겹치지 않게).
- 좌우는 카메라가 보는 쪽 기준, 거리는 동동이 자리 기준.

## 6. 검토·검수 후속(같은 날, 월드개발)
- **탭을 떠나도 남산 소리가 계속 나던 결함(코드 검토):** 남산 숨김 저장(`game.js` `suspend`)이 소리를 끄지 않았다. 숨긴 탭은 그리기 루프가 멈춰 소리 update가 못 끄므로, 관악산 `main.js`처럼 `suspend`에서 발소리 `stop()`·환경음 `setPaused(true)`·버스 소리 `pause()`를 부른다. 돌아오면 다음 프레임 update가 다시 켠다.
- 버스 소리 `pause()` 새로 만듦: 소리 내리기·문 상태·도플러용 지난 거리를 비움(돌아온 첫 프레임 음 높이 튐 없앰). 소리가 꺼져 있으면 합성음 5개를 만들지 않음(처음 켤 때 만듦).
- **메모리 측정기(월드검수·월드기획):** `scripts/measure-mobile-memory.mjs`
  - `SOUND=1`이면 소리 켠 채로 잼(기본은 예전처럼 끔). 키 입력 한 번(F13)으로 소리를 열고 `audioContext`를 결과에 남김.
  - 남산 주소: `BASE_URL`이 `/hiking/`으로 안 끝나도 `/hiking/namsan/`으로 감(예전엔 기본값이면 `/namsan/`으로 잘못 감).
  - 줄마다 `audioMB`(발소리·환경음·버스 소리가 풀어 둔 AudioBuffer MB), 결과에 `peakAudioMB`·`audioInTotalMB:false`(장면 메모리 `totalMB`에는 소리가 안 들어감). 이를 위해 `snapshot()`에 `bufferMB` 추가(`footstep-audio.js`·`ambient-audio.js`·`namsan-bus-sound.js`, 도우미 `ambient-config.js` `audioBufferMB`) — 관악산 동작은 그대로, 진단 값만 늘어남.
  - 사용: `SOUND=1 MOUNTAIN=namsan BASE_URL=http://127.0.0.1:4173/hiking/ LABEL=namsan-sound-on node scripts/measure-mobile-memory.mjs`, 비교는 `SOUND` 없이 `LABEL=namsan-sound-off`로 한 번 더.
- `public/sounds/CREDITS.md` 남산 버스 절 제목·첫 문단: 지금 나는 버스 소리 5가지가 합성 임시음임을 맨 위에 적음(녹음은 후보·준비 중).
- **못 함(자율 모드 실행 막힘):** `node --check`, `npm test`, 측정기 실행, 귀 확인.
