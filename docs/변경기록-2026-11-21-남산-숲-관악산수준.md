# 변경기록 2026-11-21 — 남산 숲을 관악산 수준으로 (산풍경)

대표 지적: 남산 나무 퀄리티가 관악산보다 떨어져 보인다. 산기획 지시로 같은 시각(여름 13:00 맑음)·같은 화면(PC 1920×1080, 휴대폰 390×844)·1인칭에서 비교했다.

## 1. 원인 (기분 탓 아님)
| 항목 | 관악산 | 남산(고치기 전) |
|---|---|---|
| 길가 30m 안 교목 밀도 | 2m 칸 20% ≈ 0.05그루/㎡(약 4.5m 간격), 화질 낮음 0.0325 | 0.005~0.01그루/㎡ (5~10배 성김) |
| 덤불층(1~3m) | 길 1.4m 밖 2m 칸 55%, 화질별 [22,34,48]m·[30,65,100]% | 없음 |
| 가까운 나무 입체 모양 | `near-trees.js`: LOD0 [0,4,7]그루 18m·잎 줄인 LOD0 [6,14,24]그루 40m | 없음(가까워도 LOD1) |
| 키 섞기 | `forest-structure.js`: 4~7m 20%·8~13m 52%·16~22m 28% | 자료 크기 0.78~1.2배 고르게(약 7~15m) |
| 그루별 잎 명도·색조 | 인스턴스 색이 있어 카툰 셰이더가 그루마다 다르게 칠함 | 인스턴스 색이 없어 모든 그루 같은 색 |
| 먼 단순 모양 전환 | 96m 칸 LOD + 근경 입체 | PC 120m·휴대폰 30m까지 LOD1 (관악산보다 오히려 넉넉) |
| 휴대폰 덜 심기 | 화질 낮음에서 dense 몫 숨김 | `forestKeep` 60m 안 100% — 원인 아님 |

LOD 전환 거리와 휴대폰 덜 심기는 원인이 아니었다. 길가 밀도·덤불·근경 입체·키 섞기·그루별 색이 원인.

## 2. 바꾼 것 (`src/namsan/namsan-art.js`)
- `treeStretch`: 관악산 키 표를 그대로. 자료 숲 나무에도 적용(자료 크기를 곱함).
- `planTrailForest`·`buildTrailForest`: 관악산 `forest-layers.js` 규칙으로 길 30m 안 교목 2,242그루·덤불 7,059포기. 숲·공원 칸(`forestK ≥ .5`)만, 노면·광장·성곽·버스 차로·시설 자리·전망탑 65m 안은 비움. 교목은 64m 칸 LOD(PC 72m·휴대폰 36m 밖 LOD2), dense 몫은 화질 낮음에서 숨김.
- 근경 입체: 관악산 `createNearTrees`를 그대로 씀(화질별 개수·반경 같음). 길 50m 안 나무만 후보.
- 자료 숲 인스턴스에 흰 인스턴스 색 → 그루별 명도·색조.
- `buildNamsan` → `update(t,night,camera,quality)`. `src/namsan/game.js`는 호출 한 줄만(camera·quality 넘김).
