# 변경 기록 — 2026-11-17 허브(게임 고르는 화면) 개선 (월드개발)

시안·문제 정리: `docs/허브개선/README.md`(월드디자인). 대표 확정: PC = 시안 B 「동동이 마을 지도」, 휴대폰 = 시안 A 「책갈피 카드 목록」, 서버 고르기는 허브에서 바로, 소리·설정은 세 체험 공용 하나.

## 사용자에게 달라지는 점
- **PC(폭 761px 이상·높이 501px 이상):** 손그림 지도 위에 등산·흡연장·크리스마스·「다음 체험 준비 중」 4곳, 가운데 동동이가 고른 곳 옷(등산복·회사원 옷·산타 옷)으로 바뀌며 「○○로 갈까?」. 오른쪽 판에 설명·즐길거리 3개·서버 3개 인원 막대·들어가기.
- **휴대폰(세로·가로):** 위 띠(접속 인원·소리·설정) + 동동이 셋 머리말 + 책갈피 카드 4칸이 스크롤 없이 한 화면. 카드를 누르면 아래에서 판이 올라와 서버를 고른다. 가로는 머리말을 숨기고 2×2.
- **서버를 허브에서 고름:** 서버마다 `n/정원`·꽉 참(고를 수 없음), 위 띠에 전체 접속 인원. 상태 3가지 — 켜짐(인원), 확인 중(「들어가서 서버 고르기」 = 예전처럼 체험에서 창), 꺼짐(「혼자 ○○로 들어가기」만). 덜 붐비는 서버를 미리 골라 둔다(80% 아래에서 사람이 가장 많은 곳).
- **체험에 들어가면 서버 창 없이 바로 그 서버**(혼자 하기를 고르면 혼자). 허브를 거치지 않고 주소로 바로 들어오면 예전처럼 서버 고르기 창이 뜬다. 꽉 차서 거절되면 예전처럼 「방금 꽉 찼어요」 창.
- **소리·설정 하나로:** 허브 🔊 단추와 설정 창(닉네임·소리 켜기/끄기·소리 크기·배경 음악(크리스마스 캐럴)·허브 시간대·의견 보내기). 여기서 바꾸면 세 체험이 들어올 때 같은 값을 쓰고, 체험 안에서 소리·캐럴을 바꾸면 허브에도 같이 바뀐다.
- 「다음 체험 준비 중」을 누르면 「가 보고 싶은 곳 알려 주기」 → 의견 보내기 카드(제목 `[허브]`).
- 일시정지 화면 없음, 모든 기능이 단추(44px 이상), Esc는 판·설정 닫기(닫기 단추도 있음).
