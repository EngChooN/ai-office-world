# 변경기록 2026-11-22 — 남산 사랑의 자물쇠: 서버 영구 저장·한마디·눌러 읽기·신고 (월드개발)

상위 업무: 관악산 단풍 무늬 · 남산 자물쇠 · 남산타워 전망대(리더 월드기획) 3/5단계.
기준 시안: `docs/남산/남산-자물쇠-메시지-시안-v2.html`(월드디자인). 수치·문구는 시안 추천안 그대로이고 **대표 미확인**입니다(대표 확인: 꽉 차면 꾸러미, 글 칸 비워도 됨).

## 1. 사용자 눈에 달라진 것
- 정상 난간에 미리 그려 둔 **가짜 자물쇠가 모두 없어졌습니다.** 234자리가 빈 고리에서 시작합니다.
- 함께 걷기 서버에 연결돼 있으면 **서버에 저장된 모두의 자물쇠**가 보입니다. 나중에 들어온 사람에게도, 서버를 다시 켜도 그대로입니다.
- 걸기 카드에 **한마디 칸(30자, 글자 수 표시)** 과 개인정보 안내가 늘 붙습니다. 서버가 「저장됐다」고 답한 뒤에만 걸리는 움직임이 나옵니다(최대 5초 기다림, 넘으면 「저장하지 못했어요 · 다시 걸기」).
- 남의 자물쇠를 **누르면(PC 클릭·휴대폰 탭) 읽기 카드**가 뜹니다: 한마디·닉네임·날짜, ‹ › 옆 자물쇠, 신고. 내 자물쇠는 「내 자물쇠」 배지와 떼기. 할 일 줄 둘째 칸 「2 자물쇠 읽기」도 됩니다. 움직이면 닫힙니다.
- PC는 마우스를 올리면 자물쇠가 1.25배·흰 테두리·손가락 커서.
- 휴대폰은 글 칸을 누르면 색·모양 줄이 「빨강 네모 · 바꾸기」 한 줄로 접히고, 키보드가 열리면 카드가 키보드 바로 위로 붙습니다(공통 틀 `data-uf-kb` 사용).
- 혼자 걷기·서버 없음·끊김이면 **내 자물쇠만** 보이고, 난간에 처음 다가갈 때 4초 알림 한 번. 이때 건 것은 「이 기기에만」(저절로 올리지 않음, 연결된 뒤 카드의 「모두에게 보이기」로 서버 검사를 거쳐 올림). 11-20 옛 저장분(글 없음)도 「글 없이 건 자물쇠예요 · 이 기기에만」으로 보입니다.
- 난간이 꽉 차면 걸 때 「곧 꾸러미로 옮겨져요」가 카드에 뜨고, 거는 사람 것이 아닌 **가장 오래된 자물쇠가 「지난 자물쇠 꾸러미」로** 옮겨 갑니다. 읽기 카드 아래 「지난 자물쇠 N개 보기」 → 최근 옮겨진 순서·한 쪽 5개·줄마다 신고.

## 2. 안전장치
- 금칙어: 채팅과 같은 목록(`server/chat-banned-words.txt` + `BANNED_CHAT_WORDS`). 채팅처럼 ***로 가리지 않고 **걸기를 거절**(빈칸 섞어도 잡음).
- 개인정보 꼴: 숫자 8개 이상(빈칸·-·. 섞여도)·이메일(@)·링크(http·www·흔한 도메인 끝) 거절. 화면이 먼저 알리고 서버가 최종 판단. (주소 글자 자체는 못 거름 — 안내 문구로만)
- 한 사람(기기 열쇠) 최대 3개, 같은 사람 20초에 1번, 같은 곳(IP 해시, 메모리만) 하루 10개.
- 신고: 이유 4가지(욕설·비하/개인정보/광고·도배/기타) 중 골라야 눌림, 신고한 사람 화면에서는 바로 숨김, **서로 다른 3명이면 모두에게서 숨김**. 신고는 `reports.jsonl`에 `kind:"lock"`으로(90일 정리 그대로).
- 운영자: `node scripts/namsan-locks-admin.mjs list | reported | hide <id> | restore <id> | delete <id>`. 서버가 켜져 있어도 되고, 서버가 5초 안에 파일을 다시 읽어 남산 방에 다시 보냅니다. 고치기 전 파일은 `.bak`.
- 글은 화면에 늘 textContent로 넣습니다. 서버 보관 상한 3,000개(넘으면 꾸러미 오래된 것부터 지움).
- 개인정보: 기기 열쇠는 파일에 원문 대신 해시만 저장. IP는 디스크에 안 씀(전과 같음). 저장하는 것은 자리·색·하트·한마디·닉네임(걸 때 이름)·시각·신고자 해시.

## 3. 서버·규격
- 저장 파일 `data-multi/namsan-locks.json`(임시 파일에 쓴 뒤 이름 바꾸기, 바뀌면 0.3초 모아 씀). 깨진 파일은 `.broken-시각`으로 옆에 두고 빈 목록으로 뜸.
- 메시지(등산 체험의 남산 방 `남산`·`남산-2`·`남산-3`에서만): `lk-list`→`lk-all`, `lk-hang`→`lk-ok`/`lk-err`(+ 남산 방 모두에게 `lk-add`), `lk-del`·신고 숨김 → `lk-gone`, `lk-report`→`lk-reported`, `lk-bundle`. 받는 사람마다 `mine`을 따로 붙임. 남산 1~3서버가 같은 자물쇠를 봅니다. 관악산 방은 이 메시지를 받지 않습니다.
- **옛 act `lk-` 호환:** 이 화면은 이제 act.x로 자물쇠를 보내지 않습니다. 옛 화면(배포 전 캐시)이 보내는 `lk-…`는 서버에 연결된 동안 빈 자리에 잠깐 칠하고 「저장되지 않은 자물쇠」로 읽힙니다(신고 없음, 그 사람이 나가면 사라짐). 서버의 act 검사는 그대로라 옛 화면도 계속 접속됩니다.
- Docker 이미지에 `server/namsan-locks.mjs`·`src/namsan/namsan-lock-rules.js` 추가(.dockerignore 두 곳).
- **서버 코드가 바뀌어 운영 서버를 다시 켜야 적용됩니다(대표 확인 뒤).** 다시 켜기 전까지 운영 서버는 `lk-*`를 버리므로 배포된 화면은 「불러오는 중…」에 머물 수 있습니다 → 배포는 운영 서버를 다시 켠 뒤에 하세요.

## 5. 확인 못 함·다르게 한 곳
- 실제 아이폰·안드로이드(키보드 높이·7cm 자물쇠 누르기 편한지)는 못 봤습니다. 헤드리스 브라우저는 키보드를 띄우지 않아 「키보드 위에 붙기」는 코드만 넣었습니다.
- 「곧 꾸러미로 옮겨져요」는 시안처럼 3D 자물쇠 위가 아니라 **걸기 카드 안 글**로 넣었습니다.
- 가운데 기둥의 「지난 자물쇠 꾸러미」 **그림(크기 3단계)은 아직 없습니다**(월드아트 몫). 목록은 읽기 카드의 「지난 자물쇠 N개 보기」로 엽니다.
- 운영자 스크립트와 서버가 같은 순간에 파일을 쓰면 한쪽이 사라질 수 있습니다(스크립트는 파일이 1초 동안 그대로일 때 읽어 줄임). 고친 뒤 `list`로 확인하세요.
- 운영 서버 재시작·커밋·배포는 하지 않았습니다.
