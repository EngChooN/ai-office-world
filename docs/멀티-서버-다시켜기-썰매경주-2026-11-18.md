# 공개 멀티 서버 다시 켜기 — 눈썰매 4명 경주·새 조작감 기록판 (대표용)

작성: 월드개발 · 2026-11-18

## 왜 다시 켜야 하나
눈썰매 경주의 판정은 서버가 합니다. 이번에 서버 쪽 규칙이 바뀌었습니다.
- 경주 모집 시간 10초 → **20초**, **2명부터** 「지금 출발」, **4명이 차면 바로** 3·2·1
- 혼자일 때 「혼자 타기」/「20초 더 기다리기」(새 메시지 `sr:solo`·`sr:more`)
- 「같은 사람과 한 번 더」(지난 참가자에게 참가 카드)
- 오늘의 기록판은 **새 조작감(직접 조작) 기록만**(`fv:3`). 예전 조작감 기록은 기록판에 섞이지 않습니다.

정원·비용은 바뀌지 않습니다. 하늘 썰매 때 다시 켜지 않았다면 이번에 한 번 켜면 두 가지가 같이 적용됩니다.

**다시 켜기 전(옛 서버)에는:**
- 경주는 열리지만 모집이 10초이고, 혼자여도 10초 뒤 그냥 출발합니다.
- 「혼자 타기」·「20초 더 기다리기」 단추를 눌러도 아무 일도 없습니다.
- **오늘의 기록판에 새 기록이 올라가지 않습니다**(옛 서버는 예전 조작감 기록만 받음). 내 기기의 최고 기록·고스트는 그대로 저장됩니다.
- 오류로 화면이 깨지지는 않습니다.

## 순서
1. 월드개발이 GitHub에 올린 뒤 진행합니다.
2. 절차는 11-17 문서와 같습니다: `docs/멀티-서버-다시켜기-대표용-2026-11-17.md`
   - 다른 곳 맥에서 `cd ~/gwanak-hiking && git pull` 뒤 서버를 껐다 켭니다(자동 켜기면 `launchctl kickstart -k …`, 터미널 창이면 Ctrl+C 뒤 `npm run multi:up`).
3. 이 맥(사무실 맥)에서는 켜지 않습니다.

## 잘 적용됐는지 확인 (두 사람, 같은 광장 서버)
- 한 사람이 출발대(또는 케이블카 마을 승강장 옆 「썰매 경주」 판)에서 「경주 열기」를 누릅니다.
- 다른 사람 화면에 「○○님이 썰매 경주를 열었어요 · 1/4 · **20초**」 카드가 뜨면 새 서버입니다(옛 서버면 10초).
- 「참가」 → 연 사람 화면에 「지금 출발 · 2명」이 보이고, 누르면 3·2·1.
- 둘 다 결승하면 출발대 옆 「오늘의 기록」 판에 이름이 올라갑니다.
