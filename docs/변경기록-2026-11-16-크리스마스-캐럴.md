# 변경 기록 — 온라인 크리스마스 캐럴 배경음 (2026-11-16, 월드개발)

총괄 검증에서 되돌린 기준 7('캐럴 분위기')을 채움. 요청: 월드리서치(1순위 군악대 곡·흘려 재생·🔊 연동·출처).

## 무엇이 달라졌나
- 광장에 들어가 화면을 한 번 누르면 캐럴이 나온다. 광장 사람 모두 같은 시계로 같은 곡(8곡이 차례로 돌고 곡 사이 2.5초 겹침, 곡 뒤 무음은 건너뜀).
- 위 오른쪽에 🎵 단추(📬·🔊 다음). 누르면 지금 곡, 「🎵 캐럴 켜짐/꺼짐」(이 기기에 저장, 프로필 `carol`), 「소리 출처」(캐럴 8곡: 곡·연주·편곡·작곡·퍼블릭 도메인·원래 페이지 링크, 바람 소리, 직접 만든 소리).
- 🔊를 끄면 캐럴도 멈춘다. 끄면 `<audio>`를 비워 받기도 멈추고, 켜면 지금 시각의 곡·위치부터 다시 받는다.
- 음량: 캐럴 버스 0.24(바람 0.07·모닥불 최대 0.55 사이), 모닥불에 다가갈수록 줄고 앉으면 0.12(장작 소리 우선). 곡마다 크기 차이(−9.4~−17.3 LUFS)는 배율로 맞춤(원본은 그대로).

## 곡
- `docs/크리스마스/소리-출처-v1.md` §2-4-1 1순위 8곡 전부. 파일은 받은 원본 그대로 `public/sounds/christmas/carol/`(약 53MB, Vite가 빌드에 복사). 출처 줄은 기록표 §16.
- 노래(가사) 확인: 귀로 듣지 못해 음성 인식(whisper.cpp small)으로 전곡을 돌림 → 8곡 모두 가사 없음. God Rest Ye Merry Gentlemen만 시작에 새소리·2:56쯤 "Go!" 외침 한 번.
