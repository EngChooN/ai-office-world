# 변경기록 2026-11-21 — 남산 계단 속도·달리기

대표 지적: "계단이 있는 길에서 걷는 속도도 너무 느리고 뛰기도 안 되는 것 같다."

## 원인
- 남산 계단도 관악산 돌계단 걸음(한 단 0.3m, 초당 1.44걸음 → 0.5m/s)을 그대로 썼다. 남산 계단은 한 단 앞뒤 폭이 0.6~1.8m로 넓고 완만해서 같은 기울기 길(약 0.9~1.0m/s)의 절반 속도였다.
- `speedAt`이 계단에서 달리기 배율을 일부러 빼고 있었다(관악산은 계단에서도 달림).

## 바꾼 것
- `src/namsan/namsan-walk.js`: `stairRuns(G)`(구간 오르는 높이 ÷ 0.16m = 단 수, 단 폭 = 길이 ÷ 단 수 — 그림 `buildStoneStairs`와 같은 셈), `stairTread`, `stairGait`(같은 걸음 수로 한 단 폭만큼, 같은 기울기 포장길보다 빠르지 않게, 최소 0.5m/s). 계단에서도 달리기 ×1.55.
- `src/namsan/game.js`: 계단 보폭(다리 움직임·발소리 간격)도 `stairGait` 값.
- 정상까지 자동 걷기 약 26.6분 → 16.8분(달리면 10.8분). 산 고르기 카드·로딩 안내·공유 미리보기 글 30분 → 17분(추천안, 대표 미확인). 로딩 안내 "계단에서는 천천히 걸어요" → "계단에서도 달릴 수 있어요".
- 시험: `tests/namsan-game.test.mjs` 계단 속도·달리기 시험 추가, 자동 걷기 14~20분, 카드 17분. `npm test` 1,110개 통과.
