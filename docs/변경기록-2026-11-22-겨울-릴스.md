## 방식
- 관악산 릴스(11-11~14)와 같은 녹화·편집 방식(CDP 스크린캐스트 + AudioContext 소리 받기, 휴대폰 세로 360×640×3, 자막 규칙·엔딩 카드 짜임 그대로). 날씨 API 안 씀.
- 남산은 `window.namsan`(jump·goTo·busClockOffset·spots·locks) 콘솔 API로, 크리스마스는 `window.xmas`(teleport·travel.spots·pickSlot)와 행동 단추(`.xh-acts [data-act]`)를 실제로 눌러 찍음. 크리스마스 트리·눈싸움·모닥불은 두 브라우저 창(동동·눈사람러버) + 로컬 서버.
- 자막 새 옵션: `top`(카드·판이 아래를 덮는 장면은 위쪽 y 290~), `band`(화면 UI 글자와 겹치는 장면만 어두운 띠). 산 고르기·자물쇠·트리 장면에 씀.
