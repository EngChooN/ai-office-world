# 정상 '먼 웅성임' 연결 — 월드개발 (2026-11-22)

월드기획 지시. 대표가 정상 소리로 **① 먼 웅성임**을 골랐습니다(대표 결정). 월드디자인 후보 기록: `docs/변경기록-2026-11-22-정상-잔잔한소리-후보.md`.

## 바꾼 것

- 파일: `design/sounds/summit-calm/preview/calm-murmur-loop.flac`을 같은 바이트로 `public/sounds/ambient/summit-murmur-loop.flac`과 원본 보관 `assets/audio/ambient/gwanak-v1/`에 넣음(28초, 모노 32kHz, RMS −34dB).
- `src/ambient-config.js`(관악산)·`src/namsan/namsan-ambient-config.js`(남산): `LAYER_FILES.crowd` = `summit-murmur-loop.flac`, `CROWD_ENABLED=true`. `FILE_RMS_DB.crowd`는 월드디자인이 잰 −34.0 그대로라 숫자 변경 없음.
- `src/ambient-audio.js`: 관악산 미리 받기 목록이 옛 환호 파일 이름을 직접 적고 있던 것을 `LAYER_FILES.crowd`로.
- 옛 환호 `summit-crowd-loop.flac`은 지우지 않고 연결만 끊음. 출처표(`public/sounds/CREDITS.md`, `public/environment/출처-이용조건.md`)에 「안 씀」·새 파일 줄, 게임 안 「소리 출처」 글(관악산·남산)도 새 출처(Joseph SARDIN, BigSoundBank "Outside Talks #2", CC0)로.
- 크기 표는 그대로: 관악산 정상 −44dB(정상 바로 아래 −54→−48), 남산 광장 가운데 −44·가장자리 −48, 밤 −4.

## 관악산 바람에 묻히는지 (크기 올리지 않음)

- 게임과 같은 크기(능선 바람 −33dB, 로우패스 3,500Hz / 웅성임 −44dB)로 맞춰 대역별 세기를 쟀습니다.
- 사람 목소리 대역(180~700Hz)에서 웅성임이 바람보다 약 **10dB 큼**. 귀 감도 보정(A가중)으로 전체를 비교해도 약 4dB 큼. 바람 힘은 대부분 더 낮은 소리 쪽에 있습니다.
- 그래서 묻히지 않을 것으로 보고(추정) 관악산 쪽 크기를 올리지 않았습니다. 더 올리면 「환호처럼 튐」 위험이 커집니다.
- 남산 광장 가운데도 같은 대역에서 바람+도시 소리보다 약 7dB 큼.
