# 허브(게임 고르는 화면) 개선 시안 — 2026-11-17 월드디자인

코드(`src/`)는 고치지 않았습니다. 시안 3개는 단독 HTML이라 파일을 브라우저로 바로 열면 됩니다.
모든 숫자(인원 등)는 예시이고, 시안 속 결정은 **추천안(대표 미확인)**입니다.

| 파일 | 내용 |
|---|---|
| `시안-A.html` | 수첩 책갈피 카드 — **추천** |
| `시안-B.html` | 동동이 마을 지도 |
| `시안-C.html` | 큰 무대 넘기기 |
| `tools/` | 시안 만드는 원본(`*.src.html`·공용 `common.js/.css`)과 `build.mjs`(아이콘 세트를 `public/icons/sprite.svg`에서 골라 넣음) |

각 시안 화면 아래 점선 띠는 **시안 보기 도구**입니다(실제 화면에는 없음). 서버 상태(켜짐·확인 중·꺼짐)를 바꿔 보고 「이 시안 설명」으로 콘셉트·장단점·난이도를 봅니다. 주소 끝에 `?shot`을 붙이면 띠가 숨습니다.

## 1. 지금 허브의 문제 (PC 1920×1080 · 휴대폰 390×844 캡처로 확인)

1. **첫인상이 비어 있음** — PC에서 카드가 화면 위쪽 절반만 쓰고 아래 절반이 빈 종이입니다. 브랜드 캐릭터 동동이가 화면에 한 번도 나오지 않습니다(설명 글에만 있음).
2. **체험 구분이 약함** — 세 카드의 「들어가기」 단추가 모두 같은 빨강입니다. 체험별 포인트 색(등산 초록·흡연장 주황·크리스마스 전나무 초록)이 쓰이지 않습니다.
3. **서버 상태가 없음** — 지금 몇 명이 있는지, 서버가 꺼졌는지 허브에서 알 수 없습니다. 들어간 뒤 서버 고르기 화면에서야 압니다.
4. **소리·설정 입구가 없음** — 체험마다 따로 있어서 허브에서는 끌 수도 바꿀 수도 없습니다.
5. **휴대폰에서 한 화면에 1개 반만 보임** — 카드 한 장이 약 470px라 크리스마스 카드는 두 번 넘게 내려야 보입니다(전체 높이 1,318px).
6. **확장 자리가 없음** — 체험이 늘어날 거라는 신호가 없고, 카드가 3개를 넘으면 PC 줄 배치가 3+1로 어색해집니다.

## 2. 세 시안 비교

| | A 수첩 책갈피 카드 (추천) | B 동동이 마을 지도 | C 큰 무대 넘기기 |
|---|---|---|---|
| 한 줄 콘셉트 | 지금 수첩 종이 느낌을 살리고 체험마다 책갈피 색을 달아 한눈에 고른다 | 체험을 손그림 지도 위 장소로 놓고, 가운데 동동이가 고른 곳 옷으로 갈아입는다 | 한 번에 한 체험을 화면 가득 보여 주고 아래 탭·넘기기로 바꾼다 |
| 동동이 | 첫 칸에 세 옷(등산복·회사원·산타) + 카드마다 작게 | 지도 가운데 1명, 고른 체험 옷으로 바뀜 | 화면 반을 차지하는 큰 동동이 |
| 서버 인원 | 위 띠 전체 인원 + 카드마다 인원 | 장소마다 인원 + 판에서 서버 3개 막대·바로 고르기 | 위 띠 전체 + 탭마다 인원 |
| 휴대폰 | 카드를 가로 줄로 접어 4칸이 스크롤 없이 한 화면 | 위 지도 · 아래 판 | 위 그림 · 아래 글 · 아래 탭 4칸 |
| 장점 | 지금 구조(체험 배열 한 줄 = 카드 하나) 그대로라 위험이 적음. 6~8개로 늘어도 줄만 늘어남 | 「여러 곳이 있는 하나의 세계」 느낌이 가장 강함. 사람 있는 서버로 가기 쉬움 | 첫인상·분위기가 가장 강함. 한 손 조작 편함 |
| 단점 | 놀라운 첫인상은 B·C보다 약함 | 장소가 6개를 넘으면 지도를 다시 그려야 함. 서버 고르기 흐름을 세 체험 모두 고쳐야 함 | 다른 체험이 덜 보임. 탭 5개부터 휴대폰이 비좁음. 체험마다 큰 그림이 필요함 |
| 구현 난이도 (추정) | **낮음** · 약 1~2일 | **중상** · 약 4~6일 | **중간** · 약 3~4일 |

**추천은 A입니다.** 지적된 문제 6개를 모두 풀면서 지금 코드 구조를 그대로 써서 가장 빨리, 가장 안전하게 바꿀 수 있습니다. B의 「장소마다 서버 막대」와 C의 「휴대폰 아래 탭」은 체험이 5개 이상으로 늘어날 때 A에 더할 후속 후보로 남깁니다.

## 3. 세 시안 공통

- 그림: 지금 허브 카드 그림(`src/hub/hub.js` ART)을 그대로 썼고, 「준비 중」 빈 땅 그림만 같은 화풍으로 새로 그렸습니다.
- 동동이: 게임 속 동동이(벙거지·빨간 목도리·주황 바람막이·청록 배낭, 큰 머리)를 평면 그림으로 옮겼습니다. 흡연장은 회사원 옷(셔츠·넥타이, 모자·배낭 없음), 크리스마스는 산타 옷입니다. **허브용 정식 그림은 월드아트 확인이 필요합니다.**
- 아이콘: 모두 `public/icons` 아이콘 세트. 이모지는 쓰지 않았습니다.
- 서버 상태 3가지: 켜짐(인원), 확인 중(도는 아이콘), 꺼짐(「혼자 하기만」, 혼자 하기로 들어가기).
- 소리 단추: 켜면 단추를 누를 때 작은 「톡」 소리(시안용 합성음). 실제로는 세 체험이 같이 쓰는 소리 설정 하나로 저장하는 것을 추천합니다.
- 설정 창: 닉네임 · 소리 크기 · 배경 음악 · 허브 시간대 · 화질 · 의견 보내기 · 처리방침/소리 출처. 「여기서 바꾼 것은 모든 체험에 같이 적용」 기준입니다.
- 넷째 자리 「다음 체험 준비 중」: 누르면 의견 보내기(가 보고 싶은 곳)로 이어지는 안입니다.
- 일시정지 화면 없음, 모든 기능이 단추로 됨, 단추는 손가락 크기(44px 이상).
