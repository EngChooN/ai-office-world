시안 B · 동동이 마을 지도

한 줄 콘셉트: 체험을 한 장의 손그림 지도 위 장소로 놓고, 가운데 동동이가 고른 곳의 옷으로 갈아입으며 기다립니다.

바뀌는 점

  • 장소(섬)를 누르면 옆 판(휴대폰은 아래 판)에 설명 · 즐길거리 · 서버 3개의 인원이 나옵니다.
  • 서버를 허브에서 바로 고를 수 있습니다(덜 붐비는 서버를 미리 골라 둠). 지금의 「서버 고르기 화면」 한 단계를 줄일 수 있습니다.
  • 가운데 동동이가 고른 체험의 옷(등산복·회사원 옷·산타 옷)으로 바뀝니다.
  • 넷째 장소는 공사 중인 빈 땅입니다. 체험이 늘면 지도에 땅이 하나씩 열립니다.

장점

  • 「여러 곳이 있는 하나의 세계」라는 메타버스 느낌이 가장 강합니다.
  • 서버 인원을 장소마다 자세히 보여 줘 사람이 있는 곳으로 가기 쉽습니다.

단점

  • 장소가 6개를 넘으면 지도를 넓히거나 다시 그려야 합니다(그림 작업이 계속 따라옴).
  • 휴대폰에서는 지도와 아래 판이 화면을 나눠 써서 장소 그림이 작아집니다.
  • 서버 고르기 흐름이 바뀌므로 세 체험의 입장 흐름도 같이 고쳐야 합니다.

구현 난이도: 중상 (지도 그림 · 장소 배치 · 아래 판 · 서버 고르기 흐름 변경, 약 4~6일 · 추정)
