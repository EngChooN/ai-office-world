# 2026-11-23 인형뽑기 숲속 집게: 옆에서 보기 왼쪽·오른쪽 둘 다 (월드개발)

대표 피드백: 옆에서 보기가 오른쪽밖에 안 됨 → 왼쪽·오른쪽 둘 다 보게.

- 「👁 옆에서 보기」는 그대로 오른쪽 옆에서 시작. 옆에서 보는 중에는 칩이 둘: 「정면으로 보기」, 「왼쪽 옆에서 보기」(왼쪽에서는 「오른쪽 옆에서 보기」).
- 왼쪽 옆 카메라 = 오른쪽 값의 x만 뒤집음(기계에서 1.5m, 왼쪽 벽 안쪽).
- 십자 단추는 화면 기준 그대로: ▶ = 화면 오른쪽(오른쪽 옆에서는 기계 안쪽, 왼쪽 옆에서는 기계 앞쪽), ▲ = 화면 안쪽.
- 옆에서 보는 중에는 「옆에서 보면 집게가…」 안내를 끔(이미 한 일이고 휴대폰 세로에서 칩 두 개와 겹침).
- 한 판을 새로 시작하면 정면으로 돌아옴(전과 같음).
