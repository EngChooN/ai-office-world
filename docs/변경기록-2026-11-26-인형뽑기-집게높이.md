# 변경기록 2026-11-26 — 인형뽑기 집게·봉 기계 12cm 높임(옮기는 집게가 상자를 치던 문제)

월드기획 지시(대표 제보: 「봉 게임에서 집게가 상자 쪽으로 이동하며 자꾸 상자를 쳐서 날아감, 기계가 더 높아야 할 듯」). 월드공통개발.

## 1. 원인(재현)
- 봉 기계에서 옮겨 다니는 집게의 발끝(쉼 높이)은 바닥에서 약 38.7cm였다. 상자 윗면은 평평하게 놓이면 35.2cm지만, 실제 판에서는 막이 봉에 기대 기울어 보통 39~40cm, 높으면 44.7cm였다.
- 무작위 판(봉 시험 겨누기 그대로, 판마다 게임처럼 → 다음 ↑로 옮김, 상자가 멈춘 뒤 잼): **판의 40~50%에서 옮기는 집게가 상자에 닿았고, 35% 안팎은 상자가 2cm 넘게 밀렸다**(최대 34~44cm). 봉 1~4 모두.
- 11-25 상자를 키운 변경(225cf5c)과는 관계없음: 그 전 코드(225cf5c^)에서도 닿음 41~43%로 같았다. 11-24 집게를 키우고 쉼 높이를 0.99 → 0.95m로 내린 뒤부터 있던 문제(추정).
- 집게 기계: 집게 6(큰 인형이 많음)에서 더미 꼭대기가 쉼 발끝(39cm)보다 높은 판이 12.5%(최고 45.7cm). 잠든 인형은 옮기는 집게와 부딪힘을 계산하지 않아 그런 판에서는 집게가 인형 속을 지나가 보였다.

## 2. 고침
- 집게·봉 기계를 12cm 높임(`claw-machine-art.js` `CLAW`): 유리 위 끝 1.30 → 1.42m, 전체 1.62 → 1.74m, 레일 1.25 → 1.37m, 집게 쉼 발끝 0.95 → 1.07m, 최대 내림 0.36 → 0.48m(바닥 바로 위 그대로). 바닥·봉·상자 높이는 그대로. **열쇠 기계(이미 1.42·1.74m)와 키가 같아짐.**
- 타이머 기계는 그대로(`TIMER.glassTop` 1.3·`boxTop` 1.62를 따로 둠 — 숫자판·이름판 자리 때문).
- 조작 카메라(PC): 1.6·1.75·바라봄 0.84 → 1.74·1.95·0.95(`main.js` `PLAY_CAM`) — 위 간판 번호·집게·상자·조작대가 모두 보이게. 휴대폰 세로 값과 옆에서 보기 카메라는 그대로(촬영 확인).
- 봉 난이도 다시 맞춤 = 봉 마찰 0.35 → 0.25(`CLAW_TUNING.bridge.barFriction`, 봉 4대 같이): 집게가 더는 기댄 상자를 우연히 쳐 주지 않아 높이만 바꾸면 성공까지 평균 봉 1·2 4.6 → 6.2, 봉 3 5.0 → 7.8, 봉 4 5.8 → 9.8판으로 어려워졌음(그 몫은 추정).
  - 봉 간격을 넓히는 쪽도 시험했지만(봉 1·2 22.75cm면 4.5~4.7판) 새 상자의 처음 받침 여유가 줄어 놓자마자 「아슬아슬」이 켜지는 상자가 17%라 버림. 봉 간격·상자 자리 저장(`MACH_PV` 3)은 그대로 → 오늘 하던 상자 자리도 그대로 이어짐.
  - 마찰 후보(상자 80~120개): 0.22 → 4.1·4.8·5.4판, 0.24 → 4.2·5.5·5.7판(봉 3·4 차이가 거의 없음), **0.25 → 4.2·5.5·6.6판**, 0.28 → 5.3·5.9·7.4판. 어려운 순서가 분명한 0.25로.
