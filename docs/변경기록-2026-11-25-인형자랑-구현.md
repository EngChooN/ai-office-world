# 변경 기록 2026-11-25 — 뽑은 인형 들기·업기·등급 빛 구현(인형가게 안에서만, 월드공통개발)

상위 업무: 인형뽑기 뽑은 인형 자랑하기 3/3단계(리더 월드기획). 시안 `docs/인형뽑기/인형자랑-체험-시안-v2.html`(대표 결정: 인형가게 안에서만·🧸 도감에서 고름·나갔다 와도 유지), 4가지 기본 규칙은 v1 결정(손 1 + 등 1·큰 인형 3종만 업기·희귀 보라/특별 금빛·뽑는 동안 숨김). 그림은 월드아트 `src/carry/carry-art.js`(인계 `docs/인형뽑기/인형자랑-그림-인계-v1.md`).

## 1. 사용자에게 달라진 점(인형뽑기 /claw/ 안에서만)
- **🧸 도감** 맨 위에 손·등 두 칸이 생겼습니다(든 인형 그림·이름·「내려놓기」, 빈 칸이면 「작은 인형을 고르면 들어요」/「큰 인형을 고르면 업어요」). 도감 칸 중 든 인형은 초록 테두리 + 「손에 듦」/「업음」.
- 뽑은 인형을 누르면 나오는 **자세히 화면**에 큰 빨간 단추: 「✋ 손에 들기」, 큰 인형은 「🎒 등에 업기」, 이미 든 인형은 「내려놓기」. 같은 자리에 다른 인형이 있으면 단추 아래 「지금 손에 ○○가 있어요 → 바꿔 들어요」.
- **뽑기 성공 카드** 맨 위에 「✋ 손에 들고 다니기」/「🎒 등에 업고 다니기」. 누르면 들고 판이 끝납니다(「한 판 더」는 아래 줄 그대로).
- 들면 0.3초 뒤 창이 닫히고, 코인 알림과 같은 자리에 「○○를 손에 들었어요 · 되돌리기」가 3초 뜹니다. 「되돌리기」는 원래 들던 것으로 돌립니다.
- 작은 인형·상자 피규어는 왼쪽 옆구리, 큰 인형 3종은 등(얼굴이 뒤를 봄). 희귀 = 보라 빛, 특별 = 금빛 + 반짝이. 기계 앞에서 판을 하는 동안은 손·등 모두 숨고, 판이 끝나면 다시 나타납니다.
- 든 인형은 이 기기에 저장되어 **가게를 나갔다 와도 그대로**입니다. 도감 기록을 지우면 저절로 내려놓습니다.
- **등산·남산·흡연장·크리스마스에는 아무 변화가 없습니다**(인형 안 보임, ☰ 메뉴 그대로).

## 2. 같이 고친 결함(이번 흐름에서 찾음)
- 인형가게 「옆에서 보기」 작은 화면 틀의 스타일 이름(`.kh-mini`)이 작은 단추(`.kh-btn.kh-mini`)와 같아, **도감 자세히 화면의 「← 도감」 단추와 ☰ 기계 탭의 ⓘ 단추가 화면 왼쪽 위로 끌려가 눌리지 않았습니다**. 작은 화면 틀만 가리키게(`div.kh-mini`) 고쳤습니다. 새 「내려놓기」 단추도 같은 문제로 처음에 안 눌려서 찾았습니다.

## 3. 같은 가게 손님에게 보이기(서버)
- 인형가게 행동 상태(act)에 칸 두 개를 더했습니다: `ch`(손 인형)·`cb`(등 인형). 다른 콘텐츠 규격에는 넣지 않았습니다.
- 서버 코드(`multi-protocol.js` `ACT_SCHEMA.claw` — 서버 `rooms.mjs`가 같은 규격으로 거름)가 이 칸을 받아 **같은 가게·같은 서버** 손님에게 전달하고, 나중에 온 손님에게도 줍니다. 서버 수·정원·비용은 그대로입니다(인형을 바꿀 때만 글자 두 칸).
- **공개 서버는 이 맥이 아닌 다른 곳에서 돌고 있어 다시 켜지 않았습니다.** 그래서 지금은 화면만 배포되어 **내 화면에서만 보이고**, 공개 서버를 새 코드로 다시 켠 뒤부터 **같은 서버 손님에게도 보입니다.** 다시 켜는 법은 `docs/멀티-서버-다시켜기-대표용-2026-11-17.md` 그대로(그 맥에서 `git pull` 뒤 다시 켜기).
- 옛 서버 + 새 화면 조합: 옛 서버는 모르는 칸만 버리고 나머지 act는 그대로 중계합니다. 접속·위치·뽑는 모습 구경은 전과 같고 오류·끊김이 없음을 확인했습니다(§5).
- 한계: 뽑은 기록이 각 기기에만 있어, 안 뽑은 인형을 든 척 꾸며 보내도 서버가 막지 못합니다(시안 v2에 적힌 대로, 범위 밖).

## 7. 개발 결정(대표 미확인)
- 휴대폰 가로 판에서도 손·등 칸에 「내려놓기」 단추를 그대로 둠(시안: 칸을 누르면 「내려놓을까요?」).
- 도감 자세히 화면에서 「내려놓기」는 창을 닫지 않음(들기만 닫힘). 들고 나면 다음에 도감을 열 때 목록부터.
- 휴대폰 12m 밖 손님은 인형 모형 없이 빛만. 가게 빛 세기는 월드아트 검수 결과 1.0(낮 세기, 분홍 바닥에서도 보이게).
