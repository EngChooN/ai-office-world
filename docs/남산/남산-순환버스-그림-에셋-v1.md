# 남산 순환버스 그림 인계 v1 (2026-11-19, 월드아트 → 월드개발)

월드기획 지시: 전기 순환버스(게임 속 디자인, 실제 로고·번호 없음)·백범광장 정류장·정상 광장 하차 지점 표식·버스 차로를 관악산과 같은 화풍으로, 동동이가 창 너머 앉은 모습 포함.
구현안: `docs/남산/남산-순환버스-구현안-v1.md`(월드개발). 이 문서는 그림 쪽 연결 방법·크기·기준 위치다.

## 1. 지금 화면에 붙어 있는 것
`buildNamsan`이 `G.bus`(= `bus-road.json`을 읽었을 때)가 있으면 버스 그림을 자동으로 만든다. **game.js를 고치지 않아도 보인다.**
- 차로(폭 6.4m, 아스팔트·흰 선·노란 가운데 선·연석) — 백범광장 → 소월로 → 남산공원길 → 정상 광장, 약 1.9km
- 두 광장 판석 위: 버스가 도는 고리 길 노란 점선, 정류장 칸(노란 테 + 「버스」), 걷는 코스가 고리를 건너는 곳 횡단보도
- 백범광장 정류장: 초록 지붕 대기소·나무 의자·둥근 정류장 표지·시간표 판
- 정상 하차 지점: 둥근 표지(「버스 타는 곳 · 내리는 곳」)·노란 볼라드 4개·바닥 화살표 「전망탑」
- 버스 한 대: 백범광장 정류장에 문을 연 채 서 있음(움직임은 월드개발 몫)
- 차로 위·옆 2.5m 안 나무는 심지 않음, 차로 둘레 땅은 차로 높이로 깎거나 돋움(걷는 코스 높이는 그대로 — 검사로 확인)

## 2. 버스가 다니는 길 = `G.bus.cycle` (닫힌 한 줄, 약 4.1km)
| 구간 `cycle.legs` | 뜻 |
|---|---|
| `startRing` | 백범광장 판석 안 고리(반지름 18m) — 정류장이 여기 |
| `up` | 오르는 차선(차로 가운데에서 진행 방향 오른쪽 1.6m, 우측 통행) |
| `summitRing` | 정상 광장 판석 안 고리(반지름 40m, 전망탑을 돎) — 하차 지점이 여기 |
| `down` | 내려오는 차선(반대편 1.6m) → 다시 `startRing` |

- 고리는 늘 같은 방향으로 돌아 **버스 오른쪽(문 쪽)이 광장 가운데를 본다.** 그래서 타고 내리는 자리가 늘 걷는 광장 안이다. 뒤로 달리거나 돌아서지 않아도 된다.
- 위치: `placeOnLane(bus, G.bus.cycle, s)` — s는 0~`cycle.length`, 넘어가면 처음으로 이어짐. 경사만큼 앞뒤로 기운다. 점·방향만 필요하면 `courseAt(G.bus.cycle.points, s)`.
- 정류장 자리: `G.bus.stops.start.s`(백범광장), `G.bus.stops.summit.s`(정상). 둘 다 `{s, bay:[s-8,s+8], x,z(표지 자리), y(광장 높이), heading}`.
- 가장 급한 굽이 반지름 약 4.5m(남산공원길 머리핀), 경사 15% 안. 시속 40km 아래 구현안 숫자와 맞음.

## 3. 버스 모델 `src/namsan/namsan-bus-art.js`
- `buildBus()` → Group. 앞 +Z, 오른쪽 -X(문 쪽), 바닥 y=0. 크기 `BUS`: 길이 9.0·폭 2.5·높이 3.05m, 바퀴 사이 5.2m·반지름 0.42m.
- `bus.userData`: `drive(m)` 지난 거리만큼 바퀴 굴림, `setNight(0~1)` 앞등·뒷등·행선지·실내등·창, `setDoors(0~1)` 오른쪽 문 2개 열림, `seats`(18자리, 버스 좌표 엉덩이 자리), `doorZ`.
- 붙일 때 `toon.toonify(group,{kind:'prop',keepMaps:true})`(글자판 무늬 유지). `buildNamsan`은 이미 이렇게 한다.
- 그리기: 버스 한 대 약 20번(재질별로 합침). 여러 대면 `buildBus()`를 대수만큼.

## 4. 동동이 태우기(창 너머 앉은 모습)
- `seatInBus(bus, avatar, i)` → 동동이를 버스 자식으로 붙이고 의자 i에 앉힌다(엉덩이 = 의자 + 0.09m). 되돌리는 함수를 돌려준다(바인드 자세로).
- **걷기 애니메이션(mixer)을 멈춘 뒤** 부른다. 다른 동작 코드가 같은 뼈를 매 프레임 덮으면 그 뒤에 `poseBusRider(avatar)`를 다시 부른다.
- 창턱 1.2m < 앉은 동동이 머리 가운데 1.4m라 머리·어깨가 창으로 보인다.
- 다른 사람: 구현안 추천대로 「위치가 고리/차선 위」면 같은 의자 자리에 앉혀 그리면 된다(의자 번호는 화면마다 정해도 됨).

## 5. 정류장 시간표 판
`ns.bus.stop.userData.setBoard(['다음 버스','0:24','정상까지 약 3분'])` — 둘째 줄이 큰 글자. 밤 빛은 `ns.update`가 처리.

## 6. 성능(측정)
- 지형 삼각형: PC 66.3만 → 75.3만(+9만, 차로 둘레를 2m 칸으로), 휴대폰 22.5만 → 25.6만(+3만). 숲(약 500만)에 비하면 작음.
- 남산 화면 점검(`verify-namsan-game.mjs`)은 **다시 돌리지 않았다**(월드개발 결과 폴더를 덮어쓰지 않으려고). 내 촬영 스크립트로 PC·휴대폰 화면 오류 0건.

## 7. 실제와의 관계
- 차로 모양만 OSM 차도(소월로3길 → 소월로 → 남산공원길) 참고(ODbL, 화면 출처 줄에 이미 OSM 표기). 높이·고리·정류장 자리는 게임 설계.
- 버스 디자인·색(노랑 + 크림 지붕 + 초록 띠)·표시(산 + 잎 동그라미)·이름 「남산 순환」은 게임 디자인. 실제 노선 번호·회사 로고 없음.

## 8. 남은 문제·후속
- 버스 움직임·타기 단추·카메라·다른 사람 탑승 표시는 월드개발 몫(이 그림을 쓰면 됨).
- 실제 아이폰·안드로이드에서 열어 보지 못함.
- 오른쪽 언덕 위 어두운 그림자 모양은 버스를 빼도 보여 이번 작업과 무관(따로 확인 필요할 수 있음, 추정: 가까운 나무 그림자).
- 확인: `src/namsan/preview.html?view=bus-start|bus-rider|bus-road|bus-cut|bus-summit|bus-aerial`, 검사 `tests/namsan-bus-art.test.mjs`.
