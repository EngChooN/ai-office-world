## 1단계 결과 (11-19)
- `loadLandscape`에 `mountain` 옵션(기본 true = 관악산 그대로). 서울 배경 코드는 `createSeoulBackdrop`으로 옮김(동작 같음).
- 남산(`game.js`·`preview.js`)은 `mountain:false` → 관악산 근경 격자·노면·입구·정상 시설·소품·계단 몸체·지형/식생 청크를 만들지 않음. 원경 땅은 관악산 자리도 채워 남쪽 먼 산이 구멍 없이 보임.
- 측정(헤드리스, 390×844 휴대폰 크기, 밤): 남산 JS 메모리 566 → 498MB, 59fps 그대로. 관악산 59.9fps.
- 점검: 단위 시험 1,053개 통과, 관악산 1군·남산 점검 결과는 `artifacts/merge-baseline/step1/summary.json`.
