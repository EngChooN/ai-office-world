# 남산 ↔ 관악산 기능 비교표 (2026-11-19)

관악산 게임에 있는 기능을 하나씩 꺼내, 남산 게임에 있는지 코드로 맞춰 본 표입니다. 대표가 항목마다 "남산에도 옮길지"를 고를 수 있게 만들었습니다.

- 관악산: `hiking/index.html` → `src/main.js`와 거기서 불러오는 모듈
- 남산: `hiking/namsan/index.html` → `src/namsan/game.js`·`namsan-walk.js`·`namsan-art.js`, 변경기록 `docs/변경기록-2026-11-19-남산-구현-연결.md`
- 코드는 고치지 않았습니다. 화면을 띄워 보지는 않았습니다. 코드에서 확인한 것은 근거 파일을 적었고, 코드만으로 확실하지 않은 것은 **추정**이라고 썼습니다.
- 남산은 관악산 `main.js`를 쓰지 않고 공통 부품만 가져다 씁니다. 그래서 공용 그리기(`rendering.js`)·입력(`input.js`)·함께 걷기(`multi-client.js`)에 들어 있는 기능은 남산에도 저절로 있고, `main.js`·`hud-notebook.js`·`interaction-*`·`trail-*`에만 있는 기능은 남산에 없습니다.

### 대표가 정해야 하는 것 (판단 필요)
스테미너·헥헥/쥐, 즐길거리(산스장·초콜릿·벤치·동물·먼지털이기), 앉기·차·스트레칭, 안내판 읽기, 쌍안경 랜드마크 설명, 라디오(이름이 「관악산 FM」), 후원하기, 출발 지점 고르기, 수첩 탭.

### 거꾸로 — 남산에만 있는 것
- 게임 안 「다른 산 고르기」 단추(`game.js` 설정 탭 `data-ns=pick`). 관악산 게임 안에는 없습니다.
- 정상 카드의 「처음부터 다시」 단추.
- 구간 이동이 `?dev=off`에서도 보임(관악산은 숨김) — 이건 남산 쪽 빠짐으로 표에 넣었습니다.

## 확인 방법·한계

- 남산 `game.js` 전체, `namsan-walk.js` 전체, `namsan-art.js` 일부, 관악산 `main.js` 전체, `hud-notebook.js`·`hiking-frame.js`·`input.js` 전체, 나머지 모듈은 필요한 곳만 찾아 읽었습니다.
- 화면을 띄워 확인하지 않았습니다. 특히 「같이 셀카 사진 안 찍힘」「멀리 있는 사람 안 보임」「3D 끊김 뒤 멈춤」「계절 눈이 남산 지형에도 쌓임」은 코드로 본 결과라 실제 화면 확인이 필요합니다.
- 개수는 이 표의 줄 수 기준입니다. 한 줄이 여러 기능(예: C·T·Z)을 묶은 곳이 있어 기능 하나하나 수와는 다를 수 있습니다.
