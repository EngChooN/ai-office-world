# 남산 소리 붙이기(환경음 + 순환버스 소리) — 취합 보고 2026-11-21 (월드기획)

## 한 줄 결과
코드는 다 붙었고 문서도 맞췄습니다. 외부 코드 검토에서 **관악산 회귀는 없었고**, 남산 쪽 지적 6건(반드시 1·좋음 5)은 **월드개발이 모두 고쳤습니다**(코드 기준, 월드기획이 고친 줄을 직접 읽어 확인). **실행 재검수(11-21, 대표가 자율 모드를 끈 뒤 월드기획이 직접) = 통과**: 문법 검사·전체 시험 1,109개·휴대폰 메모리 소리 켬/끔·소리 점검 모두 됨(시험·측정 도구 쪽 작은 오류 2개는 고침). **귀로 듣기와 사파리 엔진 측정은 아직 못 했습니다.** 커밋·배포는 하지 않았습니다.

## 지금 남산에서 달라지는 것(코드 기준)
- 걷는 동안 구간에 맞는 **환경음**이 납니다: 출발 광장(도심 소음 큼) → 성곽 옆(숲 바람·새) → 큰 계단 → 전망 쉼터(도심 소음 다시) → 마지막 계단(정상 사람 소리 시작) → 정상 광장(사람 소리·트인 바람·도심).
- **순환버스**가 지나가면 엔진 소리가 거리·방향에 따라 나고, 정류장에서는 브레이크 "치익"·문 열림·문 닫힘이 한 번씩 납니다. 타면 버스 안 소리가 나고 바깥 환경음은 작고 먹먹해집니다.
- 밤에는 새소리가 꺼지고 도시 소음이 조금 커집니다. 휴대폰은 가까운 버스 1대 소리만 냅니다.
- 소리 켜기/끄기·음량은 관악산과 같은 공용 설정을 따릅니다.
- 버스 소리는 **녹음 파일이 아직 없어 게임이 직접 만든 합성 임시음**입니다. 파일이 들어오면 파일을 먼저 씁니다.

## 실행 재검수 (11-21, 월드기획 직접)
- 문법 검사 4파일 통과, 소리 시험 19개·전체 시험 1,109개 통과.
- 고친 것(게임 코드 아님): 시험의 「까마귀 없음」 검사가 정상 **사람 소리(crowd)** 파일 이름에 걸려 2개가 실패 → 검사 글자 고침. 메모리 측정기가 소리를 열려고 누르는 키(F13)를 브라우저 도구가 몰라 멈춤 → 동작 없는 Control 키로.
- 휴대폰 메모리(아이폰 13 크기·크롬 엔진·40초): 소리 켬/끔 모두 장면 168.2MB·힙 약 194MB, 소리 켬은 소리 버퍼 15.2MB만 더함. 오류·화면 끊김 0.
- 소리 점검(PC·휴대폰): 소리 켜짐, 파일 35개 모두 풀림, 출발 구간 도시 −44·숲 −54·새 −56(설계대로), 버스 도착 때 치익·문 열림 1번씩, 정차 엔진 세기 계산과 일치. 오류 0.
- 못 함: 귀로 듣기, 사파리 엔진(웹킷) 측정 — 이 맥에 웹킷이 안 깔려 있음.

## 월드기획이 직접 확인한 것
- 코드 순서: 버스 자리 계산 → 소리 계산 순서로 매 프레임 돌고, 첫 프레임 전에 소리 변수가 모두 만들어집니다(오류 가능성 없음).
- 관악산 쪽: 환경음 표·파일을 넘기지 않으면 예전 관악산 규칙이 그대로 쓰입니다. 버스 안 먹먹함 노드는 남산 설정에만 만들어집니다.
- 출처 문서 2곳에 "지금은 합성 임시음"을 추가해 월드검수 지적(합성음 출처 표기)을 마무리했습니다.
- 외부 코드 검토 1회 결과: (아래 「코드 검토」)

## 코드 검토 (외부 검토 1회, 읽기 전용 · 실행 없음 · 11-21)
**결론: 관악산은 예전과 똑같이 동작합니다. 남산은 반드시 고칠 것 1건, 고치면 좋은 것 5건이 나왔고 모두 수정 완료(코드 기준, 실행 확인 전)입니다.**

### 수정 결과 (월드개발 3차, 월드기획이 고친 줄 직접 확인)
| 지적 | 수정 | 월드기획 확인 |
|---|---|---|
| 버스 탄 동안 듣는 자리 | 탄 동안은 탄 버스 위치로 들음 | `game.js` `soundFrame` `P=ride?buses[ride.k].position:st` 확인 |
| 정상 광장 밖 사람 소리 | 광장 밖은 가장자리 값 −48 | `crowdDb` 확인 |
| 건너뛰기 표시 남음 | 멈출 때·안 탄 화면에서 지움 | `pause()`·`if(!want)skipNext=false` 확인 |
| 녹음 일부만 있을 때 무음 | 받은 파일은 쓰고 빠진 것만 합성(`mixed`) | `loadFiles` 확인 |
| 첫 켜기 때 합성 5개 한꺼번에 | 버스 90m 안·탑승 때 한 화면에 하나씩 | `warmOne` 확인 |
| 측정기 소리 저장 이름 | 공용 `aoworld:settings:v1` + 등산 `gwanak-hiking:sound:v1` 둘 다 | 실제 키 상수를 가져와 씀 확인 |
- 변경기록 §7에 표 추가, 트인 바람 2400Hz 메모, 출처 문서 중복 안내 하나로 합침.
- 문법 검사·시험·측정기는 11-21 실행 재검수에서 통과. **아직 못 한 것:** 귀 확인.

### 반드시 고침 (→ 수정 완료)
- **버스를 탄 동안 소리 듣는 자리가 탄 정류장에 남음** (`src/namsan/game.js` `soundFrame`). 버스에 타도 동동이 좌표가 안 바뀌어, 다른 버스가 그 정류장에 서면 공회전·치익·문 소리가 바로 옆 크기로 들립니다. 타는 동안은 탄 버스 위치를 듣는 자리로 쓰도록 고칩니다.

### 고치면 좋음 (→ 수정 완료)
1. 구간 6에서 정상 광장 원 밖일 때 정상 사람 소리가 가운데 값(−44)이라, 원 안에 들어서면 −48로 갑자기 줄어듦 → 원 밖은 가장자리 값 −48.
2. 버스 소리 `skipNext` 플래그가 특정 순서(소리 끈 채 건너뛰기, skip 직후 탭 숨김)에서 남아 다음 하차 때 버스 안 소리가 너무 빨리 꺼짐 → pause/stop에서 초기화.
3. 녹음 파일을 일부만 넣으면 빠진 소리가 무음 → 합성음 버퍼와 합치기.
4. 소리 켜는 첫 프레임에 합성음 5개(약 16.6초 분량)를 한꺼번에 만들어 휴대폰에서 잠깐 끊길 수 있음 → 버스가 가까워질 때 만들기, 파일 있으면 합성 생략.
5. 메모리 측정기의 소리 켬/끔 저장 키가 실제 키(`gwanak-hiking:sound:v1`·공용 `aoworld:settings:v1`)와 다름(이번 전부터 있던 문제, `SOUND=1` 판정이 기대므로 고쳐야 함).

### 참고(이번엔 안 고침)
- PC에서 주소창을 누르면(blur) 소리가 0.25초 끊겼다 다시 켜짐 — 관악산도 같아 회귀 아님.
- 트인 바람 2400Hz는 설계표에 없는 값(변경기록에 적기), 출처 문서의 "합성 임시음" 안내 중복.

### 확인됨(문제 없음)
- 관악산 회귀 없음: preload·새소리 단계·전환 시간·톤·까마귀·목탁 조건을 예전 코드와 줄마다 대조. 설정을 안 넘기면 관악산 기본값.
- 남산 환경음 표의 구간 경계·dB·밤 보정·먹먹함 값이 설계 v1과 일치.
- 버스 소리 노드는 끝나면 모두 해제, 0나눗셈·NaN 방지, 탭 숨김 복귀 시 다시 켜짐, 첫 프레임 전에 소리 변수 생성.
- 새 시험 2개의 import·함수 이름이 실제와 일치, 기대값 손으로 재계산 일치. 기존 환경음 시험도 통과 예상.
- 문법(눈으로): 괄호·import·export 불일치 없음.

## 가정(대표 미확인)
- 소리 범위는 추천안대로 환경음 + 버스 소리 전부입니다.
- 모든 dB·거리·시간 값은 설계표의 추정값이며 귀 검수 전입니다.
- 버스 경적·까마귀·목탁·계곡 물소리는 남산에 넣지 않았습니다.
- 녹음 파일이 들어올 때까지 합성 임시음을 씁니다.

## 대표 확인 필요(막힌 작업·명령)
1. ~~자동 시험과 청취 점검 실행~~ → 11-21 실행 재검수에서 함(통과)

```sh
node scripts/trim-namsan-bus-sfx.mjs
```
3. 귀로 듣고 세기 조정(PC 이어폰·휴대폰 스피커로 구간 1·3·6, 버스 지나감·정차·탑승)
4. 휴대폰 메모리 소리 켬/끔 비교 → 크롬 엔진은 11-21에 함. 사파리 엔진도 재려면 웹킷 설치(약 수십 MB 내려받기) 뒤 다시 잼

npm run build && npm run preview   # 다른 창
