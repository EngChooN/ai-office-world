# 남산 상호작용 그림 에셋 v1 (월드아트 → 월드개발, 2026-11-19)

남산 5단계(관악산 기능 옮기기)에 쓸 그림 4종입니다. 화풍은 관악산과 같습니다(MeshStandard → `toon.toonify(…,{kind:'prop'})`).
**코드 연결은 하지 않았습니다**(`game.js`·`namsan-art.js`·공용 파일 안 고침). 아래 「붙이는 법」대로 월드개발이 5단계에서 붙입니다.
위치·크기·색은 월드아트 추천안이며 **대표 미확인**입니다(4종 구성은 월드개발 추천안 + 대표 추가 요청 ④).

## 1. 결과물

| 그림 | 모양 | 자리(게임 안, 11-19 자료 기준) | 재사용/전용 |
|---|---|---|---|
| ① 약수터 | 관악산 `springModel` 그대로(뒤 바위·쇠 대롱·돌 물받이·바가지 걸이와 빨강·파랑 바가지) + 아래 돌판 받침(경사에서 안 뜸) | 중간 쉼터 옆 s≈770m, 쉼터 데크 **반대쪽(언덕 쪽)** 길가, 앞이 길을 봄 | 관악산 모양 재사용 |
| ② 손 담그는 물확 2곳 | 8각 돌 물그릇(지름 1.2m, 물 높이 0.44m) + 대나무 홈통·물줄기 + 넘친 물이 길 반대쪽으로 3.2m 흐르는 실개천 + 끝 웅덩이·자갈 | `dip-1` s≈285m, `dip-2` s≈986m. 성곽 반대쪽·계단 아닌 평평한 길가 | 남산 전용(새 소품, 다른 콘텐츠에서도 쓸 수 있음) |
| ③ 돌탑 무리 | 관악산 `cairnModel` 7기(관악산 돌탑 공터 배치를 1.25배로 벌림, 큰 탑 1.35m) + 땅을 따라 깐 자갈 바닥(반지름 3.6m) + 올릴 돌 무더기 | 정상 광장 **돌 테 밖 4.2m 풀밭**, 성곽에서 8m 이상, 버스 차로·코스·가로등과 떨어진 곳 | 관악산 모양 재사용 |

정상 표지석·스탬프함·이정표는 그리지 않았습니다(기존 것 사용).

- 그림·자리: `src/namsan/namsan-interact-art.js`

  - `buildNamsanInteract(G,같은 옵션)` → `THREE.Group`(이름 `남산 상호작용 소품`)

## 3. 붙이는 법(월드개발)

`game.js`에서 `const ns=buildNamsan(…);scene.add(ns.root);` 바로 뒤:

```js
import {buildNamsanInteract} from './namsan-interact-art.js';
const ia=buildNamsanInteract(G,{walls:data.walls,lamps:ns.lamps?.userData.spots??[],lanterns:ns.lanterns.userData.spots,items:ns.furniture.userData.items});
toon.toonify(ia,{kind:'prop'});scene.add(ia);
// 매 프레임(ns.update 옆): 물결·자물쇠 동작·밤 물빛·먼 소품 숨기기(카메라 160m 밖)
ia.userData.update(now/1000,nightK(),camera);
```

- `lamps`·`lanterns`·`items`를 넘겨야 가로등·등불·이정표·스탬프함·표지석과 겹치지 않게 자리를 잡습니다(같은 자료면 늘 같은 자리).
- 그림자: 약수터 받침·돌탑·난간 틀은 `castShadow`. 자물쇠·빈 고리는 그림자 없음.

### 상호작용 자리 `ia.userData.spots`

관악산 `interaction-controller.js`의 종류 이름에 맞췄습니다(`spring`·`cairnField`, 물은 `stream`).

| id | kind / action | 쓰는 값 |
|---|---|---|
| `spring-1` | `spring` / `drink` | `x,y,z` = 사람이 설 자리(물받이 앞 1.25m), `face` = 서서 볼 방향(rotation.y), `fillAt` = 물 받는 대롱 끝(세계 좌표), `radius` 2.2. 집는 바가지는 그룹 안 이름 `물바가지`(관악산과 같은 `userData.rest`·`fillAt`) |
| `dip-1`, `dip-2` | `stream` / `dip` | `x,y,z` 설 자리(디딤돌 위), `face`, `waterAt` = 물 표면 가운데, `radius` 1.8 |
| `cairn-summit` | `cairnField` / `cairn` | `x,y,z` 설 자리(광장 쪽), `face`, `top` = 큰 돌탑 꼭대기(다음 돌 올릴 자리), `radius` 3.5. 내 돌을 쌓아 보이려면 관악산 `looseStone()`을 `top`에 놓기 |
| `locks-summit` | `loveLocks` / `lock` (새 이름) | `x,y,z` 설 자리(난간 가운데 앞 1.3m), `face` = 바깥 풍경 쪽, `radius` 5.5, `slots` 234 |

### 자물쇠 걸기 표현 `ia.userData.locks`

| 함수 | 하는 일 |
|---|---|
| `nearestEmpty(x,z)` | 사람 자리에서 가장 가까운 빈 자리 번호(없으면 −1) |
| `aim(i)` | 걸 자리 미리 보이기: 빈 고리가 커졌다 작아지고 위에 분홍 하트가 오르내림. `aim(-1)`이면 끔 |
| `hang(i,{color,heart})` | 새 자물쇠 걸기: 0.22m 위에서 0.25초 내려와 걸림 → 1.5초 흔들리다 멈춤 → 하트가 떠올라 사라짐. 반환 = 걸린 자리 세계 좌표(이미 찬 자리면 `null`) |
| `setFilled([{i,color,heart}])` | 저장된 내 자물쇠·다른 사람 자물쇠를 바로 칠하기(동작 없음) |
| `slots()` / `emptySlots()` / `count()` | 자리 목록(`i,bay,bar,filled,color,heart,at`) / 빈 자리 번호 / `{slots,filled}` |

- **빈 자리 = 크림색 빈 고리**, 걸린 자리 = 색 자물쇠. 오른쪽에서 두 번째 칸(`openBay` 4)은 30%만 걸려 있어 「새로 걸 곳」으로 보입니다.
- 저장·함께 걷기 공유·한 사람 몇 개까지 같은 규칙은 월드개발·월드기획 몫입니다(그림은 아무 자리나 받음).

## 4. 확인한 것(11-19, 개발 서버 5187)

- 남산 게임 화면에 붙여 PC 1920×1080 낮·밤, 휴대폰 390×844 낮을 찍었고 오류 0건.
- 휴대폰 크기에서 같은 장면 그림 보임/숨김을 번갈아 4초 × 3번: 정상 낮·밤, 쉼터 밤 모두 **60.1 / 59.8fps로 차이 없음**(가장 긴 한 장은 순서와 상관없이 첫 측정에서만 생김 = 그림 탓 아님).
- 그리기 21번(카메라 160m 밖 소품은 숨김 → 정상에서 12번, 쉼터에서 8번), 삼각형 약 4.3만(자물쇠 몸·고리를 모든 자리 수만큼 두는 InstancedMesh 몫이 대부분, 빈 자리는 크기 0).
- 찍다가 고친 것: 돌탑 자갈판이 경사에서 받침대처럼 떠 있던 것(돌탑마다 제 땅 높이 + 땅을 따르는 바닥), 자물쇠 난간이 광장 한가운데 서 있던 것(가장자리로), 하트 자물쇠가 너무 크던 것, 밤 물확 물이 형광처럼 밝던 것, 밤 약수터 물이 안 보이던 것(약수터 물 재질은 복사해 남산만 바꿈 — 관악산 화면 그대로), 걸 자리 표시가 다른 빈 고리와 구분 안 되던 것.

## 5. 확인 못 함·남은 것

- 실제 아이폰·안드로이드, 노을 시간, 겨울 눈·봄 꽃 계절 화면은 보지 않았습니다.
- 자리는 「붙이는 법」대로 `items`까지 넘긴 게임 화면 기준입니다. 검사(`tests/…`)는 `items` 없이 돌려 자리가 조금 다를 수 있습니다(규칙은 같음).
- 손 담그기·물 마시기·돌 올리기·자물쇠 걸기 사람 동작(손 뻗기 등)은 관악산 동작을 그대로 쓴다고 보고 새로 만들지 않았습니다.
