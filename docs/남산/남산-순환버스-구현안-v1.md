# 남산 순환버스 타기 — 간단한 구현안 v1 (2026-11-19, 월드개발)

월드기획 지시(대표 결정): "정상 근처까지 순환버스로 이동하는 방식". 범위가 커서 구현 전에 이 안을 먼저 올린다. 코드는 아직 고치지 않았다.

## 1. 한 줄 요약
백범광장 옆 **버스 정류장**에서 「버스 타기」를 누르면, 노란 순환버스가 와서 태우고 산허리 차로를 돌아 **정상 아래 정류장**(정상 광장 가장자리)에 내려 준다. 내려올 때도 같은 버스를 탈 수 있다. 시간은 약 1분 30초, 「건너뛰기」로 바로 도착.

## 2. 사용자 흐름
1. 출발 광장 한쪽에 정류장 표지판 + 시간표(「다음 버스 0:24」). 가까이 가면 큰 단추가 「버스 타기」로 바뀜(관악산 「모든 기능 HUD 단추」 규칙).
2. 누르면 정류장에서 기다림 → 버스 도착(모든 사람에게 같은 시각의 같은 버스) → 탐.
3. 타는 동안: 3인칭 카메라가 버스를 따라가고 창밖으로 서울이 보임. 단추는 「건너뛰기」 「내리기 취소(다음 정류장에서 내림)」 정도만. 조이스틱 숨김.
4. 정상 아래 정류장 도착 → 정상 광장 가장자리에 내림 → 몇 걸음 걸어 광장에 들어서면 정상 도착 창.
5. 정상 정류장에서 「버스로 내려가기」도 같음(출발 광장으로).

## 3. 범위 — 무엇을 새로 만들고 무엇을 안 건드리나
| 구분 | 내용 | 공통 영향 |
|---|---|---|
| 새 파일 `src/namsan/namsan-bus.js` (three 없음) | 차로 선(점 목록)·정류장 2곳·시간표(서울 시각 기준 N초마다 출발, 크리스마스 케이블카 `gondola.js`와 같은 방식)·탄 사람 위치 계산·건너뛰기 | 없음(남산 전용) |
| `src/namsan/game.js` | 정류장 단추·타는 상태·카메라·다른 사람이 버스에 탄 모습 | 없음 |
| `src/namsan/namsan-walk.js` | 타는 동안 걷기 멈춤, 내린 자리를 정상 광장 가장자리로 | 없음 |
| 차로 그림·버스 모델·정류장 표지판 | **월드아트 몫**(그림이 오기 전엔 임시 상자 버스로 동작 먼저) | 없음 |
| 공통 이동(`src/movement.js`·관악산 `main.js`) | **안 건드림** | — |
| 멀티 서버 코드 | **안 건드림.** 버스 속도를 시속 40km(11m/s) 아래로 두면 지금 서버 위치 한도(12m/s) 안이라 서버를 다시 켤 필요 없음. 건너뛰기는 기존 「구간 이동 표시」 순간이동(1초에 1번 허용)으로 보냄. 「버스에 탔음」 표시: 등산 act 칸은 허용 목록(`multi-protocol.js` `ACT_SCHEMA.hiking`)이라 새 칸 `bus`를 넣으면 서버도 바뀌어 운영 서버를 다시 켜야 함(확인함). **추천: 서버 안 바꾸는 쪽** — 다른 사람 화면이 「그 사람 위치가 버스 차로 위」면 버스 안에 앉은 모습으로 그림(버스 위치는 모두 같은 시계라 화면마다 같음) | 추천안이면 공통·서버 영향 없음 |

## 4. 정해야 할 규칙 (추천안, 대표 미확인)
1. **버스로 오른 정상은 완등 기록·도장에 넣을까?** 추천: 정상 도착 창은 띄우되 「버스로 온 정상」이라 가장 빠른 기록에는 안 넣음(지금 구간 이동과 같은 처리). 걸어서 오른 완등만 도장.
2. **버스 길:** 실제 남측 순환로 모양을 참고한 게임 속 차로(실제와 정확히 맞추지 않음). 길이 약 1.0~1.5km 예상(추정, 지형에 그려 봐야 앎).
3. **배차:** 모두 같은 시계로 2분마다 1대, 버스 한 대에 정원 없음(겹쳐 앉힘). 함께 걷기 중이면 같은 버스에 탄 사람이 서로 보임.
4. **실제 차 노선·번호(01A·01B 등)는 쓰지 않고** 「남산 순환버스」 이름만.
5. **다른 사람에게 탄 모습 보이기:** 추천 = 서버 그대로(위치로 알아봄). 다른 안 = act에 `bus` 칸 추가(더 정확하지만 서버 수정 + 운영 서버 다시 켜기 필요).

## 6. 순서
월드아트 남산 그래픽(성곽·돌계단·전망탑·이정표) 연결을 먼저 하고, 이 안이 승인되면 버스를 붙인다. 그림이 늦으면 임시 상자 버스로 동작부터 만든다.
