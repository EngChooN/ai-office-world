# 공개 멀티 서버 다시 켜기 (대표용)

작성: 월드개발 · 2026-11-17 · 대표 결정: **공개 서버는 "다른 곳 서버" 하나만 남김**

## 지금 상태 (11-17 18:46 기준)
- 이 맥(사무실 맥)의 공개 서버와 터널은 **껐습니다.** 이 맥에는 자동으로 다시 켜는 장치(예약 작업·자동 실행)가 없습니다.
- 남은 서버는 **다른 곳 맥** 하나입니다(주소 `bibliographic-…`). 사이트의 서버 주소 파일도 이 서버를 가리킵니다.
- 다만 그 서버는 **옛 코드**라서 아직 크리스마스 광장 정원 20명, 눈싸움 피하기 없음, 썰매 기록판 조작감 구분 없음입니다. 아래 절차로 다시 켜야 새 기능이 적용됩니다.

## 먼저 확인: 그 맥은 어떻게 켜 두었나
11-14에 「로그인하면 저절로 켜지는 장치(LaunchAgent)」를 만든 기록이 있습니다. 이 맥에는 없으니 다른 곳 맥에 있을 수 있습니다. 터미널에 아래를 붙여 넣어 보세요.
```sh
launchctl print gui/$(id -u)/world.ai-office.multi-up | head -3
```
- 글이 여러 줄 나오면 → **아래 「B. 자동 켜기」** 를 따르세요.
- 「Could not find service」가 나오면 → **「A. 터미널 창」** 을 따르세요.

## B. 자동 켜기를 쓰는 경우 (3분쯤)
```sh
cd ~/gwanak-hiking && git pull
launchctl kickstart -k gui/$(id -u)/world.ai-office.multi-up
```
- 두 번째 줄이 서버를 끄고 최신 코드로 다시 켭니다. 1분쯤 뒤 아래 「잘 적용됐는지 확인」을 보세요.
- `npm run multi:up`을 따로 또 켜지 마세요(두 개가 겹칩니다).

## A. 터미널 창으로 켠 경우 (5분쯤)
1. **서버 창 찾기:** 서버를 켜 둔 터미널 창(「켜 둔 채로 두세요」 문구가 보이는 창)을 엽니다.
2. **끄기:** 그 창에서 `Ctrl` + `C`를 누릅니다. 「끄는 중」이 나오고 몇 초 뒤 멈춥니다. 이때 사이트는 잠깐 「서버가 꺼져 있어요」로 바뀝니다(정상).
3. **최신 코드 받기:** 같은 창에 아래를 붙여 넣고 Enter.
   ```sh
   cd ~/gwanak-hiking && git pull
   ```
   「Already up to date」 또는 바뀐 파일 목록이 나오면 됩니다. 오류가 나면 화면을 찍어 월드개발에게 보내 주세요.
4. **다시 켜기:** 예전에 켜던 방법 그대로 켭니다. 보통은 아래 한 줄입니다.
   ```sh
   npm run multi:up
   ```
   - 「터널 열림」과 「gh-pages에 올림」이 나오면 켜진 것입니다. 창은 닫지 말고 켜 둔 채로 두세요(맥 뚜껑도 열어 두기).
   - 예전에 켤 때 앞에 `MAX_PER_ROOM_CHRISTMAS=20` 같은 값을 붙였다면 **빼거나 30으로** 바꿔 주세요. 붙인 값이 코드보다 우선합니다.
5. **1분 기다리기:** 사이트에 새 주소가 반영됩니다.

## 잘 적용됐는지 확인
- **정원 30명:** https://engchoon.github.io/ai-office-world/ 에서 크리스마스 광장 서버 카드를 보면 인원이 **「0/30」** 처럼 30으로 보이면 됩니다(옛 코드는 20).
- **눈싸움 피하기:** 두 사람(PC 두 대 또는 PC+휴대폰)이 같은 광장 서버에 들어갑니다. 한 사람이 던지는 걸 보고 다른 사람이 옆으로 반 걸음 이상 비키면 안 맞으면 됩니다. 가만히 있으면 맞습니다.
- **썰매 기록판:** 썰매를 한 번 타고 「오늘의 기록」에 이름이 오르면 됩니다. 서버를 다시 켰으니 기록판은 비어서 시작합니다(정상). 휴대폰·PC에 남은 개인 최고 기록은 그대로입니다.

## 주의
- **이 맥(사무실 맥)에서는 `npm run multi:up`을 다시 켜지 마세요.** 서버가 두 개가 되면 서로 서버 주소 파일을 덮어써서 접속자가 두 곳으로 갈라집니다.
- 사이트를 배포(`npm run deploy`)한 직후 서버 주소가 잠깐 빠질 수 있습니다. 켜져 있는 서버가 5분 안에 저절로 다시 올립니다.
