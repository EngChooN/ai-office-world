## 공통 부품
- `src/icons/icon.js` — `icon(이름,{size,label,off})`·`iconText(이름,글,{after,stack})`·`iconEl`·`setIcon`·`hasIcon`. 그림은 `${BASE_URL}icons/sprite.svg#ic-이름`을 `<use>`로 불러옴. **그림이 없는 이름은 지금 이모지 글자를 그대로 보여 줌**(월드아트 파일이 오면 저절로 바뀜). 꺼짐은 월드아트 `이름-off` 그림이 있으면 그것, 없으면 CSS 사선. `c-net-connecting`은 저절로 돎(동작 줄이기면 멈춤).
- `src/icons/icons.css` — 크기 5단계 14·18·22·28·40px(선 굵기 `--ic-sw`는 월드아트 CSS와 같은 24격자 환산값), 켜짐·못 누름·꺼짐, 글+아이콘 간격(XS·S 6px, M 이상 8px, 세로 4px). 체험 포인트 색은 `<html data-ic-exp>`로(등산 초록·흡연장 주황·크리스마스 전나무, 밤 값 포함, 추천안·대표 미확인). 허브·등산·흡연장·크리스마스 시작 코드가 불러옴.
- `src/icons/emoji-map.js` — 아이콘 178개 이름과 대신 보일 이모지, 화면 UI 130종 → 아이콘 후보표, 변형 `x-sled-pair`.
- `src/icons/available.js` — 그림이 있는 이름 목록. `node scripts/icons-sync.mjs`가 sprite.svg에서 만듦(빠진 이름도 출력).
- 검사 `tests/icons.test.mjs`, 화면 점검 `scripts/capture-icons.mjs`(4체험 × PC·휴대폰, 콘솔 오류·포인트 색·아이콘 수).
- 월드아트가 낸 `public/icons/icons.css`는 화면에 불러오지 않습니다(같은 값을 `src/icons/icons.css`에 맞춤). 파일은 그대로 둠.
