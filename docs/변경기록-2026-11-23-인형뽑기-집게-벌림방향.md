# 변경기록 2026-11-23 — 숲속 집게: 벌린 채 내려가기(그림 손가락 방향 바로잡음)

월드기획 지시(대표 피드백): 집게가 끝까지 내려온 뒤에 벌리고 조이는 것처럼 보임 → 실제 기계처럼 ①내려가기 시작할 때 벌림 ②벌린 채 바닥까지 ③바닥에서 조임(물리 판정 유지) ④조인 채 올라옴 ⑤출구로 옮긴 뒤 놓기.

## 원인
- 물리(`claw-physics.js`) 순서는 처음부터 맞았음: 내려가기 전 0.45초 동안 벌림 → 벌린 채 내려감 → 바닥(또는 인형에 닿음)에서 조임 → 조인 채 올라옴 → 출구 위로 옮김 → 놓음.
- **집게 그림(`claw-machine-art.js`)의 손가락 회전 방향이 거꾸로**였음. `open`이 커질수록 손가락 끝이 가운데로 모여(1이면 서로 지나침) 물리가 벌리면 그림은 오므리고, 물리가 조이면 그림은 벌어졌음. 그래서 오므린 채 내려와 바닥에서 「벌리는」 것처럼 보였음.
- 그림 시험(`claw-art.test.mjs`)도 「open이 크면 rotation.x가 큼」으로 이 방향을 굳혀 두고 있었음.

## 바꾼 것
- 그림: 손가락 각 `FINGER_ANGLE` {shut 0.3, wide −0.57}(rad). open 0 = 끝이 가운데에서 살짝 겹침, 1 = 활짝. 손가락 끝이 가운데에서 떨어진 거리가 물리 집게발 끝 거리와 1cm 안으로 같게 맞춘 값(닫힘·쉼·내려가기·최대 벌림 4곳). `set({opens:[…]})`로 손가락마다 따로 그릴 수 있음.
- 물리 `clawPose()`가 손가락마다 벌림 `opens`를 줌(그림 손가락 0·1·2 = 물리 집게발 0·2·1). 인형에 막혀 덜 오므려진 집게발도 그림에 그대로 보임.
- `claw-play.js` 정해진 결과 연출(타이머 기계·다른 손님 구경)의 벌림 값도 새 방향에 맞춤: 쉼 0.21(= 물리 쉼 자세), 내려가기 0.62(= 물리 내려가기, 시작 0.2초 안에 벌림), 놓기 0.75, 끝나면 쉼 자세로. 타이머 기계 처음 자세 0.55 → 0.21.
- 물리 숫자(세기·속도·판정)는 바꾸지 않음.

## 확인
- 단위 시험 1,210개 통과. 새 시험: 물리 한 판 동안 「내려가기 시작할 때 이미 벌림 → 벌린 채 내려감 → 가장 깊은 곳에서 조임 시작 → 조인 채 올라옴·옮김 → 출구 위에서 놓음」, 그림 손가락 끝 거리 = 물리 집게발 끝 거리(1cm 안), 그림 open이 클수록 끝이 바깥으로.
- `PART=size,keys,multi SIZES=portrait,pc node scripts/verify-claw.mjs` 172항목 통과. 옆에서 보기로 한 판 하며 그림 손가락 각을 매 프레임 기록: 쉼 0.12 → 내려갈 때 −0.24(벌림), 조임 시작 깊이 = 가장 깊은 곳(0.429m), 올라올 때 조임 시작보다 오므림. 사진 `portrait-6side-down.png`·`pc-6side-down.png`.
- 다른 직원이 아직 커밋하지 않은 인형뽑기 파일(옷·가게 꾸밈) 변경이 작업 폴더에 있어, 이 수정만 깨끗한 worktree에서 점검·커밋·배포함. 그 미완 변경이 있는 폴더에서는 키보드 점검(`PART=keys`)이 「window.claw 없음」으로 멈춤(이 수정 전 코드에서도 같음, 깨끗한 폴더에서는 통과) — 그 작업 담당이 확인할 것.
