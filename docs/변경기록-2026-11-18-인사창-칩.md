# 변경기록 2026-11-18 — 온라인 등산 인사창을 이름표 옆 칩으로 (월드개발)

대표 승인 시안 `docs/인사창/인사창-전후-시안-v1.html`(월드디자인)을 구현했습니다. 인사·같이 등산하기 규칙과 서버 코드는 바꾸지 않았습니다. 화면에 띄우는 방식만 바꿨습니다.

## 무엇이 문제였나
- 다른 사람이 4m 안·앞쪽에 오면 아래 수첩 카드 「인사하기 / 자동 걷기」가 뜨고 큰 빨간 도장이 「걷기」 → 「인사」로 바뀌었습니다.
- 휴대폰 세로에서 화면의 11.1%를 가렸습니다. 동행하며 걸으면 상대가 늘 1~2m 옆이라 계속 떠 있었습니다.

## 바꾼 것
| 상태 | 지금 |
|---|---|
| 근처(4m 안·앞 70°) | 상대 이름표 오른쪽에 👋 칩만(PC는 `F` 같이). 큰 도장·아래 카드는 그대로 걷기 |
| 숨김 | 5.5m 밖(경계 깜빡임 막기) |
| 칩 누르기·F | 인사(예전과 같은 `doGesture('hello')`, 자동 걷기 멈춤도 같음). 칩을 누르면 카드도 펼침(걷는 중이면 인사만) |
| 펼침 | 칩·이름표 누름, 또는 2m 안에서 1초 멈춤 → 머리 위 「이름 · 거리 / 인사 / 같이 등산하기 / ✕」 |
| 접힘 | 5초 무입력, 3m 밖, 걷기 시작, ✕. 접힌 뒤에는 움직이거나 2m 밖에 갔다 와야 저절로 다시 펼침 |
| 걷는 중 | 칩만 흐리게(50%), 펼치지 않음 |
| 동행 상대 | 칩 없음. 둘 다 멈춘 뒤 2초 지나면 보임 |
| 자리 | 칩은 이름표 오른쪽, 화면 끝이면 왼쪽. 이름표가 안 보이면(머리가 화면 밖·이름표 끔) 큰 도장 위 「👋 이름」. 카드는 머리 위 → 옆 → 아래 중 HUD와 안 겹치는 곳, 휴대폰 가로는 옆을 먼저 |
| 물건 안내 | 안내판·스탬프·약수 등은 예전 그대로 도장·카드. 사람은 칩으로 따로 |
| 누르는 칸 | 칩 48×56px(보이는 40×44), 카드 단추 높이 44px(휴대폰), ✕는 44px 칸 |

- 같이 등산하기 단추는 이름표 카드와 같은 `hiking:pair-offer`를 보냅니다. 이미 제안 중·동행 중이면 눌리지 않습니다.
- 칩 대상의 이름표를 누르면 같이 등산하기 고르기 카드 대신 이 카드가 펼쳐집니다. 다른 사람 이름표는 예전처럼 고르기 카드입니다.
- 앉기·기구(쌍안경·휴대폰)·안내판/수첩/완등 카드·산길 행동·같이 셀카 중에는 칩을 숨깁니다(예전 알약과 같은 조건).

## 고친 파일
- `src/greet-chip.js`(새로): 표시 규칙 `createGreetModel`, 자리 계산 `placeGreet`, 화면 `createGreetUI`. `src/greet-chip.css`(새로).
- `src/multi-client.js`: 칩 설치·매 프레임 갱신(카메라 앞 기준 각도), 이름표 누름 연결, `greetKey()`·`greet()` 내보냄.
- `src/interaction-controller.js`: 사람 후보(`personCandidate`)를 알약에서 뺌. `interact`에 물건이 없거나 값이 `greet`이면 칩 대상에게 인사.
- `src/main.js`: F 키가 칩이 있을 때도 인사로 가게(`interact` 조건), 멀티에 `busy`(창·행동 중) 넘김.
