# 변경기록 2026-11-26 — 인형뽑기 소리·가게 배경 음악

월드기획 지시(대표 제보 「소리가 없는 것 같고 밋밋하다」), 같은 날 방향 수정(대표: 「잔잔한 BGM이 아니라 오락실처럼 활기차고 신나게」). 담당 월드공통개발.

## 1. 원인 — 휴대폰에서 소리가 영영 안 켜졌음
- 인형뽑기 효과음(`src/claw/claw-audio.js`, 11-23)은 있었지만 소리 장치를 `pointerdown`·`keydown` 때만 깨웠다.
- 휴대폰 브라우저(아이폰 사파리·안드로이드 크롬)는 손가락을 **뗄 때**(`touchend`·`pointerup`·`click`)만 소리를 허락한다. 그래서 휴대폰에서는 처음부터 끝까지 소리가 0이었다(추정 — 실제 휴대폰으로는 확인 못 함, 브라우저 규칙과 흡연장·크리스마스가 `touchend`를 듣는 것으로 판단).
- 고침: 흡연장·크리스마스처럼 `touchend`·`pointerup`·`click`까지 듣고, 소리가 깨어날 때까지 입력마다 다시 깨운다.
- 배경 음악은 없었다.

## 2. 바꾼 것
- **가게 배경 음악** `src/claw/claw-bgm.js`(새 파일, Web Audio 합성 = 외부 음원 없음, 받는 파일 0KB): 오락실풍 후보 3개. 짧은 루프(A·B 8마디, 간주 C 4마디)를 순서대로 돌리고 멜로디를 옥타브 올림·리듬 바꿈으로 변주한다. 0.1초마다 0.3초 앞까지 음표를 예약해서 휴대폰 부담이 작다(동시 소리 최대 7~10개).
  | 이름 | 템포·조 | 악기 | 순서·한 바퀴 |
  |---|---|---|---|
  | `arcade` 신나는 오락실(기본·추천안, 대표 미확인) | 144bpm A단조 | 펄스 리드·16분 아르페지오·통통 옥타브 베이스·킥/스네어/하이햇·구간 끝 필인 | A A^ B A~ C, 60초 |
  | `pop` 경쾌한 팝 | 126bpm D장조 | 톱니 리드·엇박 화음·4박 킥·박수 | A B A~ C B A^, 84초 |
  | `retro` 레트로 게임 | 134bpm C장조 | 펄스 두 줄 멜로디·걷는 삼각파 베이스·가벼운 드럼 | A A~ B C A^, 64초 |
  - 처음 지시(잔잔한 음악)로 만든 오르골·로파이 안은 같은 날 대표 방향 수정(오락실처럼 신나게)으로 버림.
  - 크기(렌더 측정 `artifacts/claw-bgm/levels.json`): 음악 RMS −39~−43dBFS, 성공음 −29~−30dBFS → 음악이 약 9~13dB 작음. 리드는 2.4~3kHz 위를 깎고 최고음 약 1.2kHz로 막아 코인·성공음(1.5~2kHz)을 덜 가림.
  - 크기: 음악 버스 `BGM_LEVEL`(효과음보다 작게), 기계 앞에서 조작하는 동안 0.55배로 자동으로 줄였다가(`duck`) 판이 끝나면 되돌림.
  - 켜기/끄기 = 공용 설정 `music`(크리스마스 캐럴과 같은 값, 기본 켜짐). 허브 설정 「배경 음악」 설명을 「캐럴·인형가게 음악」으로.
  - 탭을 숨기면 음악을 멈추고 소리 장치를 쉬게 함, 돌아오면 다시.
  - 개발용 듣기 `/claw/?bgm=arcade|pop|retro`.
- **새 효과음**: 올라오기 `up`, 타이머 1초 틱 `tick`(숫자 숨김 기계에서 숫자가 사라진 뒤엔 안 냄)·멈춤 철컥 `door`·딱 10.00 반짝 `perfect`·아깝다 `near`, 열쇠 꽂기 `key-in`·칸 열림 `cell`, 봉 상자 밀기 `push`(물리에 `touch` 이벤트 추가)·상자 떨어짐 `drop`. 집게·봉 「뽑기」 순간 `down`(전에는 구경 화면에서만 났음).
- **다른 손님 기계 소리**(구경)는 내 자리에서 2m 안 0.6배, 9m에서 0(30명 가게가 시끄럽지 않게, `main.js` `hearOf`).
- **소리 창**(☰ → 소리): 소리 켜짐/꺼짐 + 배경 음악 켜짐/꺼짐 + 소리 크기 막대. 모두 세 체험·허브 공용 설정 `aoworld:settings:v1`에 저장.
- 마스터 크기 0.5 → 0.7(효과음이 너무 작았음, 공용 소리 크기 막대가 곱해짐).
- 기본 상태: 소리 켜짐·음악 켜짐 = 다른 콘텐츠(공용 설정 기본값)와 같음.
