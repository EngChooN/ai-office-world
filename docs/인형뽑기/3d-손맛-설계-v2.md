## 2. 물리 규칙(손맛의 핵심)
- 인형 = 공 4~7개를 묶은 덩어리. 곰·토끼(귀가 손잡이처럼 걸림)·길쭉 물개(길어서 걸치기 쉬움, 무거움)·삐약이(작고 가벼움).
- 집게: 내려가며 벌림 → 인형에 얹히거나 바닥이면 멈춤 → 1초 조임 → 들어 올림 → 구멍 위로 → 벌림.
- **세기**: 집게발은 정해진 힘까지만 조임. 인형 무게가 발끝을 누르면 발이 벌어져 떨어짐(약한 기계일수록 잘 벌어짐). 1.2 올라가면 힘이 한 번 더 빠짐(실제 기계처럼 「들었다 놓침」 장면이 생김).
- **겹침**: 다른 인형에 눌린 인형은 위 인형 무게까지 들어야 해서 잘 안 빠짐. 발 하나가 귀·목에 걸려 비스듬히 끌려 올라오는 장면도 생김.
- 구멍 둘레에 투명 칸막이(높이 1.9) — 밀어 넣기가 아니라 들어서 넘겨야 함.
- 가만히 있는 인형은 「잠듦」 처리(더미가 저절로 기어가거나 구멍에 빠지지 않게). 집게가 오거나 이웃이 움직이면 깨어남.

## 3. 기계 3대(숫자 모두 임시값)
| 기계 | 인형 | 수 | 세기(잡기/들고 가기) |
|---|---|---|---|
| 쉬움 · 삐약이 기계 | 삐약이·곰 | 12 | 0.002 / 0.0015 |
| 보통 · 곰토끼 기계 | 4종 섞임 | 14 | 0.0012 / 0.0008 |
| 어려움 · 물개 기계 | 물개·토끼 | 16 | 0.0008 / 0.0005 |
| 힘센 집게(5번 실패 뒤) | — | — | 0.012 / 0.012 |

시험 결과(위에 있는 인형을 거의 정확히 겨눈 경우, 20판씩 node로): 세기 0.0003 → 30%, 0.0015 → 35%, 0.012 → 60%. 약한 집게로 뽑힌 것은 대부분 가벼운 삐약이였음. 사람은 앞뒤(깊이)를 자주 틀리므로 실제 성공률은 더 낮을 것(추정).

## 4. 화면·조작(v1 자리 그대로 + 추가)
- 십자 단추(세로 60px·가로/PC 56px, 누르고 있기, 옆 단추로 밀면 방향 바뀜), 큰 빨강 「뽑기」 76px + 남은 시간 고리, PC 키는 덧붙임 — v1과 같음.
- **추가: 「👁 옆에서/정면」 작은 단추(52px)** — 큰 단추 왼쪽. 3D에서 가장 어려운 건 앞뒤 거리라, 실제 기계에서 옆으로 고개를 내미는 것을 단추로 함. 화면을 끌어도 돌아감.
- 단추 방향은 **화면 기준**(옆에서 볼 때도 ▶ = 화면 오른쪽). 90° 단위로 맞춰 바꿈.
- 위에서 곧장 비추는 빛으로 집게 그림자가 바로 아래 인형에 떨어지게 함(깊이 단서).
- 조작 중 안내 한 줄: 「옆에서 보면 집게가 앞뒤 어디 있는지 보여요」(세로는 단추 위, PC는 위).
- 실패 카드 문구는 실제 장면에 맞춤: 들었다 떨어지면 「아까워요! 들었다 놓쳤어요」, 못 들면 「못 잡았어요 · 옆에서 보고 앞뒤를 맞춰 보세요」 + 「힘센 집게까지 n번」.

## 5. 월드개발·월드아트 인계
- 월드개발: 물리 파일은 three를 쓰지 않아 그대로 옮겨 쓸 수 있음. 한 기계 인형 14~16개 기준 휴대폰에서도 가벼움(node에서 실제 시간의 약 25배 빠르기). 멀티에서 남이 뽑는 장면은 **결과(집게 위치·뽑기 시각·씨앗)만 보내 각 화면에서 다시 돌리면 어긋날 수 있음**(물리는 컴퓨터마다 미세하게 다름) → 뽑는 사람 화면이 판정하고, 구경하는 사람에게는 집게·인형 위치를 짧게 보내는 쪽을 추천(대표 미확인).
- 월드아트: 인형 4종·기계·가게는 자리 잡기용 임시 그림. 인형 모양을 바꿀 때 물리 공 배치(`TYPES`)도 같이 맞춰야 잡히는 느낌이 그림과 맞음.

## 6. 확인한 것 / 못 한 것
- 확인: 자동 브라우저로 휴대폰 세로·가로·PC 촬영, 페이지 오류 0, 십자 단추 누르고 있기로 집게 이동, 한 판 끝까지(들었다 놓침 장면 확인), 단추 44px 이상.
- 못 함: 실제 아이폰·안드로이드 손맛·빠르기, 집게 그림자가 휴대폰 화면에서 깊이 단서로 충분히 보이는지(PC 촬영에서는 집게 몸에 가려 뚜렷하지 않음), 사람이 해 봤을 때 실제 성공률.

## 7. 정해야 할 것
- 판정 방식: **대표 결정(11-23) = 물리 그대로** + 기계별 세기 + 5번 실패 뒤 힘센 집게(꼭 성공은 아님). 확률 먼저 정하는 안과 5번 뒤 꼭 성공 안은 고르지 않음.
- 세기·인형 수·20초·5번은 임시값. 사람 시험 뒤 맞춤.
