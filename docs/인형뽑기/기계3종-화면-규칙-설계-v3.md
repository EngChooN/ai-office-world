## 0. 고정(대표가 정한 것)
3D 가게를 걸어 다니며 뽑기 · 혼자 뽑고 남은 구경 · 무료 코인 + 도감 · **누르고 있다가 놓기/누르기, 휴대폰·PC 모두 화면 버튼(단축키 전용 금지)** · 기계 종류 다양하게(예: 정확히 10:00에 멈춰야 하는 타이머 기계) · 집게 판정 = 물리 그대로 · 치이카와는 개발용 자리만.

## 2. 화면 흐름(세 기계 공통 + 기계별 칸)
```
허브 카드 → A 가게 걷기 → B 기계 고르기(걸어가 2m 안 / ☰ 「기계」 탭 「가기」)
→ C 기계 앞(할 일 칩 「<기계> 한 판 · 🪙1」 + 「ⓘ 규칙」)
→ D 처음 규칙 카드(그 기계 첫 판만, 코인 아직 안 씀) → E 코인 −1
→ F 조작 [기계별] → G 판정 연출 [기계별, 입력 잠금] → H 결과 카드(성공/아까움/실패) → I 도감(새 인형이면 등록)
H 「한 판 더 🪙1」→ E · 「그만」→ C · 「도감 보기」→ I
```
- 조작 중 위 오른쪽 = [집게만 ⏱] · ⓘ · ✕(그만두기 확인 「코인은 돌려받지 못해요」). 💬·☰·조이스틱은 숨김.
- ☰ 「기계」 탭: 줄마다 아이콘·이름·한 줄 규칙·어려움 점·🪙1·「가기」 48px. 다른 손님이 쓰는 기계는 「기다리기」(흐림, 같은 기계 동시 사용 막기만).
- ⓘ와 D 카드는 같은 글을 **조절값에서 만들어** 보여 줌(값을 바꾸면 글도 바뀜 — 보이는 규칙 = 판정 규칙).

## 3. 기계별 규칙(조절값 이름 = 기본값, 모두 임시값)
### 3-1. 기본 집게 `claw` (v2 그대로)
- F: 십자 4단추 누르고 있기(20초 안 자유) · 👁 옆에서 · 「뽑기」. G: 내려감 → 조임 → 들어 올림(물리).
- 성공 = 구멍 위까지 들고 감 / 아까움 = 들었다 놓침 / 실패 = 못 듦.
- 조절값: `claw.grab`=0.0012 · `claw.carry`=0.0008 · `claw.dolls`=14 · `claw.timeSec`=20 · `claw.moveSpeed`=0.35(기계 폭/초) · `claw.dropLockSec`=0.6 · 보장 `pity.after`=5 → `claw.pityGrab`/`claw.pityCarry`=0.012.

### 3-2. 타이머 `timer`
- F: 큰 단추 초록 「▶ 시작」 → 숫자판이 0.01초씩 오름 → 큰 단추 빨강 「✋ 멈춤」. 준비에서 20초 안 누르면 저절로 시작.
- **판정 시각 = 손가락이 닿은 순간**(`pointerdown`의 `event.timeStamp`, 시작도 같은 방식). 화면 그리기 틈(약 16ms)과 상관없음.
- **표시 = 0.01초 아래 버림**, 늘 「두 자리.두 자리」(09.87), 고정 폭 숫자. 멈추면 그 값이 그대로 남고 결과 카드·기록에도 같은 숫자.
- **판정은 화면에 멈춘 숫자로만**: 「10.00」(실제 10.000~10.009초) = 성공(꽉 잡아 구멍으로) / 9.90~10.10 중 10.00 아닌 것 = 아까움(들었다 놓침) / 그 밖·15.00 넘김 = 실패(허공).
- 허용 오차 안내 = 숫자판 바로 아래 띠 「실패 | 아까움 9.90~ | 10.00 성공 | ~10.10 아까움 | 실패」 + 한 줄 「숫자가 10.00일 때만 꽉 잡아요 · ±0.10초는 들었다 놓쳐요」.
- 조절값: `timer.targetSec`=10.00 · `timer.okWinSec`=0.00(성공 허용 ±, 0이면 10.00만) · `timer.nearWinSec`=0.10 · `timer.maxSec`=15.00 · `timer.startLockSec`=0.5(시작 뒤 멈춤 무시) · `timer.readyLimitSec`=20 · `timer.hideAfterSec`=0(끔, 켜면 그 초부터 숫자를 어둡게 — 어려운 기계용) · `timer.pityWinSec`=0(끔).
- 보장: **기본 끔(추천)** — 완료 기준 「10.00에서만 성공」과 맞추려고. 켜면 그 판 띠에 넓어진 성공 칸을 그대로 그림.
- 판정 함수(시안 그대로 옮겨 쓰면 됨, three 없음): `hund(ms)=floor(ms/10)`, `fmtTimer(ms)`, `judgeTimer(ms,conf,pity)` → `{r:'win'|'near'|'miss', shown, diff}`.

### 3-3. 열쇠 `key` (세 번째 기계 추천)
- F: ① 큰 단추 **누르고 있기** = 열쇠가 오른쪽으로(초당 1.4칸), 떼면 고정(다시 못 고침) → 0.3초 뒤 ② 다시 **누르고 있기** = 위로, 떼면 열쇠가 앞으로 들어감. 한 번 누르고 10초면 저절로 뗀 것으로.
- 칸 2줄×4칸 = 인형 8칸(손님이 원하는 인형을 고름 → 도감과 연결). 칸마다 아래쪽에 정사각형 열쇠 구멍, **희귀·특별 칸은 구멍이 작게 그려짐**(그림 크기 = 판정 크기).
- 판정 단위는 가로·세로 모두 「칸 폭」(세로 한 칸 = 1.4칸 폭). 열쇠 끝과 구멍 가운데의 차이가 가로·세로 모두 허용 폭 안 = 성공(「철컥」 문 열림) / 허용 폭 2배 안 = 아까움(가장자리에 「딱」) / 그 밖 = 실패(튕김). 결과에 「옆으로 조금 더」처럼 빗나간 방향.
- 조절값: `key.cols`=4 · `key.rows`=2 · `key.cellH`=1.4 · `key.holeY`=0.32 · `key.speed`=1.4(칸/초) · `key.fit`=0.14(칸) · `key.fitRare`=0.08 · `key.nearMul`=2 · `key.pityFitBonus`=0.05 · `key.holdLimitSec`=10 · 보장 `pity.after`=5 → 다음 판 구멍이 눈에 보이게 넓어짐.
- 판정 함수: `judgeKey(x,y,conf,isRare,pity)` → `{r,i,j,dx,dy,fit}`.

### 3-4. 공통
`coin.cost`=1 · `coin.daily`=10 · `pity.after`=5(기계별, 0이면 끔) · `result.showNear`=켬. 판정은 뽑는 사람 화면, 구경하는 사람에게는 결과(기계·인형·멈춘 숫자/열쇠 자리)만 보냄. 몰래 확률을 바꾸지 않음(월드리서치 권고: 열쇠 기계 실물 소송 사례).

## 7. 점검(월드개발 점검에 넣어 주세요)
1. 타이머 표: 9.999→09.99 아까움 · 10.000→10.00 성공 · 10.009→10.00 성공 · 10.010→10.01 아까움 · 10.100→10.10 아까움 · 10.110→10.11 실패 · 9.899→09.89 실패. 0~15초 1ms 간격 전체에서 「성공 ⇔ 화면 10.00」.
2. 숫자는 늘 `^\d\d\.\d\d$`, 멈춘 숫자 = 카드 숫자 = 기록 숫자.
3. 열쇠: 구멍 가운데 = 성공, 0.2칸 빗나감 = 아까움, 0.5칸 = 실패. 희귀 칸 구멍 그림이 판정 폭과 같은 크기.
4. 360×640·390×844·412×915 / 844×390 / 1280×720·1920×1080에서 단추 44px 이상·서로 안 겹침·안전 영역 안, 알림·카드가 알약·위 단추에 안 가림.
5. 마우스만, 터치만으로 각각 세 기계 한 판 → 도감.

## 8. 확인한 것 / 못 한 것
- 확인(자동 브라우저, 이 맥): 위 1~3을 시안 안 점검 함수로 계산해 통과(1ms 훑기 어긋남 0건). 시안 속 모든 화면(세로·가로·PC)의 단추 44px 이상·조작 단추 겹침 0·알림이 알약/위 단추와 겹침 0. 마우스로 타이머 한 판(시작→멈춤→카드 숫자 일치), 열쇠 누르고 있기 두 번 한 판, 휴대폰 터치 흉내로 타이머 한 판, 페이지 오류 0.
- 못 함: 실제 아이폰·안드로이드에서 손가락 닿는 순간 시각의 정확도(기기 지연은 사람마다 같게 늦을 것으로 추정)와 손맛, 사람이 했을 때 10.00 성공률(실제 Time Out류도 매우 어려움 — 너무 어려우면 `okWinSec`를 올리는 대신 「아까움 보상」을 따로 정하기를 권함), 360px 좁은 폭 실제 촬영(시안은 390 기준).
