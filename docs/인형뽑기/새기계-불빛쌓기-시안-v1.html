새 기계 ① 불빛 쌓기 「별빛 탑」 추천안 · 대표 미확인

버튼 하나로 좌우로 오가는 빛 막대를 멈춰 위로 쌓습니다. 7줄 = 작은 인형, 11줄 = 큰 인형. 7줄에서 「계속하기」를 골라도 받은 인형은 잃지 않습니다. 왼쪽 휴대폰 화면을 직접 눌러(또는 Space) 한 판 해 볼 수 있습니다. 규칙서: docs/인형뽑기/새기계3종-규칙서-v1.md §1

한 판 흐름

  1. 기계 앞 할 일 칩 「✨ 별빛 탑 한 판 · 🪙1」(처음이면 규칙 카드 → 「시작하기」를 눌러야 코인 씀)
  2. 준비 0.8초 → 1줄 빛 막대(3칸)가 좌우로 오감. 첫 줄은 아무 데서나
  3. 「✋ 멈춤」 = 누른 순간 멈춤. 아래 줄과 어긋난 칸은 빨갛게 떨어짐 → 다음 줄(남은 칸 수로)
  4. 7줄: 작은 인형이 바로 나옴(도감 등록) → 카드 「▲ 계속하기 / 여기서 끝」(20초 지나면 끝)
  5. 계속 → 11줄이면 큰 인형도. 중간에 칸이 다 떨어져도 작은 인형은 그대로
  6. 결과 카드: 「들고 다니기 / 도감 / 한 판 더 · 1 / 그만」(기존 카드 그대로)

입력 없음 10초 = 그 자리에서 저절로 멈춤(열쇠 「10초면 뗀 것으로」와 같음). ✕ = 그만두기 확인 「넣은 코인은 돌려받지 못해요」.

아까움(6줄)떨어지는 칸 빨강「아까워요! 다람쥐까지 1줄」
실패떨어지는 칸 빨강「아쉬워요 · 4줄까지」 + 「5줄에서 2칸 늦었어요」

줄마다 어긋나면 짧은 알림 「6줄 1칸 빨랐어요」(1.2초). 왜 실패했는지 숫자로 보임 = 타이머 「+0.03초 늦었어요」와 같은 생각.

연속 실패 도움

경품 없이 5판 연달아 끝나면 다음 판부터(받을 때까지) 직원이 시작 칸을 3 → 4칸으로 넓혀 줍니다. 판 위에 「직원 도움 · 4칸 시작」 글, 시작 알림, 결과 카드에 「직원 도움까지 n번」.

이유: 열쇠(넓은 구멍)처럼 눈에 보이는 도움. 「첫 세 줄 느리게」(조사 초안)는 화면에서 차이가 안 보여 몰래 바꾸는 것처럼 느껴질 수 있어 뺌. 7줄 인형을 받으면 세기가 0으로.

구경하는 손님 화면 왼쪽에서 한 판 하면 0.15초 늦게 따라 그림

  • 다른 손님은 기계 판 불빛 그대로를 봄(내 화면 HUD·카드는 안 보임 — 기존 구경과 같음)
  • 멈출 때마다 act 한 번: v 쌓은 줄 · cx 그 줄 왼쪽 칸 · cz 칸 수 · 7줄 고르는 동안 ph:'drop' → 머리 위 「고르는 중…」
  • 움직이는 줄은 받는 화면이 같은 빠르기로 혼자 움직임(초당 여러 번 보내지 않음)
  • 중간에 들어온 손님은 그 순간 줄까지 그림. 11줄이면 탑 무지개(가게 알림은 기존처럼 희귀 이상만, 10초에 1번)

받은 act:

기존 4종과 다르게 한 곳 · 이유

  • 👁 옆에서 보기 없음 — 판이 평평한 불빛 판이라 깊이가 없음.
  • ⏱ 남은 시간 없음 — 줄마다 시간을 쓰는 기계라 판 전체 제한이 없고, 10초 무입력만 저절로 멈춤.
  • 한 판에 경품 둘 — 7줄에서 이미 줌. 「계속」은 코인·경품을 걸지 않음(도박처럼 보이는 「올인」 방지, 기획서 원칙).
  • 결과 카드가 두 번(7줄 고르기 카드 + 끝 카드) — 7줄 카드는 「받았다」를 먼저 확인시키려는 것.
  • 타이머와 「타이밍」은 겹치지만 타이머 = 한 번 정확히, 이쪽 = 빨라지는 여러 번.
