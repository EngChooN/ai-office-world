## 3. 기계 3대 (`MACHINES`, 기계 좌표: 앞 +Z, 바닥 0)
- 숲속 기계(초록, 집게, 「처음이라면 여기!」) · 도시 기계(주황, 타이머, 「딱 10.00에 멈춰요」) · 별빛 기계(남색, 열쇠, 「열쇠로 칸을 골라요」). `kind`가 기계 몸 종류, `pool`은 그림 기본값이고, 확률·집게 힘은 월드기획 조절값입니다. 별빛 기계는 `cells`(칸 8개)를 더 가집니다.
- 세 종류 모두 바닥 넓이·조작대·투입구·인형 나오는 문·서는 자리가 같습니다. 그래서 가게 자리·부딪힘은 그대로입니다. `userData.kind`('claw'·'timer'·'key')와 `userData.height`(이름 말풍선 높이용: 집게 1.62·타이머 1.80·열쇠 1.74)를 공통으로 줍니다. 조작 카메라는 `userData.camera`(집게는 `CLAW.camera`)를 쓰세요.

### 3-1. 집게 기계
- 크기: 폭 0.95 · 깊이 0.85 · 높이 1.62m. 조작대 윗면 0.48m(동동이 팔 높이), 유리 상자 0.56~1.30m.
- 집게: `machine.userData.claw.set({x,z,drop,open,dotY})`
  - x·z: 기계 좌표 m. 범위는 `CLAW.play`(x ±0.33, z ±0.28). 처음 자리 `CLAW.home` = 인형 나가는 구멍 위.
  - drop: 0~`CLAW.dropMax`(0.4). 손가락 끝 높이 = `CLAW.clawTop`(0.99) − drop.
  - open: 0 오므림 ~ 1 활짝. dotY: 바닥 그림자 점 높이(`pile.topAt(x,z)`를 넣으면 더미 위에 놓임).
  - `claw.tipWorld()` = 손가락 끝 세계 좌표(잡기 판정에 쓰기).
- 불빛: `setLights('idle'|'play'|'win'|'rainbow'|'off')`. 매 프레임 `update(dt)`. 희귀 성공 2초 무지개(설계 §5)는 `rainbow`.
- 뽑기 단추 눌림: `press(0~1)`.
- 자리(기계 좌표): `userData.spots` = stand(손님 서는 곳, z 1.0, 기계를 봄)·stick(손잡이)·button(뽑기 단추)·coin(투입구)·door(인형 나오는 문)·sign(이름 말풍선 자리).
- 조작 카메라 추천값 `CLAW.camera`: PC·가로 pos (0, 1.9, 1.7)·look (0, 0.74, 0)·fov 42, 휴대폰 세로 `portrait` pos (0, 2.2, 2.1)·fov 55. 동동이 모자 위로 넘겨 봅니다.

### 3-2. 타이머 기계 (`buildTimerMachine(theme,{toonify,guestObject,prize})`, v1.1)
- 위 간판 자리에 **큰 숫자판**(기계 폭 84%, 숫자 높이 약 0.19m = 기계 폭 20%), 그 아래 허용 띠(실패 | 9.90 | 10.00 | 10.10 | 실패), 그 위에 이름판. 유리 상자 안 가운데에 줄무늬 단 + 인형 하나 + 단 위 고정 집게. 조작대는 큰 단추 하나(시작 초록·멈춤 빨강).
- `userData.setTimer({text, state, dim})`: **판정이 돌려준 `fmtTimer` 글자를 `text`로 넘기세요**(화면 HUD·결과 카드와 같은 숫자). `ms`만 넘기면 같은 식(`timerText` = 0.01초 아래 버림)으로 씁니다. `state`: ready·run(주황) · win(초록, 처음 1.6초 4번 깜빡) · near(노랑) · miss(빨강) · off. `dim:true`면 도는 숫자를 어둡게(`timer.hideAfterSec`용).
  - 숫자판은 글자·상태가 바뀔 때만 다시 그립니다(384×144 한 장). 매 프레임 불러도 같은 글자면 그리지 않습니다.
- `setBand({targetSec, nearWinSec, okWinSec})`: 조절값을 바꾸면 띠 글자도 바뀝니다(보이는 규칙 = 판정 규칙). `null`이면 띠를 안 그림.
- `setButton('start'|'stop'|'off')`, `press(0~1)`, `setLights(…)`, `update(dt)`는 집게와 같습니다.
- 단 위 인형: `setPrize(id)`(손님 인형은 `guestObject`), 지금 인형 `prize`, 단 윗면 `stage`(기계 좌표). 성공 연출은 `claw.set({x,z,drop,open})`로 단 위 집게를 내리고 `prize`를 집게에 옮겨 붙이면 됩니다(집게 시작 자리 = 단 위, 구멍 `CLAW.chute`는 집게 기계와 같은 왼쪽 앞).
- `spots`: stand·button·coin·door·display(숫자판 가운데)·sign.
- 조작 카메라 `TIMER.camera`: PC·가로 pos (0, 1.65, 1.8)·look (0, 1.05, 0)·fov 42, 세로 pos (0, 1.85, 2.2)·fov 55. 숫자판 전체와 단 위 인형이 동동이 모자 위로 보입니다.

### 3-3. 열쇠 기계 (`buildKeyMachine(theme,{toonify,guestObject,cells})`, v1.1)
- 유리 상자 안 앞면에 **칸 2줄×4칸**. 칸 폭 `KEY.cell` = 0.2m, 칸 높이 = 1.4칸 폭. 칸마다 아래 자물쇠 판 + 정사각 열쇠 구멍(금 테), 위에 인형(칸에 맞게 줄임, 흔함 0.13 ~ 특별 0.18m, 다리는 판 뒤로 가려짐). 칸 앞을 오가는 금 열쇠 + 세로 기둥. 위 줄 칸이 간판에 가리지 않게 유리 상자를 집게 기계보다 12cm 높였습니다(높이 1.74m).
- **좌표는 설계 v3 `judgeKey`와 같습니다**: x = 칸 단위(0~4, 왼쪽 0), y = 칸 폭 단위(0~2.8, 아래 0). `KEY.toLocal(x,y)` = 기계 좌표. 구멍 가운데 = (i+0.5, j×1.4+0.32).
- `userData.key.set({x, y, push, aim})`: push 0(칸 앞 2cm) ~ 1(끝이 구멍 안 2.5cm). `aim`(기본 켬)은 칸 앞면 빨간 겨눔 점 — 위에서 비스듬히 보는 카메라라 열쇠만 보면 실제보다 조금 낮아 보여서 넣었습니다. 처음 자리는 시안 값 (0.15, −0.3).
- `setHoles({fit, fitRare, pity, pityBonus})`: **구멍 그림 한 변 = 2 × 허용 폭 × 칸 폭**. 희귀·특별 칸은 `fitRare`(작은 구멍, 판도 연노랑). 보장 판이면 `pity:true`로 넓어진 구멍을 그대로 그립니다. 판정 쪽 isRare는 `keyCellRare(id)` 또는 `cells[k].rare`를 쓰세요(그림과 판정이 같은 칸을 희귀로 봄).
- `cells[{i,j,id,rare,obj}]`, `cellAt(i,j)`, `setCells(ids)`(아래 줄 왼→오, 위 줄 왼→오), `markCell(i,j,'ok'|'near'|'miss'|null)`(칸 초록·노랑·빨강 빛), `openCell(i,j)`(칸 바닥이 젖혀지고 인형이 떨어져 0.6초 안에 숨음 → 문 쪽 인형은 `makePlush`로 따로), `resetCells()`(다음 판 전에).
- 기본 칸(`MACHINES[2].cells`, 추천안): 아래 = 다람쥐·산토끼·산고양이·등산 동동이, 위 = 회사원 동동이·해치·산타 동동이·손님 자리 1(공개판은 해치로 대체).
- 조작 카메라 `KEY.camera`: PC·가로 pos (0, 1.85, 1.55)·look (0, 0.92, 0)·fov 42, 세로 pos (0, 2.15, 1.75)·fov 55. 칸 아래가 모자 위로, 칸 위가 간판 아래로 보이는지 검사에 넣었습니다.

## 4. 인형 더미 (`fillPile(machine, ids, {count, seed, toonify, guestObject})`)
- 유리 안 바닥에 두 층으로 쌓고, 구멍 둘레는 비웁니다. 같은 `seed`면 늘 같은 배치(같은 방 사람이 같은 더미를 봄).
- 반환 `pile`: `items[{id,pos,size,hidden}]`, `nearest(x,z)`, `topAt(x,z)`, `take(i)`(숨김 → 집게에 `makePlush(id)`를 달면 됨), `put(i)`(다시 놓기).
- 더미를 다시 채우려면 `pile.dispose()` 뒤 `fillPile`를 다시 부르세요.

## 5. 가게 (`buildClawShop({toonify, mobile, guests, guestObject, pileSeed, kinds})`)
- **`kinds:true`면 기계 종류대로(집게·타이머·열쇠) 만듭니다.** 기본값은 세 대 모두 집게입니다(지금 게임 코드가 세 대를 집게로 쓰고 있어서 안 깨지게). 타이머·열쇠 규칙을 붙일 때 켜 주세요. 인형 더미는 집게 기계만 채웁니다.
- 9 × 7.5m, 지붕 없음, 문은 +Z 벽(「허브로 나가기」 표시). 기계 세 대는 뒷벽, 왼쪽 벽 = 도감 진열장, 오른쪽 벽 = 「오늘의 코인」 받는 곳(사는 단추 없음)·의자·희귀도 안내판, 가운데 = 큰 동동이 인형(약 1m).
- `userData`
  - `machines[{id,kind,group,x,z,heading,stand}]`: 가게 좌표.
  - `colliders`: 네모 `{x0,z0,x1,z1}`·동그라미 `{x,z,r}`. 걷기 범위는 `SHOP.walk`.
  - `spots`: spawn·door·kiosk·bench(앉는 높이 0.44)·showcase·statue.
  - `fadeWalls(camera)`: 카메라가 벽 밖이면 그 벽과 벽에 붙은 간판·전구를 숨김. 매 프레임 부르세요.
  - `showcase.set(ids)`: 모은 인형은 색, 못 모은 인형은 회색 실루엣.
  - `update(dt)`: 기계 불빛.
- 빛: `SHOP_LIGHT`(반구광 + 그림자 빛 하나, 점광원 없음). 미리보기와 같은 값입니다.

## 6. 치이카와(손님 인형) 자리 — 공개판에서 빠지는 구조
- 공개 코드에는 이름·그림·모델이 없습니다. 자리 id(`guest-1` 특별 · `guest-2` 희귀)와 대체 인형(`fallback`: 해치·산고양이)만 있습니다.
- 실제 자료는 저장소 밖 **`private/claw/`**(`.gitignore`)에 둡니다. 파일 약속: `private/claw/guest-1.js`
  ```js
  export default {id:'guest-1', name:'(실제 이름)', model:new URL('./guest-1.glb',import.meta.url).href /* 또는 image: 배경 투명 PNG */, icon:'(도감 그림, 없으면 image)'}
  ```
- 개발 서버를 `VITE_CLAW_PRIVATE=1 npm run dev`로 켰을 때만 읽습니다. 연결 순서:
  1. `const guests=await loadGuests()`
  2. 손님 인형마다 `proto=await makeGuestPlush(id,guests,{toonify})`를 미리 만들어 둡니다.
  3. `buildClawShop({guests, guestObject:id=>proto.clone(true)})`
  4. 도감은 `clawCatalog(guests)`로 만듭니다(공개판 8칸, 손님이 있으면 칸이 늘어남).
  5. 기계 목록은 `resolvePool(pool,guests)`로 만듭니다(없으면 대체 인형).
- 이 값이 없으면(공개 빌드) 비공개 파일 읽기 코드가 빌드에서 통째로 빠집니다. 확인: `npm run build` 뒤 `node scripts/check-claw-private.mjs`(배포 전 한 번).
- 확인함: 시험용 가짜 손님 파일(우리 아이콘 그림)을 넣고 두 번 빌드했습니다. 설정 없는 빌드는 통과(섞인 것 없음)했고, 설정 켠 빌드는 검사가 잡아냈습니다. 개발 화면에서 손님 인형이 도감 줄·별빛 기계 더미에 나오는 것도 봤습니다. 시험 파일은 치웠습니다.

## 7. 무게(휴대폰)
- 인형 한 종 1.7~5.0천 삼각형(꼭짓점 색, 텍스처 없음). 한 종 = 그리기 1번 + 외곽선 1번이고, 몇 개를 쌓아도 같습니다. 더미 인형은 그림자를 만들지 않습니다.
- 텍스처는 캔버스 글자판뿐입니다(기계 간판 3장, 가게 간판·안내판 6장, 합계 약 1MB 아래).
- 미리보기 측정(동동이 1명 포함, 후처리 모든 단계 합계)
  - 휴대폰 세로 가게 전체: 그리기 275번, 삼각형 32만
  - 휴대폰 조작 화면: 그리기 169번, 삼각형 16만
  - 만드는 시간 약 0.15초
  - `mobile:true`면 더미 인형이 기계마다 9개(PC 14개)입니다.
