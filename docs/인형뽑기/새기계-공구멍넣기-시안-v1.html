새 기계 ③ 공 구멍 넣기 「공 떨어뜨리기」 추천안 · 대표 미확인

집게가 든 탁구공을 구멍 판 위에서 놓습니다. 공이 몇 번 튀고 굴러 노란·보라 구멍에 들어가면 그 인형을 받습니다. 조작은 집게 기계와 같습니다. 왼쪽 휴대폰 화면의 십자 단추(또는 방향키)와 「떨어뜨리기」(또는 Space)로 해 볼 수 있습니다. 규칙서: docs/인형뽑기/새기계3종-규칙서-v1.md §3

한 판 흐름

  1. 기계 앞 할 일 칩 「🏓 공 떨어뜨리기 한 판 · 🪙1」(처음이면 규칙 카드)
  2. 준비 0.8초 「공을 집었어요」 — 공은 처음부터 집게에(공 집기 단계 없음)
  3. 십자 단추를 누르고 있으면 집게가 움직임(15초, ⏱). 판 위 그림자 점 = 떨어질 자리
  4. 「🏓 떨어뜨리기」(15초가 지나면 저절로) → 공이 튀고 굴러 구멍 하나에 들어감(2~3초, 입력 잠금)
  5. 들어간 구멍에 동그라미(초록 성공·주황 아까움·빨강 실패) → 결과 카드

판 4×4 = 16구멍(간격 6cm). 노랑 2 = 보통 인형, 보라 1 = 희귀(가장자리·작은 구멍). 구멍 옆 그림 = 그 구멍 인형(보이는 경품 = 받는 경품).

공이 떨어진 뒤 2~3초가 이 기계의 볼거리라 결과 카드는 공이 멈추고 0.5초(성공 1.1초) 뒤에.

연속 실패 도움

5판 연달아 못 넣으면 다음 판부터(넣을 때까지) 직원이 초록 「도움 구멍」을 하나 더 열어 줍니다(가운데 쪽, 보통 인형). 판 위 글·시작 알림·결과 카드 「직원 도움까지 n번」.

이유: 조사 초안 「6판 뒤 색 구멍 추가」를 집게(5판 직원 도움)와 같은 횟수로. 판 그림이 바뀌어 눈에 보이는 도움. 어림 판당 21% → 도움 판 약 30%(추정).

구경하는 손님 화면 왼쪽에서 한 판 하면 0.15초 늦게 따라 그림

  • 다른 손님은 집게가 움직이는 것 → 공이 튀는 2~3초 → 들어간 구멍 동그라미를 봄(가장 볼 만한 장면)
  • act: 조작 중 cx·cz 집게 자리(집게 기계와 같은 cm+50, 움직일 때만 초당 8번) · 공이 멈추면 v 들어간 구멍(0~15) + k 결과
  • 튐 길은 받는 쪽이 받은 구멍에서 끝나게 새로 만들어 그림(기존 「결과만 받아 다시 그림」 방식, 물리 상태를 보내지 않음)
  • 공 위치를 실시간으로 보내지 않으므로 구경 화면의 튐 모양은 뽑는 사람과 조금 다를 수 있음(결과 구멍은 같음)

받은 act:

기존 4종·조사 초안과 다르게 한 곳 · 이유

  • 공 집기 단계 없음 — 초안은 공 통에서 집게로 공을 집음. 실패해도 재미없는 단계라 빼고 「놓는 자리」에 집중.
  • 👁 옆에서 보기 없음 — 판을 위에서 내려다보는 카메라 + 그림자 점으로 앞뒤가 보임.
  • 한 줄 안내를 위 칩에 합침 — 휴대폰 세로에서 십자 판(위 끝 약 598px)과 안내 자리가 겹침.
  • 경품 = 작은 인형만(큰 인형 없음) — 초안 「가장자리 작은 구멍 = 큰 인형」 대신 희귀 작은 인형. 큰 인형은 타이머·줄 자르기 몫으로 나눔(기계마다 경품 성격이 겹치지 않게).
  • 판이 기울거나 도는 어려움 → 이번엔 없음 — 같은 종류 기계를 더 둘 때 단계별 어려움으로 남김.
