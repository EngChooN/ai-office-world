## 0. 세 기계 공통(기존 4종 그대로 쓰는 것)
| 항목 | 규칙 |
|---|---|
| 흐름 | 기계 앞 할 일 칩 「<기계> 한 판 · 🪙1」·「ⓘ 규칙」 → 그 기계 첫 판만 규칙 카드(「시작하기」를 눌러야 코인 씀) → 조작 → 판정 연출(입력 잠금) → 결과 카드 「들고 다니기 / 🧸 도감 / 🪙 한 판 더 · 1 / 그만」 |
| 코인 | 한 판 1개, 하루 30개 무료 그대로. 판 도중 코인을 더 쓰거나 경품을 거는 단계 없음 |
| 조작 단추 | 아래 가운데 판(`.kh-bar`, 손가락 기기 화면 폭·높이 80 / PC 520 + 「스페이스」). 누름은 `pointerdown`의 `event.timeStamp`로 판정(그리기 틈과 무관). 누르고 있기는 `setPointerCapture`, `pointerup·pointercancel·lostpointercapture`면 바로 뗀 것 |
| 위 | 왼쪽 알약 「<기계 이름> · 🪙 n」, 오른쪽 ✕(그만두기 확인 「넣은 코인은 돌려받지 못해요」), 💬·☰ 숨김. 가운데 칩은 타이머 숫자 칩(`.kh-tnum`) 자리 |
| 결과 카드 | 성공(띠 색 = 등급) / 아까움 / 실패. **빗나간 양을 숫자로**(칸·mm·구멍) — 타이머 「+0.03초」, 열쇠 「오른쪽에 꽂혔어요」와 같은 생각. 실패 카드에 「직원 도움까지 n번」 |
| 연속 실패 도움 | 이름은 모두 「직원 도움」(집게·봉과 같음). **눈에 보이는 도움만**, 받을 때까지 판마다, 받으면 0 |
| 구경 | 다른 손님은 기계 그림만 봄(내 HUD·카드 안 보임). act는 결과·멈춘 자리만, 받는 쪽이 같은 결과로 다시 그림. 가게 알림은 기존처럼 희귀 이상만 10초에 1번 |
| 소리 | 직접 합성(`claw-audio.js` 효과음 구조·음소거·크기 그대로), 다른 손님 기계는 거리만큼(9m 밖 0) |
| 도감·저장 | 새 인형 없음 = 도감 33칸 그대로. 새 기계 id(추천 `stack-1`·`string-1`·`ball-1`)를 `MACHINES`에 더하면 보장 수(`state.pity`)·처음 규칙(`state.seen`)이 그대로 따라옴. 판 사이에 남는 기계 상태 없음(봉과 달리 `state.mach` 안 씀) |

**서버·공용에 닿는 것(월드공통개발 확인):** act 기계 번호 `m`은 지금 0~16(`multi-protocol.js` `ACT_SCHEMA.claw.m`). 새 기계는 17~19가 필요 → 화면 쪽 표를 늘리면 되지만, **공개 서버를 다시 켜기 전에는 다른 손님에게 새 기계 구경이 안 보임**(혼자 뽑기·내 화면은 됨). 공개 서버는 대표 확인 전 건드리지 않음 — 다시 켜기는 작업량만 보고. 새 칸은 만들지 않고 지금 칸(`ph·cx·cz·v·k·r·n`)에 뜻만 정함(아래 기계별 표).

**자리:** 지금 가게 빈 자리는 2곳(설계 v4.1). 새 기계는 3대라 한 자리가 모자람 → 월드아트·월드기획이 정할 일(추천: 기계 하나씩, 빈 자리 2곳 + 가게 가장자리 장식 자리 1곳).

## 1. 불빛 쌓기 「별빛 탑」 (`kind:'stack'`)
**한 줄:** 버튼 하나로 좌우로 오가는 빛 막대를 멈춰 쌓기. 7줄 = 작은 인형, 11줄 = 큰 인형.
- **판:** 7칸 × 11줄. 시작 막대 3칸, 1줄은 아무 데나. 홀수 줄은 왼쪽에서, 짝수 줄은 오른쪽에서 출발해 벽에서 되돌아감.
- **멈춤:** 「✋ 멈춤」 누른 순간의 칸 자리. 아래 줄과 어긋난 칸은 빨갛게 떨어지고, 남은 칸 수로 다음 줄. 0칸이면 끝.
- **빠르기(한 칸 머무는 ms):** 140·125·110·100·90·80·75·75·75·75·75(줄 1~11). 7줄부터 같은 빠르기.
- **7줄:** 작은 인형이 바로 나옴(도감 등록, 보장 수 0) → 카드 「▲ 계속하기 / 여기서 끝」, 20초 안 고르면 끝. **계속해도 코인 0·작은 인형 안 잃음**(기획서 원칙: 경품을 걸지 않음). 11줄이면 큰 인형도 받음(한 판 최대 2개).
- **무입력:** 10초면 그 자리에서 저절로 멈춤.
- **화면:** 판 단추 「✋ 멈춤」(1줄은 「첫 줄은 아무 데서나」), 위 칩 「⭐ 4 / 11줄 · 7줄 🐿️ · 11줄 ⛄」, 한 줄 안내(8줄부터 「빨라요!」), 기계 판 오른쪽에 경품 그림. 줄마다 어긋나면 알림 「6줄 1칸 빨랐어요」 1.2초.
- **결과:** 11줄 「꼭대기까지! <큰 인형>」 / 7줄에서 끝 「<작은 인형>를 받았어요」 / 계속하다 끝 「<작은 인형>는 받았어요 · 9줄까지」(10줄이면 「아까워요! 1줄」) / 6줄 = 아까움 / 그 밖 = 실패 + 「5줄에서 2칸 늦었어요」(멈출 때 움직이던 방향으로 늦음·빠름).
- **직원 도움:** 경품 없이 5판 연달아 → 시작 칸 4칸(판 위 「직원 도움 · 4칸 시작」).
- **구경 act:** 줄을 멈출 때마다 한 번 — `v` 쌓은 줄 수 · `cx` 그 줄 왼쪽 칸(0~6) · `cz` 칸 수 · 7줄 고르는 동안 `ph:'drop'`(머리 위 「고르는 중…」) · 끝 `ph:'win'|'lose'` + `k` + `r`. 움직이는 줄은 받는 쪽이 같은 빠르기로 혼자 움직임.
- **기존과 다른 점:** 👁 옆에서 보기·⏱ 없음(평평한 판, 판 전체 시간 제한 없음). 결과 카드가 두 번(7줄 카드는 「받았다」를 먼저 알리려고).
- **초안과 다른 점:** 연속 실패 도움 = 「첫 세 줄 느리게」 대신 「시작 4칸」(빠르기 차이는 눈에 안 보여 몰래 바꾸는 것처럼 느껴질 수 있음). 높은 단계 기계 「시작 2칸」은 같은 종류 기계를 더 둘 때로 남김.
- **소리:** 칸 이동 틱(줄이 오를수록 음 높아짐)·멈춤 「딱」·떨어짐 「뿅↓」·7줄 「띠링」·11줄 팡파레.
- **조절값 제안:** `stack:{cols:7,rows:11,mid:7,width:3,pityWidth:4,pityAfter:5,stepsMs:[140,125,110,100,90,80,75,75,75,75,75],idleSec:10,readySec:.8,choiceSec:20}`

## 2. 줄 자르기 「가위로 툭」 (`kind:'string'`)
**한 줄:** 가위를 줄 앞으로 옮기고, 흔들리는 줄이 칼날 가운데를 지나는 순간 싹둑 → 큰 인형이 툭.
- **기계:** 안 폭 0.60m, 줄 2개(0.22·0.42m, 줄마다 큰 인형 하나 = 노릴 줄이 곧 인형 고르기). 줄 흔들림 자르는 높이에서 진폭 5cm(판마다·흔들림마다 ±15%)·주기 1.4초, 두 줄 위상 다름.
- **① 「→ 오른쪽」 누르고 있기:** 가위가 초당 15cm, 떼면 고정(되돌리기 없음, 열쇠 ①과 같은 손). 0.3초 「잠깐」.
- **② 「✂️ 싹둑」 한 번 누르기:** 누른 순간 가위가 닫힘. 그 순간 가장 가까운 줄과 칼날 가운데 차이로 판정: ±3mm 성공(줄 끊김·인형 낙하) / ±6mm 아까움(반쯤 잘린 자국, 다음 판은 새 줄) / 그 밖 실패(허공).
- **카메라:** ②에서 가위 쪽으로 2.2배 다가감(전체 화면이면 6mm 칼날이 3px). 칼날에 노란 괄호 = 판정 폭(그림 = 판정), ①에선 아래로 점선.
- **무입력:** ① 20초 안 누르면 그 자리로 ② · 누른 채 10초 또는 끝 도착 = 뗀 것 · ② 10초 = 저절로 싹둑.
- **화면:** 판 단추 ① 빨강 「→ 오른쪽」 → ② **주황** 「✂️ 싹둑」(누르는 뜻이 바뀐 걸 색으로), 위 칩 「① 가위 옮기기」/「② 줄이 칼날 가운데일 때 싹둑!」.
- **결과:** 성공 「싹둑! <큰 인형>」 · 🎒 업고 다니기 / 아까움 「아까워요! 줄이 반쯤 잘렸어요」 + 「4mm 왼쪽」 / 실패 「허공을 잘랐어요」 + 「1.8cm 오른쪽」.
- **직원 도움:** 8판 연달아 실패 → 직원이 줄을 잡아 흔들림 멈춤(줄 위 초록 「직원」 집게). 가위 자리는 맞춰야 해서 자동 성공 아님.
- **구경 act:** 뗄 때 `cx` 가위 자리(mm) · 자를 때 `ph:'drop'` + `cz` 자른 줄(1·2) + `v` 줄−칼날 차이(mm+100) + `k` + `r`. 받는 쪽은 줄을 혼자 흔들다가 자른 순간 받은 차이대로 줄을 맞춰 그림(열쇠 구경의 「구멍으로 미끄러짐」과 같은 방법).
- **기존과 다른 점:** 👁·⏱ 없음(판정이 좌우 하나), ② 판 주황색, 카메라 다가감.
- **초안과 다른 점:** ② 「앞으로 밀어 넣기」 → 「자르는 순간」(두 방향 맞추기는 열쇠와 똑같아져서, 「자리 + 때」로). 「여러 줄 중 경품 줄만 진짜」 → 뺌(숨은 속임수 = 「보이는 규칙 = 판정 규칙」 원칙 위반). 도움 「칼날 폭 넓힘」 → 「흔들림 멈춤」(눈에 보이는 도움).
- **소리:** 가위 수레 「드르르」(누르는 동안)·멈춤 「착」·싹둑 「찰칵」·줄 끊김 「툭」 + 인형 떨어짐 「쿵」·아까움 「사각」.
- **조절값 제안:** `string:{inner:.60,strings:[.22,.42],start:.04,end:.56,speed:.15,ampM:.05,ampVar:.15,periodSec:1.4,cutHalfM:.003,nearMul:2,holdLimitSec:10,readySec:20,cutLimitSec:10,gapSec:.3,pityAfter:8,zoom:2.2}`

## 3. 공 구멍 넣기 「공 떨어뜨리기」 (`kind:'ball'`)
**한 줄:** 집게가 든 탁구공을 구멍 판 위에서 놓아 색 구멍에 넣기. 공이 튀는 2~3초가 구경거리.
- **판:** 4×4 = 16구멍, 간격 6cm. 노랑 2 = 보통 인형(구멍마다 정해진 인형, 구멍 옆 그림), 보라 1 = 희귀(가장자리·작은 구멍 — 칸 안쪽 60%에 떨어져야 들어가고 아니면 위를 굴러 지나감). 나머지는 빈 구멍. 공은 반드시 구멍 하나에 멈춤(평평한 판 + 벽 되튐).
- **조작:** **집게 기계와 같음** — 공은 처음부터 집게에(준비 0.8초), 십자 판 누르고 있기(초당 9cm, 15초 ⏱), 오른쪽 세로 큰 판 「🏓 떨어뜨리기」, 15초면 저절로 놓음. 판 위 **그림자 점** = 떨어질 자리.
- **카메라:** 판을 위에서 약 55° 내려다봄(앞뒤가 보여 👁 필요 없음).
- **판정:** 공이 멈춘 구멍. 색 구멍 = 성공 / 색 구멍 가로·세로 바로 옆 칸 또는 보라 구멍 위를 굴러 지나감 = 아까움 / 그 밖 = 실패. 들어간 구멍에 동그라미(초록·주황·빨강).
- **화면:** 위 칩 「⏱ 12초 · 그림자 점을 노란 구멍 위로」(한 줄 안내를 칩에 합침 — 세로에서 십자 판 위 끝 약 598px과 안내 자리가 겹침). 결과 카드는 공이 멈추고 0.5초(성공 1.1초) 뒤.
- **결과:** 「쏙! <인형>」 · ✋ 들고 다니기 / 「아까워요! 색 구멍 바로 옆이에요」·「작은 구멍 위를 굴러 지나갔어요」 / 「아쉬워요, 빈 구멍이에요」.
- **직원 도움:** 5판 연달아 실패 → 초록 「도움 구멍」 하나 더(가운데 쪽, 보통 인형).
- **구경 act:** 조작 중 `cx·cz` 집게 자리(집게와 같은 cm+50, 움직일 때만 초당 8번) · 놓을 때 `ph:'drop'` · 공이 멈추면 `v` 구멍 번호(j×4+i) + `k` + `r`. 받는 쪽은 **받은 구멍에서 끝나는 튐 길을 새로 만들어** 그림(공 물리 상태는 안 보냄 — 튐 모양은 조금 달라도 결과 구멍은 같음).
- **기존과 다른 점:** 👁 없음, 한 줄 안내를 칩에 합침, 경품은 작은 인형만.
- **초안과 다른 점:** 공 집기 단계 없앰(실패해도 재미없는 단계). 도움 6판 → 5판(집게와 같은 횟수). 「가장자리 작은 구멍 = 큰 인형」 → 희귀 작은 인형(큰 인형은 타이머·줄 자르기 몫). 판 기울기·회전은 같은 종류 기계를 더 둘 때 단계별 어려움으로.
- **소리:** 집게 이동 「위잉」·놓음 「딸깍」·튐 「통·통·통」(작아지며)·구르기 「도르르」·구멍 「쏙」·성공 「빰빠밤」.
- **조절값 제안:** `ball:{n:4,pitchM:.06,speed:.09,timeSec:15,readySec:.8,ballR:.013,holeR:.021,rareHoleR:.016,rareIn:.6,pityAfter:5,holes:{'1,1':…,'2,2':…,'3,0':희귀},pityHole:'1,2'}` — 튐·굴러감은 실제 공 물리로(월드공통개발), 시안의 튐은 흉내.

## 4. 난이도 비교(모두 추정 — 사람 손 모델 σ60ms, 열쇠 시험 `key-rate.mjs`와 같은 방식)
