# 온라인 인형뽑기 — 「다리 걸치기(橋渡し)」 기계 조사 (월드리서치, 2026-11-23)

요청: 대표 → 월드기획 → 월드리서치. 받는 사람: 월드디자인(화면·조작 설계), 월드기획.
범위: 일본 크레인 게임의 「막대 두 개 위 상자를 밀어 사이로 떨어뜨리는」 기계. 법적·치이카와 관련은 이번 범위 아님.
확인 시점: 2026-11-23. 표기: **[확인]** = 출처에서 직접 읽음, **[추정]** = 출처 없이 판단하거나 여러 자료를 엮어 짐작함.

## 한눈에

- 정식 이름은 따로 없고, 일본 가게·공략에서 **「橋渡し(하시와타시, 다리 건너기)」 설정**이라 부릅니다. 기계 이름이 아니라 **보통 2발 집게 기계 안에 막대 두 개를 깔아 놓은 "설정(배치)"** 입니다. [확인]
- 집게가 상자를 들어 올리지 못할 만큼 약하게 맞춰 두고, 집게 끝으로 상자를 **조금씩 밀고 비틀어** 막대 사이로 떨어뜨립니다. [확인]
- 재미는 "한 판에 끝나지 않고 판마다 조금씩 다가가는" 데 있습니다. 상자가 기울고 미끄러지는 걸 읽는 손맛이 핵심입니다. [확인 + 추정]
- 휴대폰 세로·버튼 조작으로 옮기기 **어렵지 않습니다**. 실제 기계도 버튼 2개(옆 → 안쪽)입니다. 다만 **"이번 판으로 상자가 얼마나 움직였는지"가 잘 보여야** 하고, 그러려면 물리 계산이 꽤 정확해야 합니다(추정). → 우리 기존 「집게 물리」 기계의 확장으로 만드는 것이 자연스럽습니다(제안).

## ① 이름과 종류

| 이름 | 뜻 | 근거 |
|---|---|---|
| **橋渡し(はしわたし)** | 막대(봉) 2개 이상 위에 경품 상자를 걸쳐 둔 배치. 상자를 밀어 막대 사이로 떨어뜨림 | [확인] DIME 인터뷰 "“橋渡し”と呼ばれる2本以上の棒の上に景品が乗っている台", gamepedia "2本の棒の上に景品が置かれ、アームを使い箱をずらしながら落下させるクレーン" |
| 橋渡し台 / 橋渡し設定 | 같은 뜻. "台(기계)", "設定(배치)"를 붙여 부름 | [확인] gamepedia·DIME 표기 |
| 영어권 | "bridge setup", "box on two bars" | [확인] Goombastomp·Tokyo Cheapo 등 여행·체험 글 |
| "2本橋", "ブリッジ" | 지시서의 후보 이름. **이번 자료에서는 쓰는 예를 못 찾음** | — |

- 기계 자체는 세가 UFO캐처, 반다이남코 클레나 같은 **일반 2발 집게 기계**입니다. 가게가 안에 막대를 깔아 "다리 걸치기 설정"으로 만듭니다. [확인: DIME "2本アームのクレーンを前提", 기종 이름(클레나 등) 언급] / [추정: 막대는 가게가 바꿔 끼우는 부품]
- 막대가 한쪽은 좁고 다른 쪽은 넓게 벌어지는("八の字", 팔(八) 자) 배치도 있습니다. 넓은 쪽으로 상자를 옮길수록 떨어지기 쉽습니다. [확인: Goombastomp "bars come together at one end… gradually splitting", gamepedia "八の字を意識して"]
- 막대에 경사가 있으면 더 어렵고, 막대 폭이 넓을수록 쉽다는 것이 공략의 공통 기준입니다. [확인: gamepedia "景品を支える棒に傾斜", DIME "橋の幅が広いかどうかも見極めポイント"]

## ② 조작 방식

| 항목 | 내용 | 근거 |
|---|---|---|
| 버튼 수 | 일본 기계 대부분 **버튼 2개**: ① 옆(가로)으로 이동 ② 안쪽(세로)으로 이동. 기종·설정에 따라 3~4개도 있음 | [확인] Game Watch(세가 UFO캐처 소개) "ヨコ、タテ移動の2ボタン", ja.wikid.org UFOキャッチャー "多くの機種で操作には縦横2つの押しボタン…3つや4つのボタンを使うものもある" |
| 누르는 법 | 버튼을 **누르고 있는 동안 움직이고, 떼면 멈춤**. 축마다 한 번씩만(되돌리기 없음) | [추정 + 일반 설명] 일본 위키백과 "ボタンを離した時より、クレーンは少し遅れて止まる場合がある" — "떼면 멈춤"과 "조금 늦게 멈춤"은 [확인] |
| 내려가기 | 두 축을 다 정하면 **집게가 저절로 내려가 닫히고 올라옴**. 높이는 보통 못 정함 | [확인] 일본 위키백과 "上下移動は自動で、基本的に操作はできない" |
| 집게 | **2발**. 힘이 약해 상자를 들지 못하고, 발 끝으로 밀거나 걸어 당김 | [확인] Goombastomp "claw isn't strong enough to actually lift", Tokyo Cheapo "use the hook of the claw to push and budge" |
| 흔한 실수 | 상자 한가운데를 노리면 두 발이 상자 양옆으로 빠져 **아무것도 안 건드림** | [확인] Kotaku 체험기 |
| 타이밍 | 반사 신경보다 **"어디서 멈출지" 정하는 위치 판단**이 중요 | [확인] Tokyo Catch "focus more on technique and positioning" |

## ③ 성공 조건과 재미 포인트

**성공 조건** [확인]: 상자가 막대 사이로 빠져 아래 구멍(경품 출구)에 떨어지면 성공.

**대표 기술** [확인: gamepedia 공략]
- **横ハメ(요코하메, 옆으로 끼워 떨어뜨리기)**: 상자를 막대와 나란한 방향으로 돌려, 막대 사이로 세로 길게 빠지게 함. 길쭉한 상자에 씀. 한쪽 발로 상자 앞쪽을 "아슬아슬하게" 걸어 조금씩 비틂.
- **縦ハメ(다테하메)**: 정사각형에 가까운 상자에 씀. 이름만 확인, 정확한 동작 설명은 못 찾음.
- **バランスキャッチ(균형 잡기)**: 두 발이 상자 무게중심을 잡으면 들어 올려 한 번에 끝나기도 함("運がよければ1手で").
- **突く(찌르기)·反動(반동)**: 기운 상자 모서리를 한쪽 발로 쿡 찔러 앞으로 넘어뜨리는 마무리.

**재미 포인트**
1. **판마다 조금씩 다가감** — 한 판 = 상자를 몇 cm 옮기기. 끝이 보이는 진행감. [확인: Goombastomp "slowly push the object towards the opening"] [추정: 진행감이 재도전을 부름]
2. **상자 읽기** — 무게중심·기울기·어느 모서리를 칠지 "계획 세우기"가 들어감. 집게로 "잡는" 기계와 손맛이 다름. [확인: gamepedia "重心", DIME "重心"] 
3. **마지막 한 방의 쾌감** — 기운 상자가 반동으로 쑥 빠지는 순간. [추정]
4. **구경 재미** — 남이 거의 다 옮긴 상자를 보며 "다음 판이면 될 것 같은데" 하는 긴장. 온라인 크레인(Toreba)도 줄 서서 남의 판을 지켜봄. [확인: mechanicsofmagic·BGR] [추정: 구경 재미]

**주의** [확인]: 이어 하는 사람이 그만두면 다음 사람이 그 위치를 이어받습니다("someone else can benefit off your hard work"). 진행이 쌓이는 기계라 **"누구의 상자 위치인가"가 다툼거리**가 됩니다. 우리 설계에서 정해야 할 부분입니다(⑥ 참조).

## ④ 휴대폰 세로·버튼 조작으로 옮길 때

| | 내용 |
|---|---|
| **쉬운 점** | 실제 기계가 이미 버튼 2개(옆 → 안쪽, 누르고 있다 떼기)라 그대로 옮기면 됨. 우리 집게 기계의 조작 자리·카메라를 재사용 가능 [추정]. 집게가 "들지 않고 밀기만" 하므로 판정이 "상자가 출구 안으로 들어갔나" 하나로 단순함 |
| **어려운 점** | ① **상자 움직임이 그럴듯해야 재미**: 미끄러짐·회전·기울기·반동을 물리로 계산해야 함. 가짜 같으면 "조작이 아니라 운"으로 느껴짐 [추정] ② **깊이 감각**: 세로 화면 한 시점으로는 집게가 상자 앞인지 뒤인지 판단이 어려움. 실제 기계도 옆에서 들여다봄(Toreba도 카메라 2각도) [확인: BGR "two camera angles"] → 안쪽 이동 때 옆 시점으로 바뀌는 카메라가 필요 [제안] ③ **여러 판 진행 저장**: 상자 위치를 내 기록(이어 하기)으로 남길지, 기계에 남길지 정해야 함 ④ 판마다 진척이 작으면 휴대폰에서 지루할 수 있음 → 막대 폭·집게 힘으로 "3~8판 안팎"에 끝나게 조절(숫자는 추정·임시) |
| **난이도(만들기)** | 집게 물리를 이미 쓰는 우리 기준 **중간**. 열쇠 맞추기보다 무겁고, 인형 밀어내기(여러 개 연쇄)보다 가벼움 [추정] |
| **조작 제안** | 기존 집게 기계와 같게: ◀▶ 누르고 있다 떼기 → ▲(안쪽) 누르고 있다 떼기 → 저절로 내려가 밀기. 안쪽 이동 동안 옆 시점 작은 창(또는 카메라 전환). 결과 뒤 "상자가 이만큼 움직였어요" 화살표·잔상 [제안] |
| **공정성** | 화면에 보이는 물리대로만 판정. 몰래 힘을 바꾸지 않음(지난 조사의 Key Master 소송 사례와 같은 이유) [제안] |

## ⑥ 같은 기계 여러 대 두기와 대기 문제

**실제 가게** 
- 한 가게에 기계가 매우 많습니다. 세계 최다 기록은 요코하마 「サープラ横浜あそびタウン」 555대(2022), 그전 기록 「エブリデイ行田店」 약 350대(2012). 구역별로 나눠 배치합니다. [확인: Guinness, 일본 위키백과]
- 처음부터 **한 기계에 두 사람 자리**가 있는 기종도 있습니다. 세가 첫 UFO캐처(1985)는 "2人同時プレイ" 가능. [확인: Game Watch] 
- "인기 경품을 같은 설정으로 여러 대 두는가"를 수치로 밝힌 자료는 **못 찾았습니다**. 일본 가게에서 같은 경품이 여러 대에 들어간 모습은 흔하다고 알려져 있으나 근거 자료 없음 [추정].
- 큰 메달 밀어내기 기계는 **한 판 위에 자리 10~20개**를 붙여 여럿이 동시에 합니다(코나미 FORTUNE TRINITY 시리즈 최대 20인). [확인: 코나미 공식] → "한 기계 = 한 사람"이 아닌 실제 예.

**온라인 크레인(실제 기계 원격 조작)**
- Toreba: 기계를 **예약하고, 앞사람이 있으면 순번 대기**. 대기 중에는 앞사람의 판을 실시간으로 구경. [확인: Toreba 공식 안내, mechanicsofmagic]
- 한 사람이 계속 이어 하면 오래 기다림, 그만두면 다음 사람이 상자 위치를 이어받음. [확인: mechanicsofmagic] 
- 차례 제한 시간·대기 인원 표시 규칙은 **확인 못 함**(FAQ가 자동 접속으로 안 열림).

**게임 설계 일반 사례(대기 줄이기)** [확인: 개발자 글·포럼, 근거 약함]
- 기다리는 동안 남의 판 구경 / 혼자 하는 작은 놀이 제공(gamedeveloper.com).
- 줄을 하나로 세우기보다 **사본(인스턴스)을 더 열기**(Guild Wars 2 포럼 의견).
- 구경꾼에게 순서 우선권을 주면 불공정 시비 → 줄 순서는 공정하게.

**우리 게임에 대한 제안 (대표 미확인)**
1. **기계는 화면에 1대, 상자는 사람마다 따로** [제안·추천]: 온라인 게임은 실제 상자가 없으므로, 같은 기계 앞에 여럿이 와도 각자 자기 상자로 동시에 할 수 있음. 남의 판은 반투명 집게·결과만 보여 구경 재미를 살림. 대기 0.
2. 같은 기계 2~3대를 나란히 [대안]: 실제 가게 느낌은 좋지만 손님이 늘면 또 대기.
3. 실제처럼 순번 대기 + 구경 [비추천]: 이어받기 다툼·대기 문제가 그대로 생김.
→ 기존 설계(화면-조작-설계-v1 §6, "같은 기계에 동시에 들어가지 않게 막음")와 다르므로 **월드디자인·월드기획 확인 필요**. 상자 진행을 사람별로 저장하면 서버에 남는 값이 생기는지는 월드개발 확인 필요.
