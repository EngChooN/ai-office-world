## 2. 모습(시안 그대로 + 다듬은 점)

- **손(작은 인형 8종·상자 피규어 8종):** 왼쪽 옆구리, 인형 바닥은 엉덩이 뼈 아래 6.5cm(서 있을 때 약 0.165m), 몸통 바깥 0.15m + 인형 폭의 1/3. 왼팔은 원래 걷기 흔들림 대신 인형 윗면을 감쌈(두 관절 IK, 흡연장 `POSE_TOOLS.limb`). 오른팔·다리는 원래 걸음 그대로. 상자 피규어는 봉 기계 경품 그림(`makeBoxPrize`)을 긴 쪽이 위로 세워 듦.
- **등(큰 인형 3종):** 등뼈(Spine2) 뒤 0.17m, 얼굴이 뒤를 봄, 10° 뒤로 기댐. 어깨끈 두 줄 + 가슴끈(크림 `#e8d9b0`). 배낭(`pack:true`, 등산)이면 배낭 바깥면 0.30m 뒤에 매달고 배낭 띠(청록)로 감음, 어깨끈 없음. 큰 인형 꼭대기는 머리뼈보다 약 0.11m 위까지(머리 아래 부분), 게임 카메라에서 머리를 가리지 않음.
- **앉기:** 동동이는 다리가 짧아 무릎이 배 안쪽이라 「무릎 위」 = 배 앞(엉덩이 뼈 앞 0.15m + 인형 높이 30%)에 앞을 보게 앉힘. 등 인형은 숨김.
- **걷기·뛰기:** 인형은 뼈를 따라 들썩이고, 몸 기울기의 절반만 따름(몸 뚫림 방지) + 걸음마다 좌우로 살짝 흔들림.
- **빛:** 희귀 = 보라(인형 높이 2.2배, 2초에 한 번 숨쉬기), 특별 = 금빛(2.5배) + 반짝이 5개(초당 0.45번 깜빡). 흔함·보통 없음, 큰 인형은 원래 등급(큰 해치 = 보라). 진짜 조명이 아니라 그림 한 장(Sprite). 낮은 밤의 1.5배.
- **시안과 다르게 한 곳(촬영으로 찾음):**
  1. 빛을 더하기 섞기로 하면 밝은 낮 배경에서 하얗게 날아가 보라가 안 보임 → 둘레 빛은 보통 섞기(반짝이만 더하기).
  2. 시안처럼 빛을 인형 뒤 0.55배로 밀면 몸에 가려 낮에 거의 안 보임 → 0.3배.
  3. 카메라가 인형 쪽(손 인형은 왼옆)에서 보면 빛이 몸 전체를 보라로 물들임 → 그 방향일수록 빛을 줄임(손 최대 70%, 등은 게임 카메라가 늘 뒤라 25%만).
  4. 희귀 보라 세기를 시안보다 올림(0.55 → 0.72). 낮 앞모습·게임 카메라에서 보라가 보이는 것까지 확인.

## 3. 연결 방법(월드개발)

```js
import {createCarryArt,carrySlotOf} from '../carry/carry-art.js';
const carry=createCarryArt(hiker,{toonify:toon.toonify,pack:true /*등산만*/});
carry.set({hand:'haechi',back:'big-haechi'});   // null = 내려놓기. 자리가 틀리면 throw(carrySlotOf로 먼저 나눔)
// 매 프레임: hiker.update → hiker.ground → (인형가게 poser) → 
carry.update(dt,{camera,daylight,moving,phase,seated,hideHand,hideBack,far});
```

- `daylight` 0(밤)~1(낮): 각 콘텐츠 시간대 값을 넘김(낮 빛 1.5배).
- `moving`·`phase`: `hiker.ground`에 준 값 그대로.
- `seated`: `hiker.interaction.sit`(0~1). 흡연장·크리스마스처럼 자체 앉기 자세(poser)면 앉은 동안 1.
- `hideHand`: 쌍안경·휴대폰·차(등산), 담배·캔(흡연장), 코코아·눈덩이·스케이트(크리스마스), 기계 앞 조작(인형가게). `hideBack`: 썰매·회전목마·케이블카·하늘 썰매·버스. 숨겼다 다시 보이면 0.2초 커지며 나타남.
- `far`: 휴대폰 먼 사람(인형 모형 숨기고 빛만). 거리는 기기 상한에 맞춰 정해 주세요.
- 1인칭: 내 캐릭터를 숨기는 기존 방식(루트 숨김)이면 인형도 같이 숨음.
- 인형가게 옷(`claw-avatar.js`)·흡연장(`lounge/avatar.js`)은 스틱이 이미 숨겨져 있음. 등산은 손에 들면 왼쪽 스틱을 숨기고(`hidePole`, 기본 켬) 내려놓으면 되돌림.
- 다른 사람 몸에도 같은 함수(사람마다 하나). 지울 때 `dispose()`.

## 6. 11-25 손 인형 자세 바꿈 — 어깨 높이로 받쳐 들기 (월드기획 지시, 대표 결정 ③)

### 바뀐 모습
- **손(작은 인형 8종·상자 피규어 8종):** 오른 팔꿈치를 굽혀 손 위에 인형을 얹고 얼굴 오른쪽 옆·머리 바깥에 둠. 손 자리 = 지금 오른 어깨 뼈 + 바깥 0.25·위 0.03·앞 0.10m, 인형 바닥 = 손 + 바깥 0.02·위 0.012m. 인형은 앞을 보고 바깥으로 20° 돎. 걸음마다 앞뒤로 살짝 끄덕(0.06rad) + 좌우 흔들림(전과 같음). 시안 `artifacts/carry-pose/pose.js` `side2` 값 그대로.
- **왼팔:** 이제 덧씌우지 않음(원래 걷기·뛰기 흔들림 그대로). 오른팔만 두 관절 IK(`POSE_TOOLS.limb`), 팔꿈치는 바깥·아래·뒤.
- **상자 피규어:** 전에는 눕힌 상자를 옆으로 세워 안의 인형이 옆으로 누워 보였음 → 세운 진열 상자(폭 0.16·높이 0.22·깊이 0.10m)로 그려 **창과 안의 인형이 앞을 봄**. 봉 기계 안 경품 상자(눕힌 0.22×0.10×0.16)는 그대로, 들 때만 세운 치수(`CARRY_ART.hand.box`).
- **앉기(땅·벤치):** 옛 「배 앞에 올려 두기」를 없애고 서 있을 때와 같은 받쳐 들기. 어깨를 따라가므로 앉아도 손 위·얼굴 옆(벤치 0.42m 촬영 확인). 등 인형은 앉으면 숨김(그대로).
- **등산 스틱:** 손에 들면 **오른쪽** 스틱을 숨김(전에는 왼쪽). 인형가게 옷은 스틱이 원래 없음.
- **그대로:** 등에 업는 큰 인형 3종·끈·배낭, 빛(보라·금) 값 전부(`CARRY_ART.glow`, 가게 세기 `shop` 1), 빛을 카메라 반대쪽으로 미는 방식(인형 자리가 바뀌어도 자동으로 따라감).

### 연결(월드공통개발) — 고칠 코드 없음
- 함수·인자·돌려주는 값이 모두 같음: `createCarryArt`·`set`·`update(dt,{camera,daylight,moving,phase,seated,hideHand,hideBack,far})`·`bounds`·`carrySlotOf`·`glowTierOf`. `carry-attach.js`·`claw-avatar.js`·`claw-multi.js`는 손대지 않아도 새 자세가 나옴(아래 실제 가게 촬영 확인).
- `CARRY_ART`에서 없어진 값: `hand.side·sideK·drop·front`, `hug`, `lap`(다른 파일에서 쓰는 곳 없음 확인). 새 값: `hand.reach·seat·yaw·elbow·nod·box`.
- 오른손을 씀: 인형가게는 뽑는 동안 `hideHand`로 숨기므로 겹치지 않음. 나중에 오른손 동작(컵·담배 등)이 있는 콘텐츠로 넓히면 그 동작 동안 `hideHand`를 켜 주세요.
