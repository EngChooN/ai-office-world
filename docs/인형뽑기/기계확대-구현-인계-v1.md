## 2. 손맛(물리) 확인 — 추정
- 새 상자를 「모서리를 대충 노리는」 무작위 시험 사람(실제 사람 아님)으로 20번씩: 나란히 13cm 평균 약 7.5판, 八자 11→15cm 약 8.9판, 나란히 11.5cm 약 12판(25판 안에 못 뗀 막힘 포함). 목표 「새 상자 4~6판」보다 조금 어렵게 나옵니다. 사람은 넓은 쪽·모서리를 노리므로 더 빠를 것(추정). 10명 시험 전에는 조절값(`CLAW_TUNING.bridge`)을 바꾸지 않았습니다.
- 집게로 상자 가운데를 눌러도 3cm 넘게 뜨지 않음(들지 못함)을 시험으로 확인.

## 3. 그림(월드아트에 요청한 것 — 지금은 월드개발 임시 그림)
- 봉 기계 몸: 지금은 집게 기계 몸을 분홍으로 쓰고 손가락 2개만 좌우로 보이게 함(`claw-bridge.js`). 정식 2발 집게 모양·봉 받침·경품 구멍·간판 글리프(지금은 3발 집게 그림)는 월드아트.
- 상자 피규어 8종: 지금은 상자 + 희귀도 띠 + 위 투명 창 안 작은 인형(`makeBoxPrize`). 그림 크기 = 판정 크기(`bridge.box` 0.16×0.10×0.22m)는 지켜야 함.
- 번호판·간판 한 장 모으기, 먼 기계 가벼운 그림, 아슬아슬 별 ✦ 불빛, 「정리 중」 불. 반환 꼴: `buildBridgeMachine` userData `{kind:'bridge',geom,setBox(id),placeBox(frame),showGhost(before,after),claw(2발: fingers[0]=+x·[1]=−x),update}`.

> **11-23 월드아트 v1.7:** 위 그림은 정식 그림으로 바뀌었습니다(봉 기계 몸·2발 집게·상자 피규어 8종·간판 한 장·불·별·정리 중·기계 단계 그림). 반환 꼴은 그대로, 내용·그리기 수는 `그림-에셋-인계-v1.md` §13.

## 4. 3단계(서버 공유)에 붙일 자리
| 할 일 | 붙일 곳 |
|---|---|
| 자리 요청 `mt`→`mo`/`mn`, 코인은 허락 뒤 | `main.js` `startPlay(i)`: 지금 `play.busy(i)`(받은 act로만 판단) 검사 자리를 서버 답 기다리기로. 거절이면 지금 「옆 빈 ○○로」 칩을 그대로 씀 |
| 판 끝 상태 보내기 `me` | `claw-play.js` `onEvent('mach',{machine,st})` — 지금은 이 기기 저장만. `st.st` = `boxState()`(공 20개 × xyz mm = 60 정수, 약 60~200바이트) |
| 받은 상태로 놓기 `ms`·`ma` | 봉: `rig.bsim.setBox(st)`(멈춘 채 0.4초 굳힘). 판 도중 받으면 끝난 뒤 적용. 집게 더미 공유는 `claw-physics.js`에 점 자리 놓기 함수가 아직 없음(v4.1 §4-1 주의) |
| 서버 검사(§6-2) | `claw-bridge-physics.js` `bridgeSnap`·`noProgress`·`outOfReach`·`support`·`tilt`를 서버에서 같이 씀(three 없음). 이동 한도 `share.maxMoveM`·`maxTurnDeg` |
