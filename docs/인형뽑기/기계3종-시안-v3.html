1. 화면 흐름 — 공통 한 판 흐름 + 기계별 규칙 칸

허브 카드온라인 인형뽑기→ A 가게 걷기조이스틱 · 큰 단추 = 달리기→ B 기계 고르기걸어가서 2m 안 / ☰ 「기계」 탭 「가기」→ C 기계 앞할 일 칩 「한 판 · 🪙1」 + 「ⓘ 규칙」→ D 처음 규칙 카드그 기계 첫 판만 · 코인 아직 안 씀→ E 코인 −1→ F 조작기계별 규칙 칸→ G 판정 연출기계별 · 입력 잠금→ H 결과 카드성공 / 아까움 / 실패→ I 도감새 인형이면 등록
H에서 「한 판 더 🪙1」→ E, 「그만」→ C, 「도감 보기」→ I. 코인 0개면 C의 칩이 「코인 없음」 카드(v1 ⑩)로. 조작 중 위 오른쪽 ✕ = 그만두기 확인(「코인은 돌려받지 못해요」). 허브로 나가기는 ☰ → 설정(기존과 같음). 실선 칸은 세 기계가 같은 화면, 점선 보라 칸만 기계마다 바꿔 끼웁니다.

7. 점검 항목 (월드개발 점검에 넣어 주세요)

  1. 타이머 판정 표: 9.999 → 「09.99」 실패/아까움 · 10.000 → 「10.00」 성공 · 10.009 → 「10.00」 성공 · 10.010 → 「10.01」 아까움 · 10.100 → 「10.10」 아까움 · 10.110 → 「10.11」 실패. 성공은 「10.00」일 때만(이 시안에서 자동 점검함, 아래 결과).
  2. 타이머 숫자는 늘 「두 자리.두 자리」(09.87처럼 앞 0 포함), 글자 폭 고정이라 숫자가 바뀌어도 흔들리지 않음. 멈춘 숫자와 결과 카드·기록 숫자가 같음.
