# 변경기록 2026-11-23 — 인형뽑기 기계별 모양 연결·배포 (월드개발)

상위 업무: 온라인 인형뽑기 MVP(리더 월드기획). 대표 결정(월드기획 전달): 커밋 후 배포 + 운영 서버 재시작, 치이카와는 공개판 제외 유지.

## 한 것
- 월드아트 기계별 모양 연결 확인: 가게 `buildClawShop({kinds:true})`(숲속 = 집게·도시 = 타이머·별빛 = 열쇠), 타이머 숫자판 `setTimer({text: fmtTimer 결과, state})`, 열쇠 `key.set`·`setHoles`, 「뽑는 중」 표시 높이 `userData.height`. MVP 구현 때 이미 붙어 있었고 이번에 화면·점검으로 다시 확인.
- ☰ 기계 목록 소개 줄을 월드아트 문구(`MACHINES[].sub`: 「처음이라면 여기!」·「딱 10.00에 멈춰요」·「열쇠로 칸을 골라요」)로 바꿈(`claw-hud.js`).
- 타이머 「실패 누적 시 쉬워짐」: `CLAW_TUNING.timer.pityWinSec` 0 = 꺼짐(월드디자인 추천) 유지 확인. 규칙 카드에도 보장 줄이 안 나옴.
- 공개판 디버그 파일(소스맵)에 주석으로 남던 다른 회사 캐릭터 이름을 주석에서 뺌(`claw-palette.js`·`claw-guest.js`).
