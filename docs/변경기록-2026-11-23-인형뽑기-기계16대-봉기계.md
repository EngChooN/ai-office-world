# 변경기록 2026-11-23 — 인형뽑기 기계 16대·봉 기계·큰 인형 도감 딱지 (월드개발)

지시: 월드기획(대표가 월드디자인 v4.1 추천안 전부 승인). 범위 = 1단계(기계 16대)·2단계(봉 기계, 혼자 뽑기 상자 남기기). 서버 쪽 변경·서버 켜기는 제외. 커밋·배포 안 함.
자세한 구현·3단계 연결 자리: `docs/인형뽑기/기계확대-구현-인계-v1.md`.

## 바뀐 것
- 기계 3대 → 16대(집게 6·봉 4·타이머 3·열쇠 3) + 빈 자리 2(「준비 중」 덮개), 가게 14 × 11m, 장식 기계 없앰.
- 큰 인형 도감 「큰」 딱지(월드아트 v1.6 인계 §12-5 ①), 상자 피규어 「상자」 딱지. 도감 19칸·종류별 칩.
- 진열장(§12-5 ②): **큰 인형·상자는 도감에만** 표시(추천안·대표 미확인). 이유: 진열장 선반 간격 0.5m·맨 위 여유 0.37m라 큰 인형(0.42~0.50m)이 안 들어감. 자리를 늘리려면 진열장 그림을 새로 짜야 해 작은 변경이 아님.
- 월드아트가 고친 월드개발 파일 검토(§12-5 ⑤): 타이머 문 순서(성공 뒤 문 열어 둠 → 인형 치울 때 0.5초 닫힘)·규칙 글 「큰 인형」·검사 기대값 모두 문제없음. 큰 인형 id(`big-…`)는 act `r` 규칙(영문 소문자·숫자·- 24자) 안이라 **서버 자료 형식 그대로**, 저장 정리도 큰 인형을 지우지 않음(시험 추가).
- 봉 기계: 물리 판정(`claw-bridge-physics.js`), 임시 그림(`claw-bridge.js`), 두 단추 조작·옆에서 본 작은 창·판 전 자리 윤곽·8판 뒤 힘센 집게, 상자 자리를 이 기기에 오늘까지 저장, 막힘 자동 정리, 아슬아슬 이름표(내 화면만).
- 「옆 빈 ○○로 →」 칩, ☰ 기계 탭 종류별 묶음, 타이머 3만 3초부터 숫자 어두워짐, 코인 기록 매일 채움 회색(v4 §10).
- 손님 인형 자리: 열쇠 1·2의 8번째 칸, guest-2 공개판 대체 = 회사원 동동이.
- 옛 저장 이어받기(forest·city·star → 새 id).
- act 기계 번호 0~16(`multi-protocol.js`) — 운영 서버를 다시 켜야 5~16번 기계 구경이 전달됨.
- 휴대폰 무게: 안 쓰는 집게 물리 멈춤, 화면 밖 더미 안 그림, 먼 기계 외곽선·장치 숨김·그림자 끔, 그림자 범위를 가게 전체로.

## 봉 기계 구조 바로잡기(대표 지적 두 번 + 실제 사진 2장)
- 처음 구현은 봉 2개(앞뒤 방향)·봉 아래 전체가 구멍이라, 봉 바깥으로 떨어져도 성공이었음 → 바로잡음.
- 사진으로 확인한 것: 봉 4개, 모두 손님이 보기에 좌우로 뻗고 앞뒤로 나란히. 가운데 두 개 = 상자가 걸치는 받침 봉, 바깥 두 개 = 밖으로 못 나가게 막는 봉. **구멍 = 가운데 두 받침 봉 사이 틈뿐**, 그 밖은 받침판.
- 판정은 월드아트 배치 파일 `claw-bridge-layout.js` 하나를 그림과 같이 씀(그림 = 판정). 상자는 긴 쪽이 앞뒤로 두 받침 봉을 건넘. 받침·막이 봉 사이 좁은 틈으로 끼어 내려간 것은 성공 아님.
- 사진으로 못 정한 값(추정): 막이 봉 간격(받침 봉에서 6cm)·높이(같은 높이로 봄)·받침판 깊이(봉 윗면 12cm 아래)·八자 방향(왼쪽 11 → 오른쪽 15cm). 월드디자인에 §7 규칙 확인 부탁함(답 대기).
- 손맛(무작위로 모서리를 노리는 시험, 사람 아님, 20개씩): 봉 1·2(13cm) 평균 약 12판, 봉 3(八자) 약 13.5판, 봉 4(11.5cm) 거의 못 뗌(25판 안 성공 1번). 목표 4~6판보다 어려움 → 조절값은 월드디자인 추천·대표 결정 뒤 바꿈.

## 마무리 고친 것
- 「열쇠 1는」 → 「열쇠 1은」: 끝 글자가 숫자면 읽는 소리로 조사(1 = 일).
- 봉 상자 저장은 상자가 멈춘 뒤에(흔들리는 중 저장하면 새로고침 뒤 더 움직이던 것). 점검은 저장한 공 자리와 새로고침 뒤 자리를 공마다 8mm 안으로 비교.
- 그림자 보정(bias·normalBias)이 제 줄바꿈 실수로 주석 안에 들어가 꺼져 있던 것을 되살림(원래 값 그대로).
- 봉 「옆에서 본 작은 창」이 PC에서 한 줄 안내에 가리던 것 → 안내 아래로.
- 월드아트 v1.7(봉 정식 그림·단계 그림·간판 한 장·기계 위 불) 함께 묶음. 그리기 수(월드아트 측정 스크립트): 들어온 자리 휴대폰 91번·27만, PC 129번·39만, 가장 무거운 자리 휴대폰 173번·34만, PC 210번·46만 — 모두 한도 안.
