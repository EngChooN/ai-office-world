## 바뀐 것
- 막이 봉: 받침 봉보다 3cm 위(`claw-bridge-layout.js` `GUARD_RISE`). 실물 사진은 같은 높이지만 게임 판정 보정. 그림도 같은 자리에 그림(죔쇠를 그만큼 길게) — 그림 = 판정.
- 봉 3: 八자 왼쪽 11 → **12.5cm**(오른쪽 15cm 그대로). 코드는 봉 가운데 사이를 재므로 11cm면 실제 틈 9.1cm < 상자 두께 10cm.
- 봉 4: 11.5 → **13cm**. 희귀 상자 무게 1.2kg(전부터 있던 값)로 어렵게.
- 아슬아슬(기계 이름표): 받침 여유 2cm 이하**만**(기울기 20° 조건 뺌).
- 아까움(결과): 받침 여유가 2cm 이하로 **이번 판에 새로 들어간** 판(전: 기울기 15°·3cm 움직임 — 빗나간 판 44%에서 떴음).
- 보장(8판 연달아 실패): 직원이 상자를 처음 자리에 다시 놓음 + 실패 수 처음부터. 상자가 아슬아슬하면 건너뛰고 다음 판으로 미룸(추천안·대표 미확인 — 떨어지기 직전 상자를 치우지 않으려고). 힘센 집게 1.5배(`pityPower`) 없앰.
- 자동 다시 놓기(판 끝): 기존(닿지 않는 곳·진척 없음 6판) + 막이 봉 밖/봉 아래 끼임(바로) + 45° 넘게 누운 채 3판. 다시 놓을 때 **같은 경품 상자**(전: 기계의 첫 경품으로 바뀜).
- 저장(`state.mach`)에 `lay`(누운 채 판 수) 추가. 옛 저장은 0으로 읽음.
- 규칙 카드 글: 직원 도움·자동 다시 놓기 문장, 八자 간격 소수 한 자리(12.5cm).
