1. 마을 광장 배치도 (위에서 본 모습)

  • 처음 화면 = 트리 정면. 남쪽 입구에서 등장.
  • 조용한 곳(모닥불) ↔ 시끄러운 곳(눈싸움) 사이를 눈벽·집으로 가림. 눈덩이는 눈싸움 마당 안에서만.
  • 주 동선(주황 화살표)은 입구 → 트리 → 모닥불/우체통. 전시 눈사람·썰매 멈춤 구역은 주 동선 밖.
  • 광장 경계는 눈 더미·울타리·집(보이지 않는 벽 없음).
  • 크기 감: 트리 = 동동이 키의 8~10배, 모닥불 통나무 4개 × 2자리.
