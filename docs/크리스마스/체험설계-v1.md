## 1. 공통 원칙 (기존 월드와 맞추는 점)

1. **화면 톤은 「등산 수첩」 종이 톤을 그대로 쓴다.** [기존] 단추·창·서버 카드·채팅 창이 모두 같은 변수(`--paper`·`--ink`·`--accent`)를 쓴다. 크리스마스는 **밤 팔레트**만 새로 정하고(월드아트), 모양·크기·위치 규칙은 바꾸지 않는다.
2. **누를 수 있는 것은 모두 44px 이상, 휴대폰 안전 영역 안.** [기존] 서버 카드·채팅 창 기준과 같다.
3. **할 일은 대상 위의 표시로 알린다.** [기존] 흡연장 자판기·벤치처럼 *멀면 작은 점 → 가까우면 그림 → 닿을 거리면 「그림+글」 단추*. 표시를 누르면 멀리서도 걸어가서 한다. 크리스마스의 트리·우체통·모닥불·눈사람 마당·눈싸움 마당·썰매 출발대가 모두 이 규칙을 따른다.
4. **한 번에 한 가지 창.** 큰 창(장식 고르기·선물 보내기·카드 열기)이 열리면 채팅 창은 접히고, 걷기 입력은 창이 닫힐 때까지 쉰다. [기존] 채팅 창이 `hiking:sheet`로 다른 창을 닫는 방식과 같다.
5. **서버가 없어도 화면은 깨지지 않는다.** 서버 연결이 끊기면 "혼자 보기"로 바뀌고 모든 단추는 남되, 함께 하는 기능은 이유를 한 줄로 알린다(§3-4).
6. **음주·흡연 요소 없음.** [확정] 모닥불 곁 소품은 코코아·마시멜로·담요 같은 것만. 흡연장 재떨이·캔커피 단추는 가져오지 않는다.

## 2. 광장 동선 (마을 광장 배치)

### 2-1. 배치 [제안 — 시안 A를 바탕으로 크기·순서만 정함]
시안 A의 구도(가운데 트리, 왼쪽 모닥불, 오른쪽 우체통, 눈사람 코너, 양옆 집)를 유지하고, 미니게임 두 곳(눈싸움·썰매)을 광장 바깥 고리에 붙였다. 그림은 `체험설계-v1-화면.html` 1번.

```
                 북 (화면 안쪽)
          ┌──────── 썰매 언덕 ────────┐
          │   🛷 출발대(언덕 위)        │
          │     ↓  썰매 길(폭 넓게)     │
   집 집 ─┤                          ├─ 집 집
          │  🔥모닥불    🎄트리    🎁우체통 │
   ❄️눈싸움 │   (서쪽)     (중심)    (동쪽)  │ ⛄눈사람 마당
   마당   │          ⛄전시 줄          │ (만들기)
          │        🧍 첫 등장 자리       │
          └──────── 마을 입구 ─────────┘
                 남 (화면 앞쪽, 처음 카메라가 보는 쪽 = 트리)
```

| 장소 | 자리 | 크기 감(동동이 기준) | 쓰는 사람 |
|---|---|---|---|
| 🧍 첫 등장 자리 | 남쪽 입구, 트리를 정면으로 봄 | 반지름 3m 안에 흩어져 등장(겹침 방지) | 모두 |
| 🎄 트리 | 광장 중심 | 동동이 키의 약 8~10배. 둘레를 한 바퀴 돌며 장식할 수 있게 둘레 길 폭 3m | 장식 달기 |
| 🔥 모닥불 | 서쪽 | 통나무 의자 4개 × 2자리 = **8자리** 원형 | 앉기 |
| 🎁 우체통 | 동쪽 | 빨간 우체통 1개 + 앞에 2~3명 설 자리 | 선물 |
| ⛄ 전시 줄 | 트리 남쪽 반원 | 완성 눈사람 **8개** 자리 | 구경 |
| ⛄ 눈사람 마당 | 동쪽 바깥 | 눈 쌓인 평지(눈덩이가 굴러 커지는 곳) | 미니게임 ① |
| ❄️ 눈싸움 마당 | 서쪽 바깥 | 낮은 눈벽 3~4개, 바닥에 경계 표시 | 미니게임 ② |
| 🛷 썰매 언덕 | 북쪽 | 출발대 → 굽은 길 1개 → 평지 멈춤 구역 | 미니게임 ③ |
| 🏠 집 | 양옆 | MVP는 장식(문 불빛·화환), 들어가지 않음 | — |

### 2-2. 동선 규칙
- **처음 들어오면 트리가 화면 가운데.** 입장하자마자 "모두가 함께 꾸미는 트리"가 이 월드의 얼굴임을 보여준다. 첫 방문에는 트리 위 표시가 한 번 반짝이고 "트리에 장식을 달아 보세요" 말풍선 안내(4초, 한 번만).
- **조용한 곳과 시끄러운 곳을 나눈다.** 모닥불(대화)은 서쪽, 눈싸움(던지기)도 서쪽 바깥이지만 사이에 집 한 채와 눈벽을 둬 눈덩이가 모닥불까지 날아오지 않게 한다. 눈덩이는 **눈싸움 마당 안에서만** 던질 수 있다(§7-2).
- **빈손으로 다니는 길을 막지 않는다.** 전시 눈사람·썰매 멈춤 구역은 주 동선(입구→트리→모닥불/우체통)과 겹치지 않게 둔다.
- **광장 밖 경계:** 보이지 않는 벽 대신 눈 더미·울타리·집으로 막는다. 경계에 닿으면 미끄러지듯 옆으로 비껴 간다(흡연장 난간과 같은 느낌).
- **길 잃지 않게:** 화면 위 가운데에 지금 장소 이름이 작게(`🎄 눈마을 광장 1서버 · 👥 12/20`) 붙고, 미니게임 구역에 들어가면 1.5초 동안 구역 이름 띠("❄️ 눈싸움 마당")가 뜬다.

## 3. 입장과 서버 (기존 서버 고르기와 같게)

### 3-1. 흐름 [기존 흐름 재사용 + 크리스마스 입구]
```
허브(/) 「온라인 크리스마스」 카드
  → 입구 화면(눈 내리는 동네, 닉네임 칸)                     … 시안 C
  → 서버 카드 화면(entry, 불투명 전체 화면, 기존 server-pick)   … 뒤에서 광장 장면 미리 읽기
  → 광장 첫 등장 자리
```
- **허브 카드** [제안]: 제목 `온라인 크리스마스`, 장소 `눈마을 광장`, 설명 `동동이와 트리를 꾸미고 눈사람을 만들어요`, 태그 `함께`·`눈 오는 밤`. 기존 `src/hub/experiences.js`에 한 줄 추가.
- **입구 화면:** 시안 C의 `🎅 마을 입장` 단추를 누르면 서버 카드 화면으로 간다. 닉네임은 **서버 카드 화면의 기존 닉네임 칸**에서 받는다(입구에 칸을 또 두지 않음 — 등산·흡연장과 같은 자리). 시안의 `🔗 친구 광장으로`는 초대 링크로 들어온 경우에만 보인다(아래).
- **서버 카드:** [기존] 서버마다 카드(그림·이름·인원 막대·`들어가기 ▶`), 5초마다 인원 갱신, 꽉 차면 `꽉 참` 도장. 이름은 `눈마을 광장 1서버`·`2서버`·`3서버` [제안].
- **정원 20명** [확정 — 기획서]. ⚠️ 지금 공용 정원 값은 30명(`SERVER_MAX`, 11-13 대표 지시로 등산·흡연장 변경)이라, **체험마다 정원을 따로 둘 수 있게** 월드개발이 나눠야 한다. 인원 막대·꽉 참 판단도 체험별 정원으로.
- **혼자 둘러보기:** 서버 카드 화면 아래 기존 `혼자 걷기` 자리에 `혼자 둘러보기`. 혼자일 때 트리 장식·눈사람은 내 화면에만 남고(새로고침하면 사라짐), 선물·눈싸움 상대는 없다는 안내를 카드 밑에 한 줄로.

### 3-2. 초대 링크 [제안]
- 화면 위 오른쪽 `🔗 광장 초대` 단추 → "링크를 복사했어요 · 눈마을 광장 2서버로 바로 들어와요" 알림. 링크는 기존 `?multi=` 규칙(`?multi=눈마을-2`).
- 링크로 온 사람: 입구 화면에 `🔗 친구 광장으로 (눈마을 광장 2서버)` 단추가 큰 단추가 되고, 누르면 서버 카드를 건너뛰고 바로 그 서버로 [기존 직접 링크 동작]. 첫 방문이면 닉네임만 묻는 작은 창을 먼저.
- 친구 서버가 꽉 찼으면 서버 카드 화면으로 돌아와 그 카드에 `방금 꽉 찼어요` [기존 문구] + "다른 서버에서 기다리면 자리가 나도 자동으로 옮겨지지 않아요" 안내.

### 3-3. 게임 안 서버 바꾸기
[기존] 연결 상태 칩을 누르면 같은 카드 모양 창(`switch`), 지금 서버는 `지금 여기`. 서버를 바꾸면 지금 들고 있던 것(장식 고르는 중·눈덩이·썰매)은 내려놓고 옮긴다는 확인 한 줄.

### 3-4. 연결 상태와 끊김 화면 (완료 기준 5)
| 상태 | 화면 | 할 수 있는 것 |
|---|---|---|
| 연결 중 | 칩 `연결 중…` | 걷기·구경 |
| 연결됨 | 칩 `🎄 눈마을 광장 1서버 · 👥 12/20` | 전부 |
| 다시 연결 중 | 칩 깜빡임 `다시 연결 중…`, 다른 사람은 마지막 자리에서 반투명 | 걷기. 장식 달기·선물 보내기 단추는 눌러지되 "연결되면 보낼게요"가 아니라 **"연결이 돌아오면 다시 눌러 주세요"**(보내지 않고 버림 — 중복 방지) |
| 끊김 | 칩 `혼자 보기 · 다시 연결` 단추, 다른 사람·말풍선 사라짐, 트리·전시 눈사람은 **마지막으로 받은 모습 그대로 유지** | 걷기·앉기·혼자 눈사람·썰매 |
| 꽉 참 | 서버 카드 화면으로 돌아가 `방금 꽉 찼어요` | 다른 서버 고르기 |
| 서버 점검(주소 없음·`/health` 실패) | [기존] 서버 카드 대신 `서버에 연결할 수 없어요` 카드 + `혼자 둘러보기`만 | 혼자 보기 |

## 5. 광장 활동 화면 흐름

### 5-1. 🎄 트리 꾸미기 (완료 기준 2)
**규칙 [제안]**
- 트리에는 **정해진 장식 자리 120개**(월드아트가 가지 끝에 배치)가 있다. 자유 위치가 아니라 자리를 고르는 방식이라 겹침·떠 있는 장식이 없고, 동기화가 단순하다(자리 번호 + 장식 종류 + 단 사람 이름).
- 장식 종류(MVP 8개): 공 오너먼트 4색(빨강·금·파랑·은), 지팡이 사탕, 종, 눈송이, 작은 선물상자. 전구줄은 자리 대신 **트리 전체 점등 단계**로 표현(아래 「모두의 목표」).
- **한 사람 제한:** 1분에 3개, 서버에 남는 내 장식 최대 10개. 넘으면 "장식은 1분에 3개까지 달 수 있어요"(남은 초 표시).
- **떼기:** 내가 단 장식만, 단 지 60초 안에만 「되돌리기」. 남의 장식은 뗄 수 없다(장난 방지).
- **꼭대기 별:** 자리 1개, 처음엔 잠겨 있음. 장식이 40개 모이면 열리고, 먼저 단 사람이 달면 트리 전체 점등 연출(3초, 모든 접속자 화면). 별 단 사람 이름이 트리 아래 팻말에 남는다.
- **모두의 목표(전구):** 장식 수에 따라 전구가 단계별로 켜진다 — 20개 1단계, 40개 2단계(별 열림), 80개 3단계, 120개 가득(반짝임 연출 + "트리가 다 채워졌어요! 🎄"). 화면 위에 작은 진행 막대 `🎄 47/120`.
- **나중에 온 사람에게도 보임:** 들어오는 순간 서버가 트리 전체 상태를 보내 준다. 아무도 없는 채로 일정 시간이 지나면 초기화 [확정: 기획서 6절, 시간 값은 개발 결정].

**화면 흐름**
```
트리 근처 → [🎄 장식 달기] → ① 장식 고르기 모드
  카메라: 트리를 정면으로 바라보는 고정 궤도. 좌우 끌기·A/D로 트리 둘레를 돌고, 휠·핀치로 위아래.
  아래: 장식 8개 줄(가로 스크롤 없음, 휴대폰은 4×2) + 남은 개수 "이번 1분 3개 남음"
  트리 위: 빈 자리가 은은하게 점으로 보임(이미 찬 자리는 점 없음)
→ ② 장식을 고르고 빈 자리 점을 누름 → 미리 보기(반투명 장식 + [달기] [취소])
  PC는 점 위에 올리면 바로 미리 보기, 클릭 = 달기
→ ③ 달기 → 작은 '딸랑' 소리, 장식이 살짝 흔들리며 붙음, 내 이름이 1초 떠오름
   같은 순간 다른 사람이 같은 자리를 먼저 차지했으면 "앗, 방금 다른 분이 달았어요" + 가장 가까운 빈 자리를 반짝
→ ✕ / Esc / 걷기 입력 → 모드 끝, 3인칭으로 돌아감
```
- 장식 위를 누르거나(PC는 올리기) 하면 `민수가 달았어요` 작은 글.
- 동시에 여러 명이 장식 모드여도 서로의 몸은 보이고, 장식 모드인 사람 머리 위에는 작은 🎄 표시.

### 5-2. 🎁 선물 우체통 (완료 기준 3)
**규칙 [제안]**
- 선물 = **아이템 1개 + 카드**. 돈·실물 없음 [확정].
- 받는 사람: **지금 같은 광장에 있는 사람 1명** 또는 **광장 모두**. 지금 없는 사람에게 보내기(오프라인 배달)는 계정이 없어 같은 사람인지 알 수 없으므로 MVP에서 하지 않는다. 다만 받은 사람이 잠깐 끊겼다 다시 붙는 경우(기존 재접속 유예)에는 그 사이에 온 선물을 이어서 받는다 [개발 결정: 유예 기간 동안 보관].
- 아이템(MVP 6개): 산타 모자, 목도리, 순록 머리띠(=입는 것 3), 오너먼트 1개(받으면 트리에 내 몫 +1 없이 바로 달 수 있음), 눈송이 스티커, 코코아(들고 마시는 동작). 보낸 사람 것은 줄지 않는다(무한, 고르기만).
- 카드: 그림 3종(트리·눈사람·모닥불) × 글 **60자**. 글은 채팅과 같은 금칙어 가림을 거친다(§8-2). 빈 카드 대신 기본 문구 4개 중 고르기 가능("메리 크리스마스!" 등).
- 제한: 한 사람 **5분에 3개**, 같은 사람에게 **5분에 1개**, 광장 모두에게는 **30분에 1번**. 넘으면 남은 시간 안내.
- 음소거한 사람의 선물은 조용히 안 받는다(보낸 사람에게는 "보냈어요"로 보임 — 음소거 사실이 드러나지 않게).

**보내기 흐름**
```
우체통 근처 → [🎁 선물 보내기]
 ① 누구에게?  광장 사람 목록(이름·가까운 순) + 맨 위 [🎄 광장 모두에게]
             목록은 머리 위 이름표를 눌러서 [선물 보내기]로 와도 됨(받는 사람이 이미 골라진 채 ②부터)
 ② 무엇을?    아이템 6개 카드(2×3)
 ③ 카드 쓰기  카드 그림 3종 → 글(60자, 남은 글자 수) 또는 기본 문구
              아래 한 줄: "전화번호·주소·SNS 아이디는 적지 마세요"
 ④ 확인       받는 사람·아이템·카드 미리 보기 → [보내기]
 → 우체통 깃발이 올라가고 편지가 '쏙' 들어가는 연출 → "지은에게 선물을 보냈어요"
```
- 단계 위에 `1 누구 · 2 선물 · 3 카드 · 4 확인` 점 표시, 뒤로 가기 가능. 휴대폰은 아래에서 올라오는 시트(화면의 70% 높이), PC는 가운데 창(폭 480px).

**받기 흐름**
```
선물이 오면 → 화면 위에 "🎁 민수에게서 선물이 왔어요 [열어 보기]" 알림 5초
            + 💬 단추 옆이 아닌 행동 단추 쪽 📬에 숫자 배지(놓쳐도 남음)
[열어 보기] → 상자 리본이 풀리고 아이템이 튀어나옴 → 카드가 펼쳐짐(보낸 사람·글)
           → [입어 보기](입는 것) / [트리에 달기](오너먼트) / [닫기]
           카드 오른쪽 위 ⋯ → [🔇 이 사람 음소거] [🚩 신고]
광장 모두에게 온 선물 → 우체통 위 '모두의 카드' 판에 최근 5장이 걸리고, 아이템은 누구나 한 번 받기
```
- 받은 선물은 광장에 있는 동안 📬 목록에 남는다(카드·목록은 서버를 나가면 사라짐 — 저장 없음 [제안]). **입는 아이템(모자·목도리·머리띠)은 이 기기에 남겨 다음에 들어와도 입을 수 있다 [확정 11-16 대표]** — 서버에는 저장하지 않음.

### 5-3. 🔥 모닥불 앉기
**규칙 [제안, 흡연장 벤치 앉기 방식 재사용]**
- 자리 8개(통나무 4개 × 2). 표시를 누르면 **가장 가까운 빈 자리**로 걸어가서 앉는다. 다 찼으면 [기존 흡연장 문구 방식] "자리가 다 찼어요" 알림.
- 앉으면: 카메라가 천천히 모닥불 쪽으로 돌아 불과 맞은편 사람들이 보이는 각도(3인칭 낮은 각도), 따뜻한 불빛이 얼굴에 비침, 장작 소리 크게·캐럴 작게.
- 앉은 동안 행동 단추: `🙌 손 녹이기`(손을 불 쪽으로 내미는 동작 3초), `🍫 코코아`(코코아 선물을 받았을 때만). 보조: `일어나기`.
- 걷기 입력(W·조이스틱)이 들어오면 바로 일어나 걷는다 [기존 흡연장과 같음].
- **같이 앉는 포즈:** 옆자리(같은 통나무)에 다른 사람이 앉아 있으면 둘 다 살짝 몸을 기울이는 정도 [제안]. 강제 짝 동작·제안 창은 두지 않는다(처음 보는 사람끼리 부담 없이).
- 모닥불 둘레 반지름 6m 안에서는 **말풍선이 조금 더 크고 오래(6초)** 보인다 — "모닥불 앞 수다"가 이 공간의 역할.

## 6. 사람 카드 (이름표를 눌렀을 때) [제안]
다른 사람의 머리 위 이름표(또는 PC 오른쪽 클릭)를 누르면 작은 카드:
```
┌ 민수 ─────────────┐
│ 👋 인사   🎁 선물 보내기 │
│ 🔇 음소거   🚩 신고     │
└──────────────────┘
```
- 같은 내용이 연결 칩 → `👥 광장 사람 12명` 목록에도 줄마다 있다 [기존 사람 목록의 `차단`·`신고` 단추 자리].
- 휴대폰은 이름표가 작으니 이름표 주변 44px을 누름 영역으로 넓힌다.

## 7. 미니게임 3종 (완료 기준 4)

공통 규칙 [제안]
- **들어가기 = 그 구역으로 걸어 들어가기.** 별도 대기실·시작 단추 없음. 구역 경계에 들어가면 이름 띠 + 한 줄 규칙 안내(첫 1회는 4초, 이후 1.5초).
- **점수·순위·기록 없음** [확정]. 대신 "재미있는 순간"을 크게 보여준다(눈투성이, 완성 축하, 썰매 점프).
- **다른 사람 화면에도 보인다** — 눈덩이 크기·위치, 날아가는 눈덩이, 썰매 탄 모습을 모두 동기화.
- **음소거한 사람은 놀이에서도 사라진다**(그 사람의 눈덩이·썰매가 내 화면에 안 보이고, 나를 맞혀도 나에게 연출이 안 나옴).

### 7-1. ⛄ 눈사람 만들기 — 협동 굴리기
**목표:** 몸통 눈덩이와 머리 눈덩이를 굴려 키운 뒤 쌓고, 얼굴을 꾸며 광장에 전시한다. 혼자도, 여럿이도 완성할 수 있다.

**규칙 [제안]**
1. 눈사람 마당 안에서 `⛄ 눈덩이 만들기` → 발 앞에 작은 눈덩이(지름 0.3m)가 생긴다. 마당 안 동시 눈덩이 **최대 6개**(꽉 차면 "마당에 눈덩이가 많아요. 하나를 완성하거나 굴려 보세요").
2. **굴리기:** 눈덩이에 몸을 대고 걸으면 앞으로 밀리며 굴러 간 거리만큼 커진다. 크기는 3단계로 보인다 — `작음`(~0.5m) → `중간`(~0.9m) → `큼`(~1.3m, 더 안 커짐).
3. **협동:** 같은 눈덩이를 2명이 밀면 1.5배, 3명 이상이면 2배 빨리 커진다. `큼`은 혼자서는 걷기 속도가 절반으로 느려지고 둘이면 정상 속도 — "같이 하면 쉽다"를 몸으로 느끼게.
4. **쌓기:** 더 작은 눈덩이를 큰 눈덩이 옆에 붙이면 `올리기` 단추. 아래가 위보다 한 단계 이상 커야 함(아니면 "아래 눈덩이가 더 커야 해요"). **2단(몸통+머리)이면 완성 가능**, 3단도 허용.
5. **꾸미기:** 쌓으면 `꾸미기` 창 — 눈(돌 2개, 필수), 코(당근, 필수), 입(돌 줄), 팔(나뭇가지), 모자, 목도리 중 고르기. 꾸민 사람 아무나 가능. 필수 2개가 차면 `완성!` 단추가 켜진다.
6. **완성:** 눈사람이 반짝이고 "⛄ 눈사람 완성!" 연출(모든 접속자에게 1.5초 알림 "민수·지은이 눈사람을 완성했어요"). 굴리기·꾸미기에 참여한 사람 이름(최대 3명 + "외 n명")이 이름판에 남는다. 이름판 글은 사람 이름뿐(직접 입력 글 없음 → 금칙어 걱정 줄임).
7. **전시:** 완성 눈사람은 트리 앞 전시 줄 8자리 중 빈 곳으로 옮겨진다. 다 찼으면 **가장 오래된 것**이 녹는 연출과 함께 빠진다.
8. **녹기:** 아무도 3분 동안 건드리지 않은 미완성 눈덩이는 천천히 녹아 사라진다(마당 정리).
9. **장난 방지:** 남이 굴리던 눈덩이를 미는 것은 허용(협동이 기본). 다만 `꾸미기`에서 붙인 부품은 붙인 사람만 30초 안에 떼기 가능.

**화면**
- 눈덩이 위에 크기 막대(3칸)와 지금 밀고 있는 사람 수 `👥2`.
- 휴대폰: 눈덩이에 붙으면 행동 단추가 `올리기`/`꾸미기`로 바뀌고, 꾸미기는 아래 시트(부품 6칸).

### 7-2. ❄️ 눈싸움
**목표:** 눈덩이를 던져 맞히고 맞는 걸 즐기는 놀이. 피해·점수 없음 [확정].

**규칙 [제안]**
1. **눈싸움 마당 안에서만** 던질 수 있고, 마당 안의 사람만 맞는다. 마당 밖 사람(지나가는 사람·모닥불)은 절대 맞지 않는다. 들어갈 때 안내: "눈싸움 마당이에요. 안에 있으면 눈덩이를 맞을 수 있어요."
2. **손에 든 눈덩이 3개**, 화면에 ❄️❄️❄️로 표시. `🤲 눈 뭉치기`(1초 웅크림)로 1개씩 채우고, 아무것도 안 하면 3초마다 1개 자동으로 찬다.
3. **던지기 간격 0.8초.** 너무 빠른 연타는 무시(서버도 같은 값으로 거름).
4. **조준:**
   - PC: 마우스 방향(화면 가운데 조준점)으로 던짐. 왼쪽 버튼을 누르고 있으면 포물선 미리 보기, 떼면 던짐. F = 바로 앞으로 던짐.
   - 휴대폰: `❄️` 단추 **짧게 누름 = 앞쪽 60° 안 12m 이내 가장 가까운 사람에게 자동 조준**(없으면 정면), **길게 누르고 끌기 = 방향·거리 조준**(포물선 미리 보기).
5. **맞으면:** 맞은 부위에 눈 터짐 + 2초 동안 눈투성이 겉모습(머리에 눈 쌓임·몸 흰 얼룩) + 짧은 "퍽" 소리. 움직임은 느려지지 않는다. 같은 사람에게 연속 맞으면 눈이 더 쌓이는 연출(최대 3단계, 5초 안 맞으면 털어냄 동작).
6. **던진 사람 표시:** 맞힌 사람 화면에 작게 "명중! ❄️", 맞은 사람 화면에 "민수의 눈덩이!" 1초.
7. **쉬고 싶으면 나가면 끝.** 마당 밖으로 한 발짝이면 놀이에서 빠진다.
8. **같은 사람 집중 공격 완화:** 한 사람이 같은 사람에게 10초에 5번 넘게 맞히면 그 뒤 10초는 맞아도 연출이 작게(괴롭힘 느낌 줄이기). [개발 결정: 판정은 서버 기준이 바람직]

### 7-3. 🛷 눈썰매
**목표:** 언덕 위에서 썰매를 타고 내려오는 재미. 기록 없음 [확정], 둘이 타기 가능.

**규칙 [제안]**
1. 언덕 위 출발대로 가는 길: 광장 북쪽 계단길로 걸어 올라가거나, 멈춤 구역의 `⬆ 언덕 위로` 표시를 누르면 출발대로 바로 옮겨진다(눈 날리는 짧은 전환).
2. 출발대에 썰매 자리 **3줄**. 한 줄에 한 번에 한 썰매. 줄이 차 있으면 "앞 썰매가 출발하면 탈 수 있어요" + 내 순서 표시.
3. `🛷 타기` → 썰매에 앉음 → 5초 안에 다른 사람이 `둘이 타기`(내 뒤에 앉기)를 누를 수 있음. 아는 사람끼리만 타도록 **앞사람이 [같이 타요] 수락**해야 앉음(거절·무시하면 혼자 출발). 5초 뒤 또는 `출발!`로 3·2·1 출발.
4. **타는 동안:** 속도는 저절로(언덕 따라 점점 빨라짐). 좌우만 조종 — PC A/D·←/→, 휴대폰 화면 아래 양쪽 큰 `◀` `▶` 단추(또는 조이스틱 좌우). 둘이 탈 때는 앞사람만 조종, 뒷사람은 `🙌 만세` 단추.
5. **길 위 재미:** 굽은 길 1번, 작은 둔덕 2개(살짝 뜨며 "와!" 연출), 길가 눈 더미에 부딪히면 눈 파묻힘 연출 후 그 자리에서 이어서 미끄러짐(멈추거나 떨어지지 않음).
6. **다른 썰매와 부딪힘 없음**(서로 통과, 반투명). 줄을 나눠도 같은 길을 쓰므로 밀어 내기 장난을 막는다.
7. 멈춤 구역에 도착하면 썰매에서 일어나며 `한 번 더? ⬆ 언덕 위로` 단추.
8. 다른 사람 화면: 썰매 탄 동동이가 길을 따라 내려가는 모습, 둔덕에서 뜨는 모습이 보인다.

**화면:** 타는 동안 채팅 단추·행동 단추 외 HUD는 흐리게. 카메라는 썰매 뒤 낮은 각도로 고정(시점 돌리기 끔), 끝나면 원래 시점으로.

## 8. 채팅 안전 — 도배 제한·금칙어·음소거 (완료 기준 6)

### 8-1. 도배 제한
| 단계 | 조건 | 화면 | 근거 |
|---|---|---|---|
| 글 길이 | 80자 | 입력칸에서 더 안 써짐 | [기존] `CHAT.max` |
| 빠르기 | 2초에 1번, 10초에 4번 | 입력칸 위 "잠깐만요, 조금 천천히" 2.4초 | [기존] 서버 `c-limit` + 채팅 창 문구 |
| 같은 말 반복 [제안] | 직전 2번과 같은 글(공백·이모지 반복 정리 후 비교) | "같은 말은 연속 두 번까지만 보낼 수 있어요" | 새로 — 서버에서 거름 |
| 계속 막힘 [제안] | 1분 안에 위 제한에 3번 걸림 | **30초 채팅 쉬기:** 입력칸이 잠기고 자리 표시 글이 "30초 뒤에 다시 쓸 수 있어요 · 29" 카운트다운. 빠른 말 칩·이모지도 잠김 | 새로 — 서버가 시간을 정하고 알려 줌 |
| 이모지 | 3초에 2번, 10초에 5번 | 넘치면 그냥 안 뜸(안내 없음 — 장난 동기를 줄임) | 새로 |
| 선물·장식·눈덩이 | 각 절의 제한 | 남은 시간 안내 | §5·§7 |

- **같은 말 반복 막기·30초 쉬기는 등산·흡연장 채팅에도 똑같이 넣는다 [확정 11-16 대표: 세 곳 모두]** — 공통 채팅 코드(서버 `rooms.mjs`·`CHAT`)에 한 번 넣으면 세 체험이 같이 따른다.
- 막힌 글은 **입력칸에 그대로 남겨** 다시 보낼 수 있게 한다(지금은 보내는 순간 지워짐 — 크리스마스에서 고치고 등산·흡연장에도 적용 권장).

### 8-2. 금칙어
- [기존] 서버 금칙어 목록(`server/chat-banned-words.txt`)으로 부분 일치 `***` 가림. 문장 전체를 막지 않는다. 보낸 사람 화면에도 `***`로 보인다(가린 글이 그대로 돌아옴).
- **크리스마스에서 같은 가림을 쓰는 곳:** 채팅, 선물 카드 글, 닉네임(기존 이름 규칙). 눈사람 이름판·장식 팻말은 사람 이름만 쓰므로 따로 없음.
- **가족·아이 이용을 고려한 안내** [제안]: 채팅 창 맨 위 한 줄 고정 "전화번호·주소·SNS 아이디는 적지 마세요. 채팅은 저장되지 않아요." (채팅 운영 정책 §B 권고 문구). 전화번호·링크 가림 자체는 정책 문서에서 대표 결정 대기.
- 금칙어 목록은 등산·흡연장과 **같은 파일**을 쓴다(따로 만들지 않음). 흡연장 전용 '담배 거래' 줄도 크리스마스에 그대로 적용돼도 문제없음.

### 8-3. 음소거 (나만 안 보기)
- **이름:** 화면에는 `🔇 음소거`로 쓴다(기획서 표현). 동작은 기존 `차단`과 같다 — 그 사람의 채팅·말풍선·이모지·선물·눈덩이·썰매와 **모습까지 모두** 내 화면에서 사라진다 **[확정 11-16 대표: 완전히 숨기기]**. 숨긴 사람과 몸이 겹쳐도 밀리지 않게 충돌은 끈다 [개발 결정].
- **상대에게는 알리지 않는다.**
- **하는 곳:** 사람 카드(§6), 광장 사람 목록, 받은 선물 카드의 ⋯, 채팅 기록 줄을 길게 누르기(휴대폰)·오른쪽 클릭(PC).
- **풀기:** 광장 사람 목록의 `음소거 해제`, 또는 설정 → `음소거한 사람(3)` 목록. 이 기기에 저장 [기존 `moderation` 저장 방식].
- **한꺼번에 조용히** [제안]: 설정에 `다른 사람 말풍선 숨기기` 스위치(채팅 기록은 남김). 사람이 많아 화면이 시끄러울 때.

### 8-4. 신고
- [기존] 신고 → 대상의 최근 채팅 3줄이 기록되고, 서로 다른 3명이 신고하면 24시간 이름 숨김. 신고하면 자동으로 음소거도 됨.
- 신고 창 [제안]: 사유 고르기(지금 목록 `부적절한 이름 / 방해·괴롭힘 / 기타`) + 아래 한 줄 "신고하면 이 사람의 최근 채팅 3줄이 운영자에게 전달돼요". 사유 추가(욕설·성적 표현·개인정보·선물 카드)는 채팅 운영 정책 §E 대표 결정을 따른다.
- 선물 카드에서 신고하면 **그 카드 글**도 함께 기록되어야 한다(채팅 3줄에는 카드 글이 없음) [개발 결정].
