# 스케이트 그림 에셋 v1 — 월드개발 인계 (월드아트, 2026-11-19)

대표 확정: A안(가벼운 미끄러짐), 범위 = 날·자세·움직임·효과·소리 전부. 시안 `docs/크리스마스/스케이트-타기-시안-v1.html`.
이 문서는 **그림(월드아트 몫)** 만 다룹니다. 움직임 규칙·속도·소리·자세 고르기(`skate.js`)는 월드개발 몫이라 건드리지 않았습니다.

## 1. 파일과 연결

| 무엇 | 파일 | 비고 |
|---|---|---|
| 그림 묶음 | `src/christmas/skate-art.js` `createSkateArt({world, iceY, mobile})` | 새 파일 |
| 만드는 곳 | `src/christmas/festive.js` → `village.festive.skate` (시안 B `level>=2`에서만) | 3줄 추가 |
| 부르는 곳 | `rink-play.js` `SKATE_ART_API` = `wear`·`pose`·`drawFx` | 월드개발 코드 그대로(이미 `main.js`가 `art: village.festive?.skate`로 넘김) |

`createSkateArt`가 돌려주는 것:

| 이름 | 하는 일 |
|---|---|
| `wear(avatar, on)` | 날 신기·벗기. 신으면 몸이 4.5cm 올라감(`SKATE_ART.lift`). 내 몸·다른 사람 몸 같음 |
| `pose(avatar, gait, dt)` | 자세. `gait` = `createSkateGait` 결과 `{pose, side, k, lean}`. 값을 복사해 두고 **그 몸의 다음 `update` 끝(avatar.extra)** 에 입힘 → 부르는 순서(update 앞·뒤) 상관없음. 내 몸은 한 프레임 늦음(눈에 안 띔) |
| `drawFx(fx, dt)` | `createSkateFx` 자료(`marksOf(owner)`·`powder`)를 그림 |
| `force(avatar, gait\|null)` | 점검·촬영용 자세 고정 |
| `status(avatar)` | `{on, pose, quads, dots}` |

## 2. 스케이트화
- 동동이 신발은 그대로, 밑에 은색 날(`#dfe7ef`, 25cm) + 짙은 받침 2개(`#3b3f52`) + 앞 말림. 외곽선은 동동이와 같은 선.
- 옷 몸통 부품 메시(`Xmas_Body`)에 **합쳐서** 그립니다 → 그리기 호출이 늘지 않습니다. 옷을 바꾸면 다시 합칩니다.
- 옷 3종·모자와 상관없이 같은 날. 휴대폰 먼 사람(가벼운 동동이 `lite.js`)에는 날이 없습니다(멀리서 안 보이는 크기).

## 3. 자세 이름과 모습

| gait.pose | 모습 | 쓰는 값 |
|---|---|---|
| `stand` | 날 위에 섬, 발끝 살짝 바깥 | — |
| `push` | 한 발로 바깥 뒤로 밀어냄, 몸 숙임, 팔은 반대로 흔듦 | `side` +1 = 오른발로 밂·−1 = 왼발, `k` 0→1 동안 폈다 접음(sin) |
| `glide1` | 민 발을 뒤로 들고 한 발 활주, 팔 벌려 균형 | `side` = 든 발(방금 민 발) |
| `glide2` | 두 발 모아 살짝 숙인 채 활주 | — |
| `carve` | 도는 안쪽으로 몸 기울임, 안쪽 발 조금 앞 | `lean`(rad, +면 왼쪽으로 기울임 = 왼쪽으로 돌 때), 최대 15° |
| `brake` | 몸을 옆으로 돌려(약 69°) 무릎 굽히고 넓게, 가는 쪽 반대로 기댐 | `side` = 돌리는 쪽 |
| `wobble` | 팔 들고 휘청(뒤로 젖힘 + 좌우 흔들림) | — |

- 움직이는 자세는 모두 `lean`만큼 옆으로 기울입니다(carve가 아니어도).
- 자세가 바뀌면 약 0.15초에 걸쳐 넘어갑니다(`SKATE_ART.blend` 14/s).
- 걷기 다리 통통 튀기는 그림이 지웁니다. 지금처럼 그림이 있으면 `stride:0`으로 넘겨 주세요(이미 그렇게 되어 있음).
- **전환 조건(어느 순간 어떤 자세)은 `skate.js` `createSkateGait`가 정합니다.** 그림은 받은 이름만 그립니다.

## 4. 효과

| 효과 | 모습 | 크기·수명 | 그리기 |
|---|---|---|---|
| 날 자국 | 흰 선, 자국 1개 = 길이 0.36m·폭 2cm, 발 자리(몸 가운데에서 좌우 5.5cm). `side` ±1 = 한 줄(활주하는 발), 0 = 두 줄 | 4초에 걸쳐 흐려짐(진하기 0.5 → 0) | 모든 사람 합쳐 1번 |
| 멈추기 긁힘 | 넓고 옅은 띠(폭 12cm·길이 26cm·진하기 0.22), 겹쳐서 가루 띠처럼 보임 | 4초 | 위와 같은 1번 |
| 얼음 가루 | 흰 알(지름 7cm, 둥근 점) | `powderLife` 0.7초, 개수는 자료 상한(PC 80·휴대폰 30) | 1번 |

- 그리는 칸 상한: 자국 네모 PC 720·휴대폰 160(자료 상한 사람 × 40/20 × 두 줄). 넘으면 그 프레임에 더 그리지 않습니다.
- 자국·가루가 없으면 둘 다 숨깁니다(그리기 0).

## 5. 월드개발에게 부탁(작은 것 2개)
1. **자국 주인 목록:** `createSkateFx`에 `owners()`(주인 id 목록)를 더해 주세요. 지금은 그림이 `fx.emit`을 감싸 주인을 모읍니다(동작은 같음, `owners()`가 생기면 그걸 씀).
2. **멈추기 자국 표시:** 멈추기 때 남기는 자국에 `kind:'brake'`를 붙여 주세요. 지금은 앞 자국과 방향이 70° 넘게 다르면 멈추기 자국으로 봅니다.
