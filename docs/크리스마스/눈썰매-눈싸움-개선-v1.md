## 1. 눈썰매

### 1-1. 코스 (월드아트 그림 + 월드개발 `SLED_RUN` 교체)
- **길이: 가운데 선 180m 이상(지금의 약 7.7배, 최소 기준 3배 = 71m는 반드시 넘김).** 보통 실력 1회 **25~30초**.
- 자리: 지금 언덕(`HILL` 꼭대기 6.4m)으로는 부족 → **북쪽에 큰 「썰매 산」을 새로** 둔다. 출발대 높이 **18m**, 평균 기울기 약 6°. 끝은 지금 멈춤 구역(x 8.6, z -20.4) 그대로(광장 연결 유지). 지그재그로 접어 가로 60m × 세로 45m 안에 넣는다.
- 길 폭 **4.5m**(3줄 → 4대 동시 출발), 양옆 눈둑 높이 0.5m(벗어나지 않게 밀어 줌).
- 구성(출발→끝, 거리는 가운데 선 기준):

| 구간 | 거리(m) | 내용 |
|---|---|---|
| ① 출발 직선 | 0~20 | 내리막만, 연습 구간 |
| ② S자 굽이 | 20~55 | 좌 60°·우 60° 연속, 반지름 12m |
| ③ 점프대 1 | 60 | 높이 0.8m, 체공 약 0.6초 |
| ④ 부스터 줄 | 70~90 | 길 가운데 **부스터 판 3개**(폭 1.2m, 길이 2m) |
| ⑤ 헤어핀 | 95~120 | 180° 큰 굽이, 반지름 9m — **드리프트 구간** |
| ⑥ 장애물 숲 | 125~150 | 눈 더미 4개·전나무 2그루(지그재그 배치, 사이 2m 이상) |
| ⑦ 큰 점프대 | 155 | 높이 1.2m, 체공 약 0.9초, 착지 부스터 1개 |
| ⑧ 결승 직선 | 160~180 | 결승 아치(체크무늬 깃발) → 감속 구역 15m → 멈춤 구역 |

- **구간 기록점 3개**: ②끝(55m)·⑤끝(120m)·⑧ 결승(180m). 길 위 얇은 빛 띠로 보이게.
- 속도: 기본 최고 **10m/s**, 부스터 3초 동안 **+2m/s(최고 12m/s)**. 서버 순간이동 한도(`maxSpeed 12`)와 같아지므로 **썰매 중에는 한도 14m/s**로 올리거나 썰매 사람은 검사 예외(월드개발 선택).
- 장애물: 눈 더미 = 속도 −40% + "푹!" 0.4초. 전나무 = 속도 −70% + 옆으로 튕김 0.8m + 화면 흔들림 0.2초. 둑 닿음 = −15%. 멈추거나 뒤집히지 않음(다시 미끄러짐).
- 점프: 공중 동안 조종 30%만 먹음. 착지 때 썰매가 길 방향과 25° 안이면 **"착지 성공!" +1m/s**, 넘으면 −20%.
- 완료 기준: 가운데 선 ≥180m, 사람 시험 평균 25~30초, 구성 8구간 모두 있음, 끝이 지금 멈춤 구역에 이어짐.

### 1-2. 조작
| 동작 | PC | 휴대폰(가로·세로 같음) |
|---|---|---|
| 좌우 기울이기 | A/D · ←/→ | 화면 **아래쪽 절반 아무 곳이나 좌우로 끌기**(가상 핸들). 기준점은 처음 누른 곳, **60px 끌면 최대**. 끌기 싫은 사람용 ◀ ▶ 단추 88px 유지 |
| 드리프트 | **Shift**(누르는 동안) | 오른쪽 아래 **드리프트 단추 96px**(누르는 동안) |
| 브레이크 | S · ↓ | 드리프트 단추 위 작은 단추 64px |
| 다시 시작(결과 전) | R 길게 1초 또는 위 기록 띠 옆 `↺` 단추 | 같은 `↺` 단추 56px(누르면 "처음부터?" 확인) |

- 기울이기 감도: 키는 0→최대까지 **0.25초에 걸쳐 차오르고, 떼면 0.15초에 0으로** 돌아온다(지금처럼 즉시 꺾임 없음). 최대 꺾임 각속도 **75°/s**, 속도가 8m/s 넘으면 **60°/s**로 줄임(고속 흔들림 방지).
- 길 따라 자동 정렬: 손을 떼면 썰매 방향이 길 방향으로 **초당 40%씩** 맞춰짐(조작 서툰 사람도 굽이에서 덜 부딪힘).
- 드리프트: 굽이에서 꺾기 + 드리프트를 누르면 꺾임 **1.6배**, 속도 −8%/초. **0.8초 이상** 유지하고 놓으면 **미니 부스트 +1.5m/s 1초**(1.6초 이상이면 +2m/s). 썰매 뒤 눈가루 색: 0.8초 하양 → 1.6초 하늘색(부스트 준비 표시).
- 민감도 설정: 썰매 탈 때 보이는 위 오른쪽 `⚙` 단추(44px, 게임은 멈추지 않음) 안에 **「조종 감도」 3단계(부드럽게 0.7배 / 보통 1배 / 빠르게 1.3배)**, 기기에 저장.
- 카메라: 썰매 뒤 4.5m·높이 1.8m, 속도에 따라 시야각 60°→70°. 굽이에서 카메라가 0.3초 늦게 따라옴(어지러움 방지).
- 완료 기준: 키를 톡 누르면 0.25초 안 작은 꺾임만 생김(즉시 최대 아님). 휴대폰 끌기·단추 모두로 완주. 처음 탄 사람 시험에서 S자 구간 둑 닿음 평균 2번 이하.

### 1-3. 레이스 재미
- **출발:** 출발대에서 `레이스 시작` → 대기 **10초**(그 안에 다른 사람이 `같이 하기`로 최대 4명) → 화면 가운데 **큰 숫자 3·2·1·출발!**(각 1초, 120px, 소리 "삑·삑·삑·뿡"). "출발!" 순간 **0.3초 안**에 앞으로 밀면 **스타트 부스트 +2m/s 1초**, 너무 일찍 밀면 0.5초 늦게 출발.
- 혼자 타기도 같은 카운트다운(대기 없음). 둘이 타기(앞·뒤)는 지금처럼 유지, 한 썰매로 1등 순위 하나.
- **화면 위 기록 띠:** 가운데 진행 시간(0.01초까지), 오른쪽 "구간 1/3", 왼쪽 순위(2/4). 구간 기록점을 지나면 1.5초 동안 **구간 시간 + 내 최고와 차이**(빨강 +0.42 / 초록 −0.31).
- **진행 막대:** 화면 왼쪽 세로 막대(높이 200px)에 내 썰매·다른 썰매·고스트 점.
- **고스트:** 내 최고 기록 주행을 반투명 하늘색 썰매로(이 기기 저장, 0.1초마다 위치 기록 = 30초에 약 300점). 함께 탄 사람이 없으면 자동으로 켜짐. `⚙` 안에서 끌 수 있음.
- **멀티 순위:** 같이 출발한 썰매끼리 **부딪힘 없음(서로 통과)**, 순위만 겨룸. 결승 뒤 남은 사람은 **15초** 안에 못 들어오면 "완주 못 함". 다른 사람 화면의 썰매는 지금 방식(위치 공유) 그대로.
- **오늘의 기록판:** 출발대 옆 판에 이 방 오늘 최고 5명(이름·시간). 서버 방 상태에 저장, 빈 방 초기화 규칙은 트리와 같음.
- **결과 화면(결승 1초 뒤, 가운데 창 PC 420px / 휴대폰 화면 폭 90%):**
  - 순위(1등이면 왕관 + 종소리), 전체 시간, 구간 3개 시간과 최고 대비, "새 최고 기록!" 표시
  - 별 3개: 완주 ★ / 45초 안 ★★ / 32초 안 ★★★ (보통 실력 기준 ★★)
  - 오늘의 기록판 몇 위인지
  - 단추: **`다시 타기`(E, 바로 출발대로 순간이동 + 카운트다운)**, `기록판 보기`, `내리기`(Q)
  - 다시 타기까지 결승 → 다음 출발 **5초 이내**(지금의 "걸어 올라가기"는 남겨 두되 기본 아님).
- 완료 기준: 카운트다운·스타트 부스트·구간 시간·고스트·4명 순위·결과 창·다시 타기가 PC 1920×1080, 휴대폰 390×844·844×390에서 모두 보이고 눌림. 결과 → 다시 출발 5초 이내. 오프라인(혼자 모드)에서도 고스트·결과 창은 됨(기록판·순위는 숨김).

## 2. 눈싸움

### 2-1. 조준 (가장 급함)
- **조준 모드:** 마당 안에서 던지기를 **누르고 있는 동안** 조준, **떼면 던짐**.
  - PC: 마우스 왼쪽 누름(또는 F 누름). 마우스 위치 = 방향·거리. F만 쓰면 정면, 거리는 힘 게이지로.
  - 휴대폰: `❄️` 단추(96px)를 누른 채 **끌기 = 방향**(새총처럼 반대로가 아니라 **끈 쪽으로 던짐**), 끈 길이 20~120px → 거리. 짧게 톡(0.2초 미만) = 지금처럼 자동 조준 유지.
- **포물선 미리보기:** 손에서 착탄 지점까지 점선 포물선(점 12개, 지름 6px 화면 크기 고정, 흰색 + 잉크색 테두리). 벽에 막히면 막히는 곳까지만 그리고 끝을 회색으로.
- **착탄 지점 표시:** 바닥 고리 지름 **0.8m**(지금 0.76m 유지), 사람 위에 겹치면 **빨강으로 바뀌고 그 사람 머리 위 작은 과녁**. 거리가 멀수록 고리가 커짐(최대 1.2m) = 빗나갈 수 있음 표시.
- **힘 모으기 게이지:** 누르는 시간 **0~1.0초** 동안 채워짐(캐릭터 옆 둥근 게이지, 지름 48px). 거리 = 4m + 게이지×10m(최대 14m = 지금 `maxDist`). 마우스·끌기 거리와 게이지 중 **PC 마우스는 마우스 위치 우선**(게이지는 속도만 +20%), F·휴대폰 끌기 짧을 때는 게이지 우선. 가득 찬 채 0.5초 넘으면 게이지가 깜빡이며 그대로 유지(손해 없음).
- **조준 보정:** 고리 안 0.5m에 사람이 있으면 그 사람 쪽으로 착탄 지점을 끌어당김(최대 0.4m). 자동 조준이 아니라 "살짝 도움".
- 조준 중 걷기 속도 50%, 카메라가 어깨 뒤로 살짝 당겨짐(0.25초).
- 완료 기준: 누르는 순간부터 0.1초 안에 포물선·고리 보임, 떼면 실제 착탄 = 미리보기 고리 안(오차 0.3m 안, 서버 판정과 같은 식 사용). 휴대폰 세로에서 손가락이 고리를 가리지 않음(고리는 캐릭터 앞 월드에 표시).

### 2-2. 날아가는 모습·맞았을 때
- 눈덩이: 지름 0.22m, 실제 포물선(최고 높이 = 거리×0.12, 1.5m 안팎), 뒤에 흰 가루 꼬리 0.3초. 날아가는 시간 지금 식(거리/13m/s + 0.12초) 유지.
- 땅·벽에 떨어짐: 눈가루 퍼짐 0.4초 + 바닥 흰 자국 3초.
- **맞음(맞힌 사람 화면):** 맞은 사람 머리 위 **"명중!"**(굵게, 1초) + 점수 **"+1"** 위로 떠오름, 짧은 "퍽" + 화면 끝 하양 번쩍 없음(맞힌 쪽은 기분 좋은 소리만).
- **맞음(맞은 사람 화면):** 화면 가장자리 하얀 눈 얼룩 **1.5초**(가운데 70%는 가리지 않음), 몸이 맞은 방향 반대로 0.15초 움찔, **0.6초 동안 던지기 못 함**. 눈 쌓이기(최대 3단계) 지금 그대로.
- **머리 맞힘:** 머리 높이(1.0m 근처) 맞으면 "헤드샷!" +2점(포물선 끝 높이 0.75m 이상 + 사람에 닿음).
- **피하기:** 웅크리기(PC Ctrl·C / 휴대폰 웅크리기 단추 72px)로 키 0.6m → 눈벽(0.7m) 뒤에서 안 맞음. 웅크리면 걷기 40%.
- 완료 기준: 맞힘/맞음 반응이 양쪽 화면에서 0.2초 안에 나옴, 맞은 사람이 연속으로 3번 넘게 맞아 아무것도 못 하는 일 없음(맞은 뒤 **1.0초 무적**).

### 2-3. 규칙(「눈싸움 한 판」)
- 그냥 던지기(지금 방식)는 그대로 두고, 마당 입구 판에서 **`한 판 하기`**로 경기 시작.
- **팀:** 빨강 대 초록(장갑·목도리 색으로 구분). 2~10명, 들어온 순서대로 적은 쪽에 배정. 혼자면 **눈사람 과녁 연습**(움직이는 눈사람 과녁 5개, 60초).
- **대기:** 판에서 2명 이상 모이면 **15초** 대기 후 시작, 그 사이 들어온 사람도 참가.
- **시간:** 한 라운드 **90초**, **3라운드(2선승)**, 라운드 사이 10초(진영 바꾸기). 한 판 최대 약 5분.
- **점수:** 맞힘 +1, 헤드샷 +2, 같은 편 맞힘 0점(반응은 작게). 라운드 승 = 팀 점수 높은 쪽, 같으면 무승부(둘 다 0.5승).
- **진영:** 마당을 반으로 나눠 라운드 시작 때 자기 진영 끝(마당 가장자리 1m 안)에서 출발. 가운데 선 넘어도 됨.
- **눈덩이:** 손에 3개, 뭉치기 1초에 1개, 저절로 3초에 1개(지금 값 유지). 던지기 간격 0.8초 유지.
- **같은 사람 집중 공격 완화:** 지금 규칙(10초 5번 넘으면 연출 작게) + 한 판 중에는 그 이후 맞힘 점수 0점.
- **화면 위 경기 띠:** 가운데 남은 시간(크게, 마지막 10초 빨강·째깍 소리), 양옆 팀 점수, 라운드 점 ●●○.
- 완료 기준: 2명·10명·혼자 연습 모두 시작→3라운드→결과까지 끝남. 중간에 나간 사람은 점수 남기고 팀에서 빠짐. 서버 판정(지금 `resolveThrow`)이 점수도 매김.

### 2-4. 결과 화면
- 마지막 라운드 끝 → 1초 멈춤("그만!") → 가운데 창(썰매 결과 창과 같은 틀).
- 내용: 이긴 팀(색 띠 + 이긴 팀 캐릭터 만세 동작), 팀 점수, 라운드 결과, 개인 표(이름·맞힘·헤드샷·맞음), **칭호 3개**: 「명사수」(맞힘 최다)·「눈사람」(가장 많이 맞음)·「저격수」(가장 먼 명중 m).
- 단추: **`한 판 더`(E, 같은 사람 그대로 15초 대기)**, `마당 나가기`(Q). 10초 아무것도 안 누르면 창 닫고 자유 던지기로.
- 완료 기준: 결과 → 다음 판 대기까지 3초 이내, 칭호가 같은 수면 먼저 달성한 사람.

### 2-5. 조작 정리
