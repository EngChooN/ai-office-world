# 하늘 썰매·별 흔적 그림 자산 v1 — 인계 (월드아트, 2026-11-18)

상위 업무: 크리스마스 루돌프 썰매 타기·하늘 날기·별 흔적(리더 월드기획) 2/3단계. 설계 `docs/크리스마스/루돌프-하늘썰매-설계-v2.md`(월드디자인, 대표 지시: 루돌프 2마리가 끄는 썰매에 앉아 탐).
시안 보드 `artifacts/sleigh/board.html`. 커밋·배포 안 함. 설계서 대표 결정(별 보통·PC 400/휴대폰 150·동시 탑승 제한 없음·썰매 방식)이 아닌 숫자는 추천안(대표 미확인)입니다.
작업 중에 설계가 v1(루돌프 등에 타기)에서 v2로 바뀌어, 등에 타는 자세·안장은 지우고 썰매 방식으로 다시 만들었습니다.

## 2. 연결 방법(월드개발)
```js
const SK=village.festive?.skySleigh;               // 시안 B가 아니면 null
const team=SK.fleet.spawn();                       // 썰매 한 벌(최대 31 = 정류장 1 + 정원 30). 다 쓰면 null
team.place(x,y,z,heading);                         // 썰매 자리(원점 = 썰매 날 바닥 가운데)를 바로 정함, 루돌프는 곧게 앞 2.35m
team.drive(fx,fy,fz,heading);                      // 또는 루돌프 둘 가운데(앞)를 움직이면 썰매가 끈 길이만큼 뒤에서 끌려옴(설계 §3 「루돌프가 먼저 돌고 썰매가 따라옴」)
team.mode='run'; team.speed=3.6; team.progress=p;  // stand | run | takeoff | fly | land, progress = takeoff·land 0~1
const rider=createSleighRider({avatar:player,poser});   // sleigh-rider.js, poser = createXmasPoser 결과
team.driver=true; rider.mount(team,{groundY});     // 다른 화면에서 이미 탄 사람을 처음 볼 때 {instant:true}
// 매 프레임: team.drive/place → avatar.update(dt) → village.update(fleet.update가 그 안에서 돎)
const trail=SK.stars.emitter({mine:true});         // 다른 사람 것은 {mine:false}
team.trailPoint(p); trail.update(dt,p,{air:mode!=='stand'&&mode!=='run',running:mode==='run',ground:groundY});
SK.stars.splash(x,groundY,z);                      // 착지 순간 눈 튐
rider.dismount({groundY}); team.driver=false;      // 먼저 avatar.place(옆자리) 하고 부름
team.release();                                    // 빈 썰매를 정류장으로 날려 보낸 뒤 돌려주기
```
- 땅 모드(stand·run)는 썰매·루돌프를 땅 높이(`heightAt`)에 붙이고, 하늘 모드는 받은 높이를 씁니다(썰매는 땅 밑으로 안 내려감). `drive`의 y = 루돌프 발굽 높이(= 설계의 고도 기준과 맞추려면 썰매 날 높이 `team.y`를 보세요).
- 날아오르기는 앞(루돌프)을 먼저 올리면 썰매가 늦게 따라 뜨고 코를 듭니다. 내려앉기는 **progress 0.75에 루돌프 발굽이 땅에 닿게** 맞추면 착지 눌림이 맞습니다.
- 돌 때 썰매는 바깥쪽으로 최대 15° 기울고, 하늘에서는 천천히 흔들립니다(기준점 `SLEIGH.pivot`). 루돌프는 안쪽으로 기웁니다(저절로).
- **탄 동안(`rider.active`)은 avatar.update 뒤에 땅 높이를 더하지 마세요.** 몸 높이는 좌석이 정합니다. `player.x·z·heading`은 `team.x·z·heading`으로 맞추면 이름표·말풍선이 앉은 동동이 머리 위에 옵니다.
- 만세는 `rider.setArms('cheer')` 뒤 poser `setArms('cheer')`.
- 판정 원(설계 §4): `team.front`(루돌프 가운데)·`team.back`(썰매), 반지름 1m.
- 성능 대책(설계 §6 「먼 사람부터 1마리」): `team.pair=false` → 루돌프 한 마리가 가운데서 끎.
- 정류장 기다리는 썰매는 `SK.waiting`(내 것이 아님, 출발 뒤 2초 숨기려면 `SK.waiting.visible=false`). 정류장 값 `REINDEER_STATION`: 원 가운데 (25, 28)·반지름 2·썰매 (23.5, 30.68)·heading 0.729(북서)·표지판 (24.4, 25.38)·건초 (27.6, 30.2). 충돌 원은 표지판·건초·썰매·루돌프에 넣었습니다.
- 지도 핀: 아이콘 `x-reindeer`, 자리 = `REINDEER_STATION`(지도 핀 목록은 월드개발 쪽이라 손대지 않음).

## 3. 성능 예산(시험이 검사)
- 삼각형: 루돌프 한 마리 PC 3,294 / 휴대폰 2,114(상한 3,400 / 2,200), 썰매 한 대 PC 2,360 / 휴대폰 1,754(상한 2,600 / 1,800). 30대(루돌프 60마리) PC 약 27만.
- **그리기: 썰매가 몇 대든 7번**(루돌프 몸·머리·윗다리·아랫다리·코 빛 + 썰매 + 끈) + 그림자(PC만), **별 1번**. 살아 있는 썰매를 감싸는 구로 화면 밖이면 안 그림, 별이 없으면 별도 안 그림.
- 실제 게임 화면에서 같은 화면을 켜고/끄고 잰 값(11-18): 첫 화면 PC +5·휴대폰 +0회, 정류장을 볼 때 PC +12·휴대폰 +7회. 오류 0건, FPS 60(헤드리스).
- 별: 보통 = 내 것 1초 10개(0.6m마다)·남의 것 5개·수명 2.4초·땅 반짝임/눈 튐 1초 3개. 한 화면 상한 PC 400·휴대폰 150(오래된 별부터 다시 씀). 휴대폰은 별 밝기를 낮춰 네모 번짐 방지.
- 설계 §5의 「휴대폰은 가까운 6명만 흔적」·「프레임 떨어지면 남의 흔적 절반」은 연결하는 쪽 규칙입니다(`trail.on=false`로 끔).

## 5. 남은 일·알아 둘 점
- 썰매끼리·썰매와 사람은 그림에서 밀어내지 않습니다(설계 §7 「부딪히지 않고 지나감」과 같음).
- 휴대폰 먼 사람용 「간단한 모양의 썰매」는 따로 만들지 않았습니다. 같은 그림을 한 번에 그려서 썰매 30대도 그리기 7번이고, 휴대폰은 면 수를 줄인 모양을 씁니다. 프레임이 부족하면 `team.pair=false`부터 쓰세요.
- 휴대폰에서 별에 아주 가까우면 다른 바닥처럼 가는 가로 줄무늬가 보일 때가 있습니다(휴대폰 외곽선 처리 공통 현상).
