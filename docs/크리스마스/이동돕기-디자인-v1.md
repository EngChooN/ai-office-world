## 2. 지도 좌표 변환

- 지도 범위 = 월드개발 `mapBounds()` 그대로: **x −46 ~ 46, z −59 ~ 46** (92 × 105m, 가로:세로 = 0.8762). 그림의 `viewBox`도 `0 0 92 105`.
- 화면 비율: `u = (x − x0) / (x1 − x0)`, `v = (z − z0) / (z1 − z0)` → 지금 `toMap()`과 같음. 위 = 북쪽(−z).
- 썰매 출발대(−30, −106)·케이블카 꼭대기는 범위 밖 → 지금처럼 위 가장자리 핀(`xt-edge`, 「↑」).
- 내 자리 화살 회전: `rotate(−heading)`(heading 0 = 북쪽 = 지도 위) — 지금 코드 그대로.
- 범위를 바꾸면 그림을 다시 만들어야 합니다(스크립트가 `mapBounds()`를 읽음).

## 3. 자리·크기 (휴대폰 엄지 기준)

- **달리기 단추**: 오른쪽 가장자리 `right: 16px`, `bottom: 262px`(안전 영역 더함), 지름 60px(가로 화면 56px·`bottom 258px`).
  - 왜: 조이스틱은 화면 **왼쪽 절반 어디든** 손가락을 대면 생깁니다. 지금 자리(왼쪽 아래, 채팅 단추 위)는 엄지가 조이스틱을 잡으려고 처음 닿는 곳이라 단추가 먼저 눌립니다.
  - 262px = 행동 단추 줄(큰 단추 64 + 보조 2개, 최대 약 180px)과 눈덩이 개수 표시(아래 210px, 높이 약 36px) 위.
