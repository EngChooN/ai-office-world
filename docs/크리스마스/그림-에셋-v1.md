## 2. 파일 지도 (`src/christmas/`)

| 파일 | 내용 | three |
|---|---|---|
| `layout.js` | 배치 자료·계산: 트리 자리 120 `treeSlots()`, 전구 단계 `treeLightStage(n)`, 모닥불 자리 `campfireSeats()`, 전시 자리 `displaySlots()`, 집 `HOUSES`·`houseHeading`, 마당·언덕·썰매 길 `SLED_RUN`, 땅 높이 `heightAt(x,z)`, 가까이 표시 대상 `TARGETS`, 경계 `BOUNDS` | 안 씀(서버도 import 가능) |
| `palette.js` | 색 `XMAS`, 밤 하늘·빛 배수·눈 내림 값 `XMAS_SKY` | 안 씀 |
| `props.js` | 형상: `buildTree`·`ornamentGeometry`·`buildCampfire`·`buildHouse`·`buildMailbox`·`buildCardBoard`·`snowball`·`buildSnowman`·`thrownSnowball`·`snowBurst`·`buildSled`·`buildSnowWall`·`buildLamp`·`buildArch`·`buildSign`·`buildDisplayBase`·`buildSledDeck`·`pineGeometry`·`fenceGeometry`, 정적 합치기 `bakeStatic` | 씀 |
| `village.js` | `buildVillage({toon,scene,world,mobile,samples})` 광장 전체 조립 | 씀 |
| `snowfall.js` | `createSnowfall({mobile})` 함박눈 두 층 | 씀 |
| `outfits.js` | 크리스마스 옷 `XMAS_OUTFITS`·모자 `XMAS_HATS`·선물 옷 `XMAS_GIFT_WEARABLES`, 입히기 `applyXmasLook(hiker,look)` | 씀 |
| `avatar.js` | `createXmasAvatar({rigUrl,toon,look})` = 흡연장 `createAvatar` + 크리스마스 차림, `a.setLook({...})` | 씀 |
| `preview.html/.js` | 그림 확인 페이지(게임 아님) | 씀 |

공용 파일 변경은 하나다: `src/lounge/outfit.js` `applyOutfit(hiker,key,{table,hide,fold})`에 옷 표를 넘길 수 있게 했고, 접어 넣은 부품을 옷마다 다시 계산한다(원래 자리 기억). 흡연장 기본 동작은 같다(흡연장 테스트·셔츠·정장·롱패딩 캡처로 확인).

## 3. 월드개발 연결

```js
import {buildVillage} from '../christmas/village.js';
import {createXmasAvatar} from '../christmas/avatar.js';
import {XMAS_SKY} from '../christmas/palette.js';
const village=buildVillage({toon,scene,world,mobile});           // samples:true면 예시 눈사람·썰매까지
// 매 프레임
village.update(dt,{camera,viewHeight:renderer.domElement.height,snow:1});
```
- **빛:** 흡연장 밤 공식(`composeEnvironment({sun:XMAS_SKY.sun,moon:XMAS_SKY.moon})`)에 `XMAS_SKY.light` 배수(반구광 ×1.9·달빛 ×1.25·노출 ×1.15)를 곱한다. 따뜻한 마을 빛(반구광 하나)은 `buildVillage`가 넣는다. 미리보기 `preview.js` 위쪽에 그대로 있다.
- **땅:** 광장(반지름 17m)·두 마당·썰매 멈춤 구역은 높이 0. 그 밖은 `village.heightAt(x,z)`(=`layout.heightAt`). 집은 발밑 가장 낮은 땅에 맞춰 놓았다.
- **충돌:** `village.colliders` = 원 `{x,z,r}` 또는 돌린 상자 `{x,z,w,d,heading}`(트리·모닥불 돌·통나무·우체통·카드 판·집·눈벽·가림 눈벽·가로등·아치 기둥). 광장 바깥 경계는 `BOUNDS`(울타리 반지름 43m, 언덕 쪽 북쪽 −58m까지).
- **트리:** `village.tree.setOrnament(자리, 종류|null)`, `.setLightStage(0~4)`(= `treeLightStage(장식 수)`), `.setStar(true)`, `.showSlots(true)`(장식 고르기 모드의 빈 자리 점), `.flash(초)`(점등·가득 연출), `.slotWorld(i)`. 자리 번호는 `layout.treeSlots()`와 같아 서버는 번호·종류·단 사람만 주고받으면 된다. 장식 종류 8개 = `ORNAMENT_KINDS`(빨강·금·파랑·은 공, 지팡이 사탕, 종, 눈송이, 선물상자).
- **우체통:** `village.mailbox.setFlag(0~1)`(편지 들어갈 때 깃발 올리기). 모두의 카드 판 칸은 `village.cardBoard.cards[0~4]`(그룹 이름 `card-0~4`, 받은 카드 그림으로 바꾼다).
- **모닥불:** `village.seats`(8자리: `x,z,y(엉덩이 높이 0.34),heading`(불을 봄), `log` 통나무 번호). 불빛 점광원은 `village.campfire.light`.
- **전시 줄:** `village.display[i]`(8자리, `group`에 눈사람을 올리고 `plate`(이름판 자리)에 이름 글자판을 붙인다). 완성 눈사람은 `buildSnowman(toonify,{sizes:[아래,위(,맨 위)],parts:[…],scarfColor})`로 만든다(반지름은 `SNOWBALL_SIZES` 작음 0.25·중간 0.45·큼 0.65).
- **놀이 소품:** 굴리는 눈덩이 `snowball(toonify,반지름)`, 던지는 눈덩이 `thrownSnowball`, 맞은 자리 `snowBurst`(조각 9개, `userData.dir` 날아갈 방향), 썰매 `buildSled`(자리 `SLED.seats` 앞 z=+0.24·뒤 z=−0.3, 높이 0.22), 썰매 길 가운데 선 `SLED_RUN.path`(높이는 `heightAt`), 출발대 `SLED_RUN.deck`(3줄).
- **옷:** `createXmasAvatar({rigUrl,toon,look:{outfit:'santa'|'sweater'|'elf',hat:null|'santa'|'antlers'|'beanie'|'elf'|'none',scarf:null|'stripe'}})`. 머리 칸은 하나라 선물 모자·머리띠를 쓰면 옷 모자 대신 그것을 쓴다. 줄무늬 목도리를 두르면 산타 털 깃 대신 목도리가 보인다. 선물 옷은 이 기기에 남긴다 [확정 11-16] — 저장은 월드개발.

## 5. 성능 (PC 1600×900, 동동이 12명 포함 미리보기)

- 그리기 호출 약 370~510회/프레임(그림자·외곽선 패스 포함), 휴대폰 상한(`mobile=1`) 약 370~400회. 처음엔 900~1,500회였다 — 빈 장식 자리 960개를 다 그리던 것과 소품 조각을 따로 그리던 것을 고쳤다(장식은 단 것만 그림, 소품은 재질별로 합침: 집 한 채 28개 → 6개).
- 삼각형 약 150만~180만/프레임. 이 중 미리보기 동동이 12명이 약 59만(한 명 약 4.9만)이다. 광장에 20명이 모이면 사람이 가장 큰 몫이 된다 → §7 가벼운 동동이.
- 휴대폰: 땅 그림자 해상도 1024, 숲 170그루, 눈 1,800송이, 가로등 점광원 없음(바닥 빛 원판만).

## 7. 남은 일·인계

**월드개발과 함께 정할 것**
- **가벼운 동동이(먼 거리용):** 휴대폰은 다른 사람 2명만 동동이로 그린다(`multiFullCap`). 20명 광장에서는 먼 사람용 가벼운 몸이 필요하다(체험설계 §9-1 ⚠️). 지금 동동이 한 명은 약 4.9만 삼각형·메시 약 16개다.

**이번 카드 밖(후속 제안 — 대표 요청 시 진행)**
- 동작: 장식 달기(팔 뻗기)·통나무 앉기(흡연장 벤치 앉기 재사용 확인 필요)·손 녹이기·눈덩이 밀기·눈 뭉치기·던지기·맞음·눈 털기·썰매 앉기·만세.
- 효과 연출: 눈투성이 3단계, 트리 점등 연출 다듬기, 눈사람 완성 반짝임, 썰매 눈보라.
- HUD 그림: 장식 8종·선물 아이템 6종·카드 그림 3종의 64px 단추 그림(월드디자인과).
- 선물 아이템 중 입는 것 외 3종(오너먼트·눈송이 스티커·코코아 들기)의 손 소품.

**알려 둘 점**
- 휴대폰 블룸(절반 해상도)에서 전구·별 빛이 네모지게 번진다. 카툰 후처리 공통 동작이라 이번에 고치지 않았다(등산 밤 화면과 같음).
- 크기·자리 숫자는 월드디자인 추천 배치를 화면으로 맞춘 [추천안]이다. 광장 반지름은 12.5m가 아니라 17m로 넓혔다(모닥불 의자·우체통이 돌바닥 안에 들어가도록).
- 실제 장소 참고 없음. 모두 게임 속 마을이다. 음주·흡연 소품 없음(모닥불 곁은 코코아·마시멜로·담요·장작).
