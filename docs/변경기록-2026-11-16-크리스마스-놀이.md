## 사용자에게 달라지는 점
- **선물 우체통:** 우체통 옆 `🎁 선물 보내기` → 누구에게(광장 사람·🎄 광장 모두) → 선물 6개 → 카드(그림 3 + 글 60자·기본 문구 4) → 확인·보내기. 받은 사람은 위에 알림 5초 + 📬 숫자, 카드를 열면 상자가 풀리고 [입어 보기]/[트리에 달기]/[코코아 받기]. 입는 선물은 이 기기 옷장에 남음. 광장 모두에게 보낸 카드는 「모두의 카드」 판(최근 5장). 사람 카드·사람 목록에도 🎁.
- **모닥불:** `🔥 앉기` → 가장 가까운 빈 자리(8자리)로 걸어가 통나무에 앉음(흡연장 벤치 앉기 자세·다리 그대로). 앉으면 카메라가 천천히 불 쪽으로. `🙌 손 녹이기`·`🍫 코코아`(선물 받았을 때)·`↩ 일어나기`, 걷기 입력이면 일어남. 다른 사람 화면에도 앉은 모습·손 녹이기가 보임. 모닥불 6m 안 말풍선은 크고 6초.
- **소리:** 모닥불 탁탁(멀면 작게, 앉으면 크게)·장식 딸랑·우체통·선물 풀기·눈덩이·썰매 쉬익과 방울. 위 오른쪽 🔊로 끄기(이 기기에 저장). 모두 코드가 직접 만드는 소리(외부 음원 없음). 캐럴은 아직 없음.
- **⛄ 눈사람:** 마당에서 `눈덩이 만들기` → 걸어서 밀면 굴러가며 커짐(같이 밀면 1.5배·2배, 큼을 혼자 밀면 느림) → 작은 눈덩이를 큰 눈덩이 옆에 두고 `⬆ 올리기` → `🎨 꾸미기`(눈·코 필수 + 입·팔·모자·목도리) → `완성!` → 트리 앞 전시 8자리, 이름판에 참여한 사람 이름. 모두에게 "눈사람 완성!" 알림. 3분 안 건드린 눈덩이는 녹음.
- **❄️ 눈싸움:** 마당 안에서만. PC `F`(정면)·화면 클릭(누른 곳), 휴대폰 `❄️` 짧게 = 앞쪽 가장 가까운 사람 자동 조준, 길게 누르고 끌기 = 방향·거리 조준(바닥 고리). 손에 3개(🤲 눈 뭉치기 1초·3초마다 저절로 1개). 맞으면 머리·몸에 눈이 쌓이고(최대 3단계, 5초 뒤 털어냄) "퍽", "○○의 눈덩이!"/"명중!". 마당 밖·모닥불 쪽은 절대 안 맞음.
- **🛷 눈썰매:** 출발대 `타기`(3줄, 차 있으면 "앞 썰매가 출발하면…") → 5초 안에 옆 사람이 `👥 둘이 타기` → 앞사람 [같이 타요] → `출발!` 또는 5초 뒤 3·2·1 → 좌우만 조종(A/D·←/→·조이스틱, 휴대폰 ◀ ▶ 88px) → 둔덕에서 "와!", 눈 더미에 "푹!" → 멈춤 구역에서 내림 → `⬆ 언덕 위로`. 뒷사람은 `🙌 만세`. 다른 사람 화면에도 썰매가 내려감. 한 번 약 6초.
- **화면 공통:** 오른쪽 아래 행동 단추 줄(큰 단추 + 보조 2개, 키 E·R·Q·F 표시). 구역에 들어가면 이름 띠(처음은 규칙 한 줄). 큰 창이 열리면 💬 단추를 접고 걷지 않음. 휴대폰 세로에서 위 둥근 단추(📬·🔊·👕)는 오른쪽에 세로로, 장소 칩은 왼쪽에.
- **서버가 끊기면:** 놀이 요청은 보내지 않고 "연결이 돌아오면 다시 눌러 주세요", 전시 눈사람·모두의 카드는 마지막 모습 그대로. 혼자 둘러보기에서도 모닥불·눈사람·눈싸움(혼자)·썰매가 됨(선물은 안내만).

## 구조
- 판정(서버·혼자 모드 공용, three 없음): `src/christmas/room-play.js`(선물·자리/줄 겹침·눈사람·눈싸움·썰매 요청 중계) ← `gift-state.js`·`snowman-state.js`·`snowfight.js`. 서버 `server/rooms.mjs`가 크리스마스 방마다 하나(트리와 같이 빈 방 5분 뒤 초기화), 화면은 `play-net.js`가 서버 모드면 서버로, 아니면 직접 판정.
- 화면: `gift-ui.js`·`campfire.js`·`snowman-play.js`·`snowfight-play.js`·`sled-play.js`(+계산 `sled.js`)·`poses.js`(앉기·손 녹이기·밀기·뭉치기·만세·코코아·던지기 — 흡연장 `createPoser` 재사용)·`audio.js`. 연결은 `main.js`(행동 단추 고르기 `currentActions`, 키, 구역 띠, 카메라).
- 규격(`multi-protocol.js`): 크리스마스 메시지에 `gift:send`·`snow:*`·`sb:throw`·`sled:ask|ok|no` 추가, act 칸 `st`(모닥불 1~8)·`wm`·`cc`·`sl`(썰매 0~5)·`sp`·`pu`·`pk`. 남이 쓰는 자리·줄은 서버가 빼고 `seat:no`·`sled:busy`.
- 공용 파일: `src/hiking-chat-ui.js/.css`에 `bubbleFor(id)` 옵션(없으면 등산·흡연장 그대로), `src/lounge/spots.js`에 뼈 도구 내보내기 `POSE_TOOLS`(흡연장 동작 같음), `src/christmas/tree-state.js` `put(…,{free})`(선물 오너먼트), Dockerfile·.dockerignore에 판정 파일 5개.

## 개발 결정(대표 미확인 — 숫자는 바꿀 수 있음)
- 썰매 최고 9m/s(서버 순간이동 한도 12 아래), 출발대에서 2.6m/s로 밀고 나감, 멈춤 구역 2.6m 안에서 섬.
- 눈덩이: 1m 밀 때 반지름 4.5cm(혼자 작음→큼 약 11m), 한 번에 0.8m, 미는 사람은 서버가 아는 자리에서 1.5m+반지름 안.
- 모닥불 `앉기` 단추는 통나무 바깥 2.2m 안. 받은 선물은 끊긴 사람(재접속 유예) 몫을 60초 들고 있음. 선물 오너먼트 몫은 최대 3.
- 내 컴퓨터 모드(서버 없이 같은 브라우저 창끼리, 개발용)에서 눈사람 마당은 창마다 따로(눈싸움·선물만 창끼리 보임).
