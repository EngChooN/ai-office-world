# 2026-11-23 인형뽑기 무료 코인 하루 15개 (월드개발)

대표 결정(월드기획 전달): 무료 코인을 하루 15개로. 매일 15개로 초기화, 전날 남은 코인은 이월하지 않음, 최대 30개 누적 규칙 폐지. 코인 판매는 계속 없음.

## 바뀐 것
- 조절값 `CLAW_TUNING.coin` = `{daily:15,cost:1}` (`cap` 삭제). `grantDaily`: 서울 날짜가 바뀌면 `coins = 15`(더하지 않음). 반환 = 지금 코인 수.
- 저장 `coinV:2` 추가. 옛 저장(표시 없음 = 10개씩 더해 30개까지 모으던 규칙):
  - 어제 이전에 받았으면 → 그냥 새 규칙(오늘 15개).
  - 오늘 이미 받았고 15개보다 적으면 → 15개까지 채워 줌(기록 「오늘의 코인을 15개로 채웠어요」).
  - 오늘 이미 받았고 15개보다 많으면 → 오늘은 빼앗지 않고 그대로, 다음 날 15개.
- 화면 문구: 첫 알림 「오늘의 코인 15개 · 매일 0시에 15개로 다시 채워져요」, 코인 탭 「/ 하루 15」·「남은 코인은 다음 날로 넘어가지 않아요」, 규칙 카드 안내 글, 기록 「오늘의 코인 15개(어제 남은 n개는 넘어오지 않아요)」. 「30개까지만 모여요」 알림 삭제.
- 코인 없음 카드는 조절값을 읽어 「내일 0시에 15개를 또 받아요」로 저절로 바뀜.
- 기계 대수는 그대로(월드디자인 설계 뒤 별도).
