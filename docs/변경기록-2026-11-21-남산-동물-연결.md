# 남산 동물 연결 (2026-11-21, 월드개발)

상위 업무 「남산에 동물 상호작용 넣기」 2/3단계. 관악산 동물(고양이·까치·다람쥐·멧토끼)과 반응·말풍선·효과음·함께 걷기 놀람 중계를 남산 게임에 붙였다. 출현 구역은 1단계 추천안(대표 미확인) 그대로다. 커밋·배포는 하지 않았다.

## 1. 바꾼 것

| 파일 | 내용 |
|---|---|
| `src/animal-zones.js` | 산별 판정 옵션 `lanes = {laneLimit, inForbid, step, allows?}`(안 주면 `GWANAK_LANES` = 관악산 `animal-lanes.js`, 예전과 같음), `zone.minOffset`(종류별 최소 거리보다 크면 그것). `zoneSpawns(…,{lanes})`·`wanderAt(…,lanes)` |
| `src/trail-world.js` | 옵션 `height`·`sites`·`zones`·`measure`·`halfWidth`·`lanes`·`treeNear`(안 주면 관악산 지형·코스 그대로). F 키용 `interact()`·`chipActive()`(관악산은 부르지 않음) |
| `src/trail-hud.js` | `installTrailHud(doc,win,{snack:false})` = 초콜릿 줄 없이 칩·즐길거리 줄만 |
| `src/namsan/namsan-animal-lanes.js` | `namsanTrailLanes(L,end)`: 길가 1~5m는 `allows`, 길 위·가장자리 1m 안(길을 가로지르는 걸음)은 금지만 봄. 성곽 선분·계단 측벽을 8m 칸 색인으로(판정 1회 약 60µs → 3µs, 53만 점 비교 결과 같음) |
| `src/namsan/game.js` | 동물 연결: 실제 그린 성곽·시설 배치(`ia.userData.plan`)로 안전 범위, 높이는 길 가까이 노면·그 밖 그려진 지형 면, 다람쥐 나무 = 길가 숲 띠 나무. 고양이에게 들른 동안 몸 자리·카메라·걸음(관악산 main.js와 같은 순서), F = 칩 누르기, 함께 걷기 act에 쓰다듬기 동작 |
| `src/mountains/namsan-page.js` | `NAMSAN_FEATURES.animals: true` |

관악산 쪽 기본값은 그대로다. 공용 파일을 고쳐서 관악산도 아래 3절로 다시 확인했다.

## 2. 정한 것(개발 결정·대표 미확인)

- 남산에서는 동물이 길 가장자리에서 1m 안쪽(경계석 둘레)에는 나오지 않는다(1단계 자료의 1~5m). 관악산 까치(0m~)·토끼(0.8m~)보다 조금 떨어진다.
- 고양이·까치·토끼는 관악산처럼 길을 건너갈 수 있다. 다만 계단 측벽·성곽·차로를 지나는 걸음은 막힌다(계단 구간에선 건너지 않음).
- 남산에는 산스장·벤치(관악산)·먼지털이기·초콜릿·헥헥/쥐가 없으므로 「벤치 고양이」·「초콜릿 다람쥐」 반응은 나오지 않는다(기획 범위 밖).

## 4. 남은 점

- 실제 아이폰·안드로이드에서 직접 보지 못했다(에뮬레이션만).
- 토끼가 길가 덤불(그림의 덤불층)과 몸이 겹쳐 보이는 경우가 있다. 덤불 자리는 안전 범위 판정에 없다(관악산도 덤불은 보지 않음). 화면상 큰 문제는 아니라 그대로 두었다.
- 출현 구역(종류·거리)은 대표 미확인 추천안이다.
