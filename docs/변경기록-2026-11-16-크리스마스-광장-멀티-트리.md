## 한 것
- **새 페이지 `/christmas/`** (`christmas/index.html` → `src/christmas/main.js`, `vite.config.js` PAGES). 허브 카드 `온라인 크리스마스 · 눈마을 광장`(맨 뒤, 그림 `ART.village` 늘 밤).
- **입장 흐름은 기존과 같다:** 허브 → 카드 → 서버 카드 전체 화면(`server-pick.js` `PICK_LABELS.christmas`: `눈마을 광장 1~3서버`, 닉네임 칸, `⛄ 혼자 둘러보기` + "트리 장식은 내 화면에만" 한 줄) → 광장. `?multi=눈마을-1`은 바로 참가.
- **서버**(`server/rooms.mjs`): 체험 `christmas`(`EXPERIENCES`), 체험별 정원 `EXPERIENCE_MAX={christmas:20}`(등산·흡연장 30은 그대로, 환경 변수 `MAX_PER_ROOM_CHRISTMAS`), 방 키 `christmas:눈마을`.
- **트리 동기화**: 규칙은 `src/christmas/tree-state.js`(서버·화면 공용, three 없음 → 서버 이미지 Dockerfile·dockerignore에 추가). 120자리·장식 8종·1분 3개·내 장식 10개·되돌리기 내 것 60초·별 40개부터 1번.
  - 서버가 판정: `tree:put|undo|star` → 모두에게 `tree:set|del|star`, 실패는 보낸 사람에게 `tree:no {reason,wait,near}`. 들어오면 `{t:'tree',s,star}` 전체 상태(나중에 온 사람도 같은 트리).
  - **초기화**: 방에 아무도 없는 채로 5분(`TREE_RESET_MS`, 개발 결정) 지나면 버림. 디스크에 쓰지 않음.
  - 화면: `src/christmas/tree-play.js`. 혼자·내 컴퓨터 모드는 같은 규칙으로 화면이 판정. 다시 연결 중·끊김에 누른 것은 버리고 "연결이 돌아오면 다시 눌러 주세요". 끊겨도 트리는 마지막 모습 유지.
- **20명 접속·이동·말풍선**(`src/christmas/multi.js`): 흡연장과 같은 전송(위치 10Hz·act). act `{o 옷, hat, sc 목도리, d 꾸미는 중}`으로 **고른 옷이 상대에게 보임**, 꾸미는 사람 이름표에 🎄.
  - 몸: PC는 19명 모두 동동이, 휴대폰은 가까운 6명 동동이 + 나머지 **가벼운 동동이**(`src/christmas/lite.js`, 꼭짓점 색 메시 하나 약 1천 삼각형, 월드개발 임시 모양 — 월드아트가 다듬을 수 있음). 22m 넘게 먼 사람은 이름표 숨김.
- **채팅 안전**(대표 결정 11-16: 세 체험 모두): `createChatGuard`(`multi-protocol.js`) — 기존 속도 제한 + 같은 말 세 번째 막기 + 1분 3번 막히면 30초 쉬기. 서버 `{t:'c-limit',reason:'rate'|'repeat'|'mute',wait}`, 내 컴퓨터 모드도 같은 규칙. 공용 채팅 창(`hiking-chat-ui.js`)에 `ns·title·quick·cls·notice` 옵션(크리스마스 ns `xmas`), 막힌 글은 입력칸에 되돌림, 쉬기 동안 입력칸·칩 잠금 카운트다운. 등산·흡연장 문구도 반복·쉬기 이유를 보여 줌. 금칙어는 기존 서버 목록 그대로.
- **음소거**(대표 결정: 완전히 숨기기): 사람 카드(이름표 누르기)·광장 사람 목록에서 🔇 음소거·🚩 신고(신고하면 음소거도). 몸·이름표·말풍선·채팅 모두 사라짐, 상대에게 안 알림, 이 기기 저장(`xmas-moderation`). 음소거한 사람의 장식은 트리에 남고 이름만 숨김.
- **화면**(`src/christmas/hud.js/.css`): 위 가운데 연결 칩(`🎄 눈마을 광장 1서버 · 👥 12/20`/`⛄ 혼자 둘러보기`/`다시 연결 중`/`혼자 보기 · 다시 연결`) → 사람 목록, 트리 진행 `🎄 47/120`·⭐, 👕 옷 고르기(선물 옷은 이 기기에 가진 것만), 트리 옆 `🎄 장식 달기(E)`, 장식 모드(트리 둘레 카메라·장식 8종 PC 8칸/휴대폰 4×2·남은 개수·되돌리기·별·✕/Esc, 휴대폰은 자리 고른 뒤 [달기][취소]), 💬 왼쪽 아래.
- 이동·충돌: `src/christmas/collide.js`(울타리 원·언덕 통로·원·돌린 상자), 흡연장 입력(`lounge/input.js`) 재사용.
