# 변경기록 2026-11-19 — 아이스링크 스케이트 타기 A안 (월드개발)

대표 확정(월드기획 전달): A안 「가벼운 미끄러짐」, 범위는 날·자세·움직임·효과·소리 전부. 시안 `docs/크리스마스/스케이트-타기-시안-v1.html`, 계산 `artifacts/skate-design/sim.mjs`.
이번 커밋은 월드개발 몫(움직임·소리·연결 틀·다른 사람 자세)입니다. 스케이트화·동작 6종·얼음 효과 그림은 월드아트가 만들면 연결합니다.

## 1. 바뀐 것
- **링크 안 움직임 = A안** (`src/christmas/skate.js` 새 파일, `rink-play.js`가 부름)
  - 최고 2.4m/s, 1.6초에 90%, 손 떼면 감속 1.15m/s² + 속도×0.08로 약 2.2m 미끄러짐
  - 몸(날) 방향으로만 잘 나감. 입력 쪽으로 몸을 돌리는 빠르기 300°/s(느릴 때) → 150°/s(최고 속도) = 커브. 휴대폰 조이스틱 8방향도 이 빠르기로만 돌아 매끄럽게 꺾임
  - 옆미끄럼 잡힘 7/s(옆 속도의 85%는 앞으로 옮겨 감)
  - 가는 쪽과 120° 넘게 반대로 누르면 제동 3.6m/s², 0.5m/s 아래면 제자리에서 바로 돎(720°/s)
  - 벽: 튕기지 않음. 벽 쪽 속도만 버리고, 벽 쪽으로 미는 힘은 벽을 따라가는 쪽으로 돌림. 세게(벽 쪽 0.6m/s 넘게) 닿으면 나란한 속도 80%만 남기고 0.3초 휘청
  - 문 안쪽 1.5m 안은 걷기 속도(1.37m/s)까지만(초과분을 14m/s²로 줄임 — 시안에 감속 세기가 없어 개발 결정, 6m/s²로는 1.2m 안에서 1.51m/s가 나와 올림)
  - 다른 사람과는 지금처럼 부딪히지 않음(겹쳐 지나감)
  - 처음 들어오면 안내 「스케이트장에 들어왔어요 · 밀면 쭉 미끄러져요 · 반대로 당기면 멈춰요」
- **자세 판단** `createSkateGait`: stand·push(좌·우 번갈아 0.5초)·glide1(밀어낸 발 들고 0~0.6초, 최고 속도 근처면 세 번째마다 1초)·glide2(손 뗌)·carve(기울기 5° 넘게 돌 때, 기울기 = 속도×도는 빠르기, 최대 15°)·brake·wobble. 그림이 오기 전에는 밀 때만 짧은 보폭(×0.55) 걷는 다리, 활주·제동은 다리 멈춤
- **소리 3종**(`audio.js`, 합성·파일 없음): 활주 「쉬익」(속도에 따라 커짐·높아짐), 밀기 `skate-push` 「슥」, 멈춤 `skate-stop` 「샤악」. 소리 끄기·크기를 따름. 내 소리만(다른 사람 소리는 시안대로 후속)
- **효과 자료** `createSkateFx`: 날 자국(사람마다 PC 40·휴대폰 20조각, 4초에 흐려짐)·얼음 가루(PC 80·휴대폰 30알), 효과를 남기는 사람은 나 + 가까운 PC 8명·휴대폰 3명. 그림은 없음(월드아트 그리기가 자료를 읽음)
- **다른 사람 자세(서버 변경 없음)** `createSkateTrack`: 받은 위치·몸 방향에서 속도·가속·도는 빠르기를 알아내 같은 자세 함수에 넣음. 누름 = 감속이 0.6m/s²보다 약함, 제동 = 1.75m/s² 넘게 줄어듦(손 뗀 감속은 최대 약 1.35), 휘청 = 순간 크게 줄어듦. `multi.js`가 `ctx.skateAt`로 부름(링크 밖이면 null → 예전 그대로)

## 2. 월드아트 연결 자리(그림이 오면)
`createRinkPlay({art})`·`rink.setArt(art)`. `main.js`는 `village.festive?.skate`를 art로 넘김(지금은 없음 → null). art에 있는 것만 부릅니다(`SKATE_ART_API`).
- `wear(avatar,on)` 링크 안이면 날을 신기고 몸 4.5cm 올림, 밖이면 벗김(나·다른 사람 모두)
- `pose(avatar,gait,dt)` `gait.pose`·`side`(±1)·`k`(0~1 진행)·`lean`(rad, 도는 안쪽 +)를 몸에 입힘. art.pose가 있으면 걷는 다리 보폭은 0으로 넘김
- `drawFx(fx,dt)` `fx.marksOf(owner)`(owner = 'me' 또는 사람 id, {x,z,h,side,age})·`fx.powder`({x,y,z,age}), 수명 `SKATE_FX.life` 4초·`powderLife` 0.7초
월드아트가 다른 이름·모양으로 만들면 이 연결 몇 줄만 맞추면 됩니다.

## 4. 못 한 것
- **실제 손맛은 사람이 타 봐야 압니다.** 숫자는 시안과 맞지만, 실제 휴대폰 손가락·실제 키보드로 탄 느낌은 확인하지 못했습니다.
- 스케이트화·자세·효과 그림이 아직 없어 화면에는 예전처럼 짧은 걸음만 보입니다(밀 때만 걷고 미끄러질 땐 멈춤).
- 공개 멀티 서버(다른 곳 맥)로는 시험하지 않았습니다. 서버 코드는 바꾸지 않아 다시 켤 필요는 없습니다.
- `artifacts/skate-design/sim.mjs`의 「지금」 모델은 예전 `ICE` 값을 읽어 이제 돌리면 맞지 않습니다(시안 기록용이라 두었음).
