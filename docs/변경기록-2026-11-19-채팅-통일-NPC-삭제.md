### 1-1. 같이 바뀐 작은 것
- ✕ 닫기는 줄 오른쪽 끝(엄지 자리). 위 💬를 다시 눌러도 닫힘. 게임 빈 곳을 누르면 키보드만 내려감(예전 그대로).
- 휴대폰은 채팅을 열어도 키보드가 바로 오르지 않음(입력칸을 눌러야 오름, 시안 「누르면 키보드가 오름」). PC는 열면 바로 입력칸에.
- 크리스마스 「전화번호·주소·SNS 아이디는 적지 마세요」 안내는 예전 창 안 줄 → 처음 열 때 지난 말 자리에 회색 한 줄(한 번 열었다 닫으면 사라짐).
- 보내기 제한 안내(「잠깐만요, 조금 천천히」 등)는 지난 말 자리에 갈색 한 줄로 2.4초.
- 밤(등산·흡연장 `data-hud-time=night`)에는 말하기 줄도 수첩 밤 종이 색.

### 3-1. 휴대폰 화면 점검(verify-chat-unify) — 30개 상황 모두 통과
두 사람 접속, 세 콘텐츠 × 세로 390×844·가로 844×390. 상대가 실제로 세 마디를 보내 지난 말 3줄·머리 위 말풍선이 생긴 상태에서 잼.
- 말하기 줄 부품 = 입력칸·보내기·✕(세 콘텐츠 모두), 빠른 말·동작 칩 0개, 부품 모두 44px 이상.
- 자리: 세로 (0, 784) 390×60 = 맨 아래 꽉 참, 가로 (0, 330) 540×60 = 왼쪽 아래 540px, 키보드 흉내 때 줄 아래 끝 = 키보드 위 끝(세로 493+60·가로 130+60).
- 지난 말: 열림 3줄, 키보드 때 세로 2줄·가로 0줄.
- 채팅 중 보이는 행동 단추 0개(흡연장 피우는 중·크리스마스 눈싸움 마당 포함). 단추 겹침·가림 0건, 창 2개 이상 동시 0건.
- 말풍선: 세 콘텐츠 모두 `uf-bub`, 글자 14px·굵게 800·모서리 14px·최대 240px(세로 화면은 60vw = 234px). 테는 CSS 2.5px인데 브라우저가 2px로 그림(11-18 등산 풍선도 같았음).
- 페이지 오류 0건.

「게임 보임」(단추·창·키보드에 안 가린 넓이, 시안과 같은 4px 칸 방법. 지난 말 띠는 반투명·누르기 통과라 시안처럼 뺌, 띠 넓이는 화면의 3.4%)
