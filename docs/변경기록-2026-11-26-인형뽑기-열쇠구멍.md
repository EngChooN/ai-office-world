# 2026-11-26 인형뽑기 열쇠 기계 구멍 줄이기

대표 제보 「열쇠 기계가 너무 쉬움, 구멍을 더 작게 해도 될 것 같음」(월드기획 지시, 월드공통개발).

## 1. 측정 방법
- `artifacts/claw-design/key-tune/key-rate.mjs [fit,fitRare | 배율] [σms] [판 수]`. 규칙은 게임 코드 `judgeKey`·`keyCellRare`·보장(5번 실패 뒤 성공까지 +0.05칸)을 그대로 부름.
- 사람 손 모델: 8칸 중 하나를 무작위로 노림, 가로·세로 각각 구멍 가운데 도착 시각에 손을 떼되 정규 오차 σ. σ 60ms를 보통 사람으로, 40ms(잘하는 사람)·80ms(서툰 사람)를 같이 봄. 화면 갱신 칸은 기기마다 달라 오차에 묻음.
- 판당 성공 = 보장 없는 판 10만 판, 평균 판 = 보장 포함 2만 번.
- 실제 사람의 σ는 재지 못함(추정). 그래서 숫자는 「안끼리 비교」에 씀.

## 3. 고른 값과 이유
- `CLAW_TUNING.key.fit` 0.14 → 0.09, `fitRare` 0.08 → 0.06. 보장 +0.05·아까움 2배·속도는 그대로.
- 열쇠 몸통 굵기 1.6cm(0.08칸). 희귀 구멍 0.06칸 = 2.4cm가 몸통보다 넉넉한 마지막 값이라 희귀 구멍은 여기서 멈춤(같은 비율 60%면 1.9cm로 몸통과 거의 같음). 보통 구멍만 더 줄임.
- 난이도 순서: 지금은 열쇠가 어떤 기계보다 훨씬 쉬움(평균 1.6판). 바꾼 뒤 열쇠 1·2 < 열쇠 3 < 집게 ≈ 봉 순서. 서툰 손 기준으론 열쇠 3이 집게와 비슷(3.9판). 열쇠는 연습하면 느는 기계라 운에 기대는 집게·봉보다 조금 쉽게 둠. 보장 판은 구멍이 0.14·0.11칸으로 거의 지금 크기라 「계속 안 들어가는 느낌」은 5판 뒤 풀림.
- 배포 뒤 대표 결정(11-26): 이 난이도 그대로 둠(집게·봉보다 조금 쉬움 유지).

## 4. 같이 바꾼 것
- 성공한 판은 밀어 넣는 0.35초 동안 열쇠가 구멍 가운데로 미끄러져 들어감(`claw-rules.js` `keyHole`, `claw-play.js` 내 판·구경 화면). 구멍이 작아져 가장자리 성공 때 몸통이 판에 박혀 보이던 것을 없앰. 판정·저장·전송 값은 그대로(뗀 자리).
- 그림 쪽 기본 구멍(`claw-machines-more.js` holeConf, 미리보기가 씀)도 0.09·0.06.
