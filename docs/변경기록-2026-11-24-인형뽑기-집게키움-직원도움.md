# 변경기록 2026-11-24 — 인형뽑기 집게 키움·벌림 넓힘, 집게 기계 보장 = 직원 도움

- 지시: 월드기획(대표 추가 지적 「집게가 작고 벌어지는 각도가 좁아 큰 인형·봉 상자를 못 잡음」, 월드디자인 검토 「힘센 집게 보장이 효과 없음」)
- 결정: 집게 기계 보장 = **직원 도움**(대표 확인 대기(추천안), 11-24 결재함 질문). 힘센 집게(세기만 올림)는 없앰
- 담당: 월드공통개발(집게 크기·물리·난이도·시험). 옆에서 보기 5건은 월드게임개발이 확인(`변경기록-2026-11-23-인형뽑기-물리-통과수정.md` §6), 봉 집게 색은 월드아트(`claw-bridge.js`)

## 1. 무엇이 문제였나

- **집게 기계:** 내려갈 때 손가락이 61%만 벌어져 발끝 사이가 약 19cm였고, 큰 인형 몸 폭(약 23cm)보다 좁았다. 특별 인형(가장 큼)은 겨눠도 거의 안 잡혔다(3%).
- **봉 기계:** 상자 폭 16cm에 두 발 사이도 약 19cm라 발이 상자 옆으로 못 내려가고 상자 위에 얹혔다.
- **힘센 집게 보장:** 판정을 그림 모양으로 맞춘 뒤(11-23)부터 세기를 올려도 손가락 모양이 그대로라 보장 판 성공 22%로 보통 판(20%)과 같았다. 세기를 더 올리면 손가락이 인형 속으로 1~5cm 파고들어 보였다(11-23 대표 지적과 충돌).

- 통과(그림 기준 0.5cm 넘게 들어간 판): 집게 180판 0판(최대 0.35cm, `probe-claw-vis.mjs`), 봉 1·3·4 각 약 110판 0판(최대 0.06cm, `probe.mjs`).
- 봉 약한 집게: 상자 가운데 7곳 조이면 최대 2.8cm 들림(시험 8cm 아래, `pity-tune/bridge-lift.mjs`).

## 5. 못 한 것·알릴 것

- 실제 휴대폰·사람 손 확인 못 함.
- 흔한·보통 인형은 겨눴을 때 잡히는 비율이 조금 내려갔다(판당 전체는 그대로).
- 직원이 세운 인형은 더미에 기대 조금 기울 수 있다.
- 봉 상자가 막이 봉 끝에 기울어 걸린 채 멈추면(드묾) 저장한 자리를 다시 열 때 약 2cm 미끄러질 수 있다(다른 겨눔 4곳은 1.4mm 안).
- 봉 물리: 판이 끝난 뒤에도 닿음은 계산하되 상자가 멈추는 판정은 그대로(이 둘을 섞었더니 상자가 멈추지 않아 자리 저장이 안 됐음, 브라우저 점검에서 발견해 고침).
- 브라우저 점검 「그림 집게: 바닥에서 조이기 시작」은 조이는 동안 5cm까지 가라앉는 것(11-23 물리)을 허용하게 고침 — 집게가 커져 가라앉음이 자주 보임.
- 집게 그림 크기(0.24m)·처음 자리를 월드아트 파일(`claw-machine-art.js`)에서 바꿨다. 월드아트에 알림. 그림 치수를 바꾸면 판정 값도 같이(시험이 대조).
