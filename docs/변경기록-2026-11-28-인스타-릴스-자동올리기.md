## 안전장치
1. **미리보기 기본:** 옵션이 없으면 영상 검사·본문·첫 댓글 전문·계정·한도만 보여 줌(인스타에는 읽기 요청만). 게시는 `--게시`에 미리보기의 **확인 코드**(영상 sha256 + 본문 + 댓글로 만든 열쇠 앞 6자)까지 맞아야 함 — 미리보기 뒤 내용이 바뀌면 거절.
2. **비밀값:** `.instagram/`에만(파일 권한 600). 저장소 안 폴더면 `git check-ignore`로 무시되는지 확인하고 아니면 멈춤. 화면 출력·오류 글은 모두 가림(토큰 값 그대로·`access_token=`·`client_secret=`). `state.json`에는 비밀값 없음. 토큰 입력은 화면에 안 보이게 받음.
3. **토큰 60일:** `--토큰갱신`(받은 지 24시간 뒤부터), 게시 때 남은 날 15일 이하면 저절로 갱신, 10일 이하면 「⚠️ 만료 임박」(미리보기·`--상태`, `--상태`는 종료 코드 3). 짧은 토큰은 앱 시크릿이 있으면 60일 토큰으로 바꿈(없으면 받은 날 + 60일로 추정 표기).
4. **중복 방지:** 단계마다 `state.json`에 기록하고 다시 실행하면 이어 감. 게시 요청 전 「게시 중」 표시 → 응답을 못 받으면 다음 실행에서 최근 게시물 10개에서 같은 본문을 찾아 이어 받음, 못 찾으면 `--다시시도` 전까지 안 올림. 분명한 거절(오류 응답)이면 그냥 다시 시도. 댓글도 같은 방식(댓글 목록에서 같은 글 찾기). 끝난 내용은 `--새로` 없이 다시 안 올림. 준비 단계는 23시간까지 다시 씀.
5. **하루 한도:** `content_publishing_limit`(quota_usage·quota_total)을 미리보기·`--상태`·게시 직전에 조회, 다 썼으면 올리기 전에 멈춤(문서마다 50 또는 100이라 숫자는 응답 그대로).

## 흐름에서 정한 것(개발 결정·대표 미확인)
- 상태 확인은 1분 기다린 뒤 확인을 5번(= 5분). 끝나지 않으면 영상을 남겨 두고 멈춤 → 다시 실행하면 같은 준비 단계로 이어 확인. ERROR·EXPIRED면 영상 지우고 처음부터.
- 임시 영상 이름 `reels-tmp/reel-<열쇠 10자>-<무작위 8자>.mp4`(밑줄 폴더는 Jekyll이 숨겨서 안 씀). 지우기 실패는 게시 성공으로 보고 `--정리` 안내.
- `share_to_feed=true`(피드에도 보임).
