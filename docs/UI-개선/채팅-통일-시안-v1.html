2. 통일 디자인 — 부품 하나하나

  1. 지난 말 줄 — 말하기 줄 바로 위, 왼쪽부터 최근 3줄. 반투명 갈색 띠·흰 글자 13px, 이름은 노랑(나는 연두). 오래된 줄은 흐리게. 새 말이 오면 위로 밀려 사라짐.
  2. 입력칸 — 채팅을 열면 늘 보임. 비어 있으면 「한마디 해 보세요」. 누르면 키보드가 오름. 글자 16px(아이폰 확대 막음), 높이 44px.
  3. 보내기 — 빨간 둥근 단추. 보내도 키보드는 그대로라 이어서 씀.
  4. ✕ 닫기 — 줄 오른쪽 끝, 엄지 닿는 곳. 위 💬를 다시 눌러도 닫힘. 게임 빈 곳을 누르면 키보드만 내려감.
  5. 머리 위 말풍선 — 세 콘텐츠 같은 종이 풍선 한 모양(테 2.5px·모서리 14px·글자 14px 굵게·최대 240px·4초).

3. A안 · B안 비교 — 휴대폰 세로

열기 전지금 공통 틀 그대로A안채팅 중 행동 단추 숨김(대표 의견)B안큰 단추만 작게 남김(지난번 안 = 커밋본)

키보드 높이는 가정입니다(세로 291px · 가로 200px, 아이폰 한글 키보드 어림). 실제 휴대폰에서 키보드를 띄워 찍지 못했습니다. 키보드가 오르면 A·B 모두 같은 화면(입력 줄만 남김)이라 B안 키보드 그림은 따로 그리지 않았습니다.

5. 채팅 중에도 행동 단추가 필요한 때가 있나

상황채팅 중 그 단추를 누를 일판단
흡연장 · 피우는 중(꾹 들이마시기)많음. 「피우면서 떠드는 곳」이 흡연장의 핵심. 숨기면 한 모금 빨 때마다 채팅을 닫고 다시 열어야 함. (불 붙인 담배는 가만히 둬도 7분이면 다 탐 — 급하지는 않음)큰 단추 작게 남김(예외)
크리스마스 · 눈싸움 한 판 진행 중(던지기)있음. 한 판(90초)은 점수가 걸려 채팅을 열면 맞고만 있게 됨. 다만 이때는 채팅을 잘 안 염(빠른 말이 없어져 키보드로 쳐야 하니 더 드묾).큰 단추 작게 남김(예외)
크리스마스 · 눈싸움 마당에서 그냥 던지기(한 판 아님)적음. 점수 없음. 닫고 던지면 됨.숨김
등산 · 걷기/멈추기적음. 자동 걷기는 채팅 중에도 계속 걸음. 빈 곳을 끌면 직접 걷기도 됨. 멈추려면 닫으면 됨.숨김
흡연장 · 서 있을 때(꺼내기·인사)적음. 인사는 서 있을 때 작은 단추에 따로 있음.숨김

6. 숫자로 비교

「게임 보임」= 화면에서 단추·창·키보드에 가리지 않은 넓이. 배포판·커밋본은 지난 촬영 측정값(11-18), 시안은 이 페이지 그림에서 직접 잰 값입니다. 빠른 말 칩을 빼도 줄 높이(60px)는 그대로라 숫자는 칩이 있던 그림과 같았습니다. 달라지는 것은 줄이 단순해져 「어디를 눌러 말하나」가 한눈에 보이는 점입니다.

「지난 말 자리」= 지난 대화가 쌓여 보이는 넓이. 배포판 등산·크리스마스는 창 안 기록 상자(약 346×63px)지만 창 전체가 화면을 덮어서 게임 보임이 57%대로 떨어졌습니다. 통일안은 지난 말을 게임 위에 반투명 띠로 띄워 같은 3줄을 보이면서 게임을 덜 가립니다.

7. 확인한 것 · 못 한 것

  • 확인함: 배포판 채팅 화면은 11-18 오후, 커밋본은 11-18 밤 실제 게임을 띄워 찍은 그림입니다(2명 접속). 통일안 그림은 그때 찍은 게임 배경 위에 말하기 줄을 그린 것입니다. 숫자는 이 페이지가 그림에서 직접 잽니다.
  • 확인함: 말풍선 크기·커밋본의 말하기 줄 모양·흡연장 동작 칩 연결·등산 인사 칩이 채팅과 따로인 것은 지금 코드에서 읽었습니다.
  • 확인 못 함: 실제 휴대폰 키보드 높이(가정 세로 291px·가로 200px), 아이폰 노치·홈 막대 여백(그림과 숫자에는 넣지 않음. 실제로는 줄 아래에 약 20px가 더 생기며 배포판·커밋본·시안 모두 같게 더해짐), 실제 손가락으로 눌러 본 느낌.
  • 확인 못 함: 썰매 경주·하늘 썰매 조종 중에 채팅을 여는지는 추정입니다.
