## 2. 쓰는 법

```html
<link rel="stylesheet" href="${BASE_URL}icons/icons.css">
<!-- 아이콘만 있는 단추는 aria-label 필수(규칙 §6-9) -->
<button aria-label="소리 끄기" title="소리 끄기">
  <svg class="ic ic-m" aria-hidden="true"><use href="${BASE_URL}icons/sprite.svg#ic-c-sound"/></svg>
</button>
```
- 주소는 꼭 `import.meta.env.BASE_URL` 기준(AGENTS §0).
- 낱개 `<img src=".../common/c-sound.svg">`도 됩니다. 이때 선은 잉크 #4a3618, 면은 그 묶음 기본 색으로 고정이고 밤·체험 색은 안 바뀝니다. **색을 토큰으로 바꾸려면 `<use>`(또는 SVG를 글 안에 넣기)로 쓰세요.**
- **색:** 선 = CSS `color`(기본 `var(--ink)`), 면 = `--ic-point`. 체험 페이지 `<html>`이나 `body`에 `ic-hiking` / `ic-smoking` / `ic-christmas`, 밤에는 `ic-night`를 같이 붙이면 됩니다.
- **크기:** `ic-xs` 14 · `ic-s` 18 · `ic-m` 22 · `ic-l` 28 · `ic-xl` 40px(선 굵기도 같이 맞춰짐). 누르는 칸은 아이콘 크기와 상관없이 44×44px 이상.
- **상태:** 켜짐 = 부모에 `.is-on`(단추 바탕을 포인트 색으로) · 못 누름 = `.is-disabled` 또는 `:disabled` 부모 · 꺼짐 = `-off` 파일 · 연결 중 = `ic-spin`(`c-net-connecting`, 동작 줄이기면 멈춤). 잠김 배지·알림 점·숫자 배지는 규칙 §5대로 CSS로 얹습니다(그림 아님).
- **고정 색 아이콘:** `index.json`의 `color:true`는 색이 곧 뜻이라 포인트 색을 안 따르는 부분이 있습니다(장식 공·별·당근·눈·물·연결 상태 등).

## 3. 확인한 것 / 못 한 것

- 확인: 대응표 130종 모두 아이콘 파일이 있음(스크립트로 대조, 없는 이름 0). 확인 시트 3장(아래)에서 14~40px·밤·켜짐·휴대폰 44px 단추에서 깨짐 없음을 눈으로 봤습니다.
- 확인 시트: `artifacts/icons/sheet-pc.png`(큰 그림·14/18/22/28px·밤·켜짐), `sheet-mobile.png`(390 폭, 44px 단추·14/18px), `silhouette.png`(22px 실루엣 대조).
- 실루엣이 같은 것(뜻은 안쪽 선으로 구분): 흡연장 들이마시기 세기 4종(얼굴 표정), 크리스마스 옷 3종(XL 전용이라 무늬로 구분). 14px에서는 표정이 작으니 S(18px) 이상을 권합니다.
- 확인 못 함: 실제 게임 화면에 붙인 모습(교체는 월드개발). 흡연장 주황 #c8682f·밤 #eb9a62, 크리스마스 밤 #6fbf8f 새 값은 시트에서 읽히는 것만 봤습니다(추천안·대표 미확인).
- 규칙 문서에 대해 그림에서 정한 것: `c-help`는 ❓·📋 안내 다시 보기 공용 물음표, `c-upload`는 깃허브 상표 대신 「종이 + 위 화살」, 공통 닫기류 4개(✕ ← ⋯ ✓)도 만들어 둠(교체 여부는 개발 판단).
