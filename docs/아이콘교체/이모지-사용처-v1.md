## 7. 다음 단계에 참고할 점

- **같은 뜻, 여러 자리**: 🔊/🔇(흡연장·크리스마스), 💬(공용 채팅·흡연장·말 고르기), 💌·💗(등산·흡연장 설정), 연결 상태 ⏳ 💻 🟡 🟢 🔄 ⚠ 🚪(등산 칩·흡연장 단추·크리스마스 칩이 거의 같은 세트) — 공통 아이콘 한 벌로 묶기 좋습니다.
- **같은 그림, 다른 뜻**: ⛄(등산 겨울 / 크리스마스 혼자·끊김·눈사람), 🔥(흡연장 불·독한 맛 / 크리스마스 모닥불), ❄️(날씨 눈 / 멘솔 / 눈싸움 / 스티커), 🌿(여름 / 비흡연자 / 눈사람 팔) — 아이콘을 체험별로 나눌지 정해야 합니다.
- **글자 사이에 섞인 것**: 단추 글자 안에 이모지가 붙어 있는 곳(예: `'🎁 선물 보내기'`, `'📻 91.9'`)은 글과 아이콘을 나눠야 그림으로 바꿀 수 있습니다. 데이터 표(`ic:`·`icon:`)로 이미 나뉜 곳은 바꾸기 쉽습니다.
- **CSS 글자로 그린 것**: `content:'…'`로 넣은 이모지(🔒 ☝ 👋 🙇 🤝 ⏳ 💪)는 CSS에서 바꿔야 합니다.
- **알림·말풍선 문장 속 이모지**는 그림으로 바꾸기 어렵고, 빼거나 그대로 둘지 정하는 편이 현실적입니다(추정).
