## 1. 범위

### 교체함
- `이모지-사용처-v1.md` §1 **화면 UI 376곳·130종**(허브·공용·등산·흡연장·크리스마스).
- 같은 계열의 일반 글자 기호(✕ 닫기 · ← 뒤로 · ⋯ 더 보기 · ✓ 확인)는 이모지가 아니라 130종에 없지만, 기획서 「닫기류」에 맞춰 **공통 세트에 4개 자리를 같이 만듭니다**(추천안·대표 미확인). 교체 여부는 개발 단계에서 정합니다.

### 제외(그대로 이모지·글자로 둠)
| 제외 | 이유 | 위치 |
|---|---|---|
| 사용자가 채팅·선물 카드·닉네임·의견 글에 **직접 입력한** 이모지 | 사용자의 글입니다. 바꾸거나 걸러 내지 않습니다 | 사용처 문서 §2 「직접 입력」 표 |
| 사용자가 **보내는 말**의 값: 등산 빠른 말 칩 👍, 흡연장 인사 단추가 보내는 👋 😮‍💨 🙆, 흡연장 말 고르기 칩 글(😭 🍜 🌶 🙂 💪 📉 ☕ 🙈 🎤) | 글자 그대로 다른 사람 화면·말풍선에 갑니다. 그림으로 바꾸면 받는 쪽과 어긋납니다 | 사용처 문서 §2 |
| 캐릭터·NPC **말풍선 대사** 속 이모지 26곳 | 문장과 같이 읽히는 감정 표현입니다 | 사용처 문서 §3 |
| 3D 표지판 3곳, 화면 밖·미사용 추정 12곳 | 월드개발이 판단해 목록에 결과를 적습니다(기획서) | 사용처 문서 §4·§5 |

- **단추 모양과 보내는 값은 따로 봅니다.** 흡연장 인사 단추(👋 😮‍💨 🙆)는 단추에 그리는 그림만 아이콘으로 바꿀 수 있고, 눌렀을 때 채팅으로 가는 글자는 이모지 그대로입니다. 이번 1차에서는 단추 그림도 그대로 둡니다(보내는 값과 단추가 달라 보이면 헷갈림, 추천안·대표 미확인).
- **확인 필요(월드개발):** 크리스마스 채팅 창의 빠른 말 칩 🎄(`src/christmas/main.js:308`)가 채팅으로 그대로 가는 값이면 제외 쪽으로 옮깁니다. 사용처 문서에는 화면 UI로 들어가 있습니다.
- **의견 보내기 깃허브 글 제목**의 🐞 💡 💬은 게임 화면 밖 글이라 글자로 둡니다. 화면 카드 안 고르기 칸만 아이콘으로 바꿉니다.

## 2. 크기 단계와 누르는 칸

### 2-1. 아이콘 크기 5단계 (추천안·대표 미확인)

지금은 9px부터 72px까지 글자 크기가 19가지로 흩어져 있습니다. 아래 5단계로 모읍니다.

| 단계 | 크기 | 선 굵기(실제 화면) | 어디에 | 지금 크기(사용처 문서) |
|---|---|---|---|---|
| XS | 14px | 1.5px | 문장·꼬리표·이름표·알림 줄 앞, 진행 막대 끝 | 9~14px, 「본문」 |
| S | 18px | 1.75px | 글이 있는 단추·칩·시트 항목·창 제목 | 13.5~19px |
| M | 22px | 2px | 아이콘만 있는 둥근 단추(44~48px 원), 탭 줄, 고르기 칸 | 17~24px |
| L | 28px | 2.25px | 큰 행동 단추·큰 도장(96px)·썰매 조종(휴대폰 88px 원 안에서는 36px로 키움) | 22~34px |
| XL | 40px 이상 | 2.5px | **그림 아이콘**: 선물 상자·카드 그림·도장 칸·불러오는 화면 제목 | 34~72px |

- 크기가 커져도 선이 같이 굵어지면 뭉개지므로, 단계마다 선 굵기를 따로 정합니다(위 표).
- **14px보다 작게 쓰지 않습니다.** 예외는 아이콘 위에 얹는 작은 배지(자물쇠 배지 12px, §5)뿐입니다. 지금 9~10px인 곳(🔒 잠금 표시 9px, 🤝 이름표 10px)은 각각 배지 12px·XS 14px로 키웁니다.
- XS·S는 글자와 같이 쓰므로 **글자 크기 × 1.25~1.4배**로 고릅니다(13px 글 → 18px 아이콘 아님, 14px 아이콘이 맞음 · 14~15px 글 → 18px).
- XL 그림 아이콘은 세부(리본·주름·그늘)를 더 그린 따로 된 그림입니다. 같은 뜻의 작은 아이콘을 그냥 키우지 않습니다.

### 2-2. 누르는 칸 (기존 규칙 유지)

- 누를 수 있는 것은 **휴대폰·PC 모두 44×44px 이상**입니다(기존 AGENTS §3, 흡연장·크리스마스 CSS 머리말). 아이콘이 14px이어도 누르는 칸은 44px입니다.
- 이웃한 누르는 칸 사이는 **8px 이상** 띄웁니다.
- 자주 누르는 큰 행동 단추는 56px 이상(지금 큰 도장 96px·썰매 조종 88px 그대로).
- 안전 영역(아이폰 노치·홈 막대) 안에 둡니다(기존 `--sl/--sr/--st/--sb`).
- 지금 사용처 문서에서 「확인 못 함」인 단추(서버 고르기 창 혼자 하기, 안내판 ◀ ▶, 같이 등산하기, 산스장 기구 단추, 간식 줄)는 교체할 때 44px을 같이 확인합니다.

## 3. 모양 — 동동이 화풍에 맞추기

### 3-1. 기준으로 삼은 것 (확인한 사실)
- 동동이 그래픽: 3단 툰 명암, 얇은 외곽선, 둥글고 큰 머리(2.1등신) — AGENTS §1·§10.
- 화면(HUD): 「등산 수첩」 크라프트 종이 톤. 잉크 `--ink #4a3618`, 종이 `--paper #fbf3df`, 빨간 도장 `--stamp #b9472f`, 둥근 모서리 4~9px, 살짝 기운 도장(-3°) — `src/hud-notebook.css` 1~17줄. 흡연장·크리스마스도 같은 토큰을 씁니다.

### 3-2. 그리기 규칙 (추천안·대표 미확인)

| 항목 | 규칙 |
|---|---|
| 격자 | 24×24, 바깥 1칸 비움(그림은 22×22 안) |
| 선 | 잉크 한 색, 끝·이음 둥글게. 굵기는 §2-1 표 |
| 면 | **선 + 면 한 가지 색(툰 2단)**. 면은 선 안쪽을 다 칠하지 않고 큰 덩어리 한 곳만 칠함(예: 종 몸통만, 말풍선 안만) |
| 그늘 | L·XL만 면 색을 한 단 어둡게 한 그늘 한 조각 허용(툰 3단 느낌) |
| 모서리 | 네모 모서리 반지름 2(24 격자 기준). 뾰족한 모서리는 별·불꽃·번개처럼 뜻이 있을 때만 |
| 기울기 | 똑바로 그림. 「도장」류(🔖 매너 도장·🏅 완등 카드·⛰ 완등 도장 자리)만 -3° 기울여 기존 도장과 맞춤 |
| 사람 모양 | 사람이 들어가는 아이콘(혼자·사람들·인사·셀카·표정)은 **동동이 머리 실루엣**(둥글고 큰 머리, 몸은 짧게)으로 그림. 옷·소품은 넣지 않음(체험 공통이라서). 표정 아이콘(흡연장 들이마시기 세기)은 동동이 얼굴의 점 눈·짧은 입 |
| 글자 | 아이콘 안에 글자·숫자를 넣지 않음(? · ! 기호만 예외) |
| 외부 상표 | 깃허브 문어(🐙)처럼 다른 회사 상표는 그리지 않고 「올리기」 그림으로 바꿈(상표 사용 조건을 피함) |
| 출처 | 모두 직접 그림. 외부 아이콘 세트를 쓰면 이름·이용 조건을 `assets/출처-라이선스.md`에 적음(기획서 완료 기준 6) |

- **모양 확인은 실루엣으로 합니다.** 시안이 나오면 22px로 줄여 검은 실루엣만 남긴 판을 체험별로 나란히 놓고, 뜻이 다른 것끼리 헷갈리지 않는지 봅니다(§8 구분 표 기준).
- 그림 담당: 월드아트(추천, 대표 미확인). 이 문서의 아이콘 이름·뜻·크기·구분 방법을 시안 주문서로 씁니다.

### 3-3. 파일 형태 (월드개발과 맞출 것, 추천안)
- SVG 한 파일에 `<symbol id="ic-이름">`으로 모읍니다. 선은 `stroke="currentColor"`, 면은 `fill="var(--ic-point)"`로 그려 **색은 CSS 토큰만으로 바뀌게** 합니다(낮·노을·밤 자동).
- 이름은 이 문서 §7의 아이콘 이름(`c-sound` 등) 그대로 씁니다.

## 4. 색

### 4-1. 기본 두 색
- **선 = 잉크** `--ink`(기존). 낮 #4a3618 · 노을 #45301a · 밤 #f1e4c4 — 밤에는 밝은 잉크로 자동 바뀜.
- **면 = 포인트 색** `--ic-point`(새 토큰). 체험마다 다름(아래).
- 한 아이콘에 **최대 2색**(잉크 + 면)입니다. 단, 색이 곧 뜻인 경우만 고유색을 씁니다: 장식 공(빨강·노랑·파랑·하양), 연결 상태(초록·노랑·빨강), 당근(주황), 눈(하양).

### 4-2. 체험별 포인트 색 (추천안·대표 미확인)

| 체험 | 포인트 색 | 근거 | 밤 |
|---|---|---|---|
| 공통(허브·서버 고르기 등) | 도장 빨강 #b9472f | 기존 `--stamp`·`--accent` | #f3a48c(기존 밤 `--accent`) |
| 등산 | 숲 초록 #5f8f3e | 기존 `--go`(진행 막대) | #9cc27a(기존 밤 `--go`) |
| 흡연장 | 불씨 주황 #c8682f | **새 값**. 담뱃불·노을 옥상. 흡연장 토큰에 아직 없음 | #eb9a62(새 값) |
| 크리스마스 | 전나무 초록 #2f7a52 | 기존 크리스마스 `--pine` | #6fbf8f(새 값) |

- **공통 아이콘도 그 체험의 포인트 색으로 칠합니다.** 예: 소리 단추 그림은 흡연장에서 주황 면, 크리스마스에서 초록 면. 모양은 같고 색만 체험 분위기를 따릅니다. 페이지마다 `:root{--ic-point:…}` 한 줄로 정합니다.
- 크리스마스 보조색 금 `--gold #e9b949`(기존)은 별·반짝이에만 씁니다.
- 새 값 3개(흡연장 낮·밤, 크리스마스 밤)는 월드아트 확인이 필요합니다.

### 4-3. 상태 색 — 체험과 상관없이 고정
| 뜻 | 색 | 기존 토큰 |
|---|---|---|
| 됨·연결됨 | #5f8f3e | `--go` |
| 주의·다른 방 | #d39a2e | `--mid` |
| 안 됨·끊김·경고 | #c8553d | `--low` |
| 알림 점·숫자 배지 | #b9472f(크리스마스 #c23a32) | `--stamp` |
| 잠김·못 누름 | #9b8a72 | `--lock` |

- **색만으로 뜻을 나누지 않습니다.** 상태는 늘 모양(체크·느낌표·화살 고리·문)과 같이 바뀝니다. 색을 못 구분하는 사람도 읽을 수 있어야 합니다. (흡연장 포인트 주황과 주의 노랑이 가까운 것도 모양으로 구분됨)

## 6. 글 + 아이콘 단추 배치

1. **아이콘 앞, 글 뒤**(왼쪽 → 오른쪽). 세로 가운데 맞춤.
2. **이동·진행 화살은 글 뒤**: 「들어가기 ▶」, 외부 링크 「… ↗」. 지금 위치 그대로입니다.
3. **간격**: XS·S 아이콘과 글 사이 6px, M 이상 8px.
4. **한 단추에 아이콘 하나.** 「🎁 보내기」처럼 글 앞에 하나만. 문장 끝에 붙은 이모지(「같이 걸어요 🤝」, 「명중! ❄️」)는 끝에서 빼고 알림 줄 맨 앞 XS 아이콘 하나로 옮깁니다.
5. **세로로 쌓는 단추**(큰 도장·행동 큰 단추·탭 줄): 아이콘 위, 글 아래, 간격 4px.
6. **켜고 끄는 단추**는 아이콘과 글이 같이 바뀝니다(「소리 켜짐」 ↔ 「소리 꺼짐」 + 사선).
7. **숫자 칩**(🍫 5/5, 👥 12, 🎄 47/120): 아이콘 + 숫자, 간격 4px, 숫자는 폭이 같은 숫자 모양(`font-variant-numeric: tabular-nums`)으로 자리가 흔들리지 않게.
8. **반복 표시**(남은 눈덩이 ❄️×3): 아이콘을 개수만큼 반복해도 되고(최대 3), 빈 자리는 점선 테두리만 그립니다.
9. **아이콘만 있는 단추**에는 화면 읽기 이름(`aria-label`)을 꼭 붙이고, PC에서는 마우스를 올리면 같은 글이 뜨게 합니다(`title`). 아이콘만으로 둬도 되는 것: 설정·소리·채팅·사람 목록·닫기·좌우 화살·수첩 펼치기·고르기 칸(이름 글이 옆이나 아래에 보일 때). **처음 해 보는 행동 단추는 글을 같이 씁니다.**
10. 지금 글 속에 섞인 이모지(`'🎁 선물 보내기'`, `'📻 91.9'`)는 개발 단계에서 「아이콘 이름 + 글」로 나눕니다. 이미 `ic:`·`icon:` 칸으로 나뉜 표는 값만 아이콘 이름으로 바꿉니다.
11. CSS 글자(`content:'🔒'` 등)로 넣은 곳은 같은 자리에 아이콘 배경 그림이나 마스크로 바꿉니다(🔒 ☝ 👋 🙇 🤝 ⏳ 💪).
