# 변경 기록 — 인형뽑기 새 기계 ① 불빛 쌓기 「별빛 탑」 (2026-11-27, 월드공통개발)

- 지시: 대표 「새 기계 3종(불빛 쌓기·줄 자르기·공 구멍 넣기), 기계 한 종류씩 시험·검사를 통과하면 푸시·배포까지」(월드기획 전달). 공개 멀티 서버는 건드리지 않음.
- 근거: 규칙서 `docs/인형뽑기/새기계3종-규칙서-v1.md` §1, 시안 `docs/인형뽑기/새기계-불빛쌓기-시안-v1.html`(월드디자인, 추천안·대표 미확인). 숫자는 규칙서 제안값 그대로.

## 사용자에게 달라지는 점
- 가게 앞벽 문 왼쪽(빈 자리 A)에 새 기계 「별빛 탑」이 생김. ☰ 기계 탭에 「✨ 불빛 쌓기」 묶음, 바닥 번호판·간판은 ★.
- 한 판: 「✋ 멈춤」 판 하나. 빛 막대(3칸)가 좌우로 오가고, 누른 순간 자리에 멈춤. 아래 줄과 어긋난 칸은 빨갛게 떨어짐. 위로 갈수록 빨라짐.
- 7줄 = 다람쥐를 바로 받음(도감 등록) → 「▲ 계속하기 / 여기서 끝」 카드(20초면 끝). 계속해도 코인 0·다람쥐 안 잃음. 11줄 = 큰 눈송이도 받음.
- 결과 카드: 11줄 「꼭대기까지! 큰 눈송이」 / 「7줄에서 끝냈어요」 / 「다람쥐는 받았어요 · 9줄까지」 / 6줄 아까움 / 실패 「2줄에서 3칸 빨랐어요」 + 「직원 도움까지 n번」.
- 직원 도움: 경품 없이 5판 연달아 끝나면 다음 판부터 시작 칸 4칸(판 위 「직원 도움」 글·알림). 경품 없이 그만두기도 한 번으로 셈(규칙서).
- 10초 안 누르면 그 자리에서 저절로 멈춤. 👁 옆에서 보기·⏱ 없음.
- 소리: 칸 틱(줄이 오를수록 높게)·멈춤 「딱」·떨어짐 「뿅↓」·7줄 「띠링」·11줄 팡파르(합성).

## 바꾼 곳
- 목록 `claw-palette.js` `MACHINES` 맨 뒤 `stack-1`(act m 17, 기존 16대 번호 그대로), `prizes {small:'squirrel',big:'big-nunsong'}`(시안 예시 그대로 — 경품 배정은 월드아트·월드기획이 바꾸면 이 줄만).
- 규칙 `claw-rules.js` `CLAW_TUNING.stack`·`stackPos`·`stackStop`·`stackMissText`·`KINDS`·`KIND_INFO`·`PITY_NAME`·`pityOn`·`rulesFor`.
- 그림(1차, 월드공통개발) `claw-stack.js` `buildStackMachine`·`STACK`: 기존 몸통(bodyKit) + 7×11 불빛 판(캔버스 한 장, 칸 8cm, 상태가 바뀔 때만 다시 그림) + 판 오른쪽 경품 실물(7줄 작은·11줄 큰 인형). **월드아트 정식 그림이 오면 같은 userData(`kind`·`setBoard({rows,cur,falling,glow,pity,idle})`·`clearBoard`·`setButton('stop'|'off')`·`setLights`·`update`·`press`·`camera`·`spots.button/stand/door`)만 맞추면 연결 코드는 그대로.**
- 가게 `claw-shop-art.js` 자리(빈 자리 A → 별빛 탑, 빈 자리 B는 「준비 중」 그대로), 간판판 `claw-machine-art.js` 2048×1024 → 2048×1280(최대 20대, 번호 없는 기계는 ★·이름), 단계 그림 `claw-machine-lod.js` 「불빛 판」은 멀리서도 살아 있게.
- 진행 `claw-play.js`(누른 순간 판정·줄·7줄 고르기·결과·구경), 화면 `claw-hud.js/.css`(판 단추·위 칩·한 줄 안내·고르기 카드·결과 카드·그만두기 문구), 연결 `main.js`(7줄 작은 인형 바로 기록·결과 때 다시 안 적음·알림), 소리 `claw-audio.js`(step·snap·fall·ding).
- act 기계 번호 `multi-protocol.js` `ACT_SCHEMA.claw.m` 0~16 → 0~19(새 기계 3종 몫). 새 칸은 없음(v·cx·cz·ph·k·r 뜻만, 규칙서 §1).

## 확인
- 단위 시험 1,294개 통과(새 `tests/claw-stack.test.mjs` 10개: 조절값·막대 움직임·멈춤 판정·기계 자리·규칙 글·저장·그림·소리·화면·사람 손 모의).
- 사람 손 모의(규칙서 §4와 같은 모델, σ60ms·2만 판): **7줄 46.7% · 11줄 7.9%**(목표 추정 46%·7%).
- 브라우저 점검 `PART=stack node scripts/verify-claw.mjs`(휴대폰 세로·가로·PC): 규칙 카드 → 진짜 누름으로 1줄 → 7줄 고르기 카드 → 계속 → 11줄 큰 인형, 실패 카드 숫자, 7줄에서 끝(한 번만 기록), 직원 도움 4칸, 그만두기 보장 +1, 10초 저절로 멈춤, 단추 44px·안 겹침, 페이지 오류 0. 두 창 구경(`PART=multi`): B 화면 판에 A와 같은 쌓인 줄.
- 기존 점검 `PART=size,multi,keys,hub`(세로·PC)로 다른 기계 회귀 확인.

## 못 한 것·남은 것
- 실제 휴대폰 손맛(75ms 칸)·사람이 한 실제 성공률은 못 봄(모의만).
- **공개 멀티 서버를 다시 켜기 전에는 다른 손님에게 별빛 탑 구경이 안 보임**(옛 서버가 m 17을 버림, 혼자 뽑기·내 화면은 됨). 다시 켜기는 대표 확인 대기 — 작업량만 월드기획에 보고.
- 「7줄 계속하기 = 코인 0·안 잃음」·난이도·경품 배정은 추천안(대표 미확인).
