# 변경기록 2026-11-23 — 온라인 인형뽑기 MVP 기능 구현 (월드개발)

상위 업무: 온라인 인형뽑기 MVP(리더 월드기획) 4/4단계. 커밋·배포는 하지 않았습니다(대표 지시가 있을 때).
근거: 기획서(월드기획 MVP), 조사(월드리서치), 설계 v1 `docs/인형뽑기/화면-조작-설계-v1.md`·v2 `3d-손맛-설계-v2.md`(집게 = 물리, **대표 결정**)·v3 `기계3종-화면-규칙-설계-v3.md`(기계 3종), 그림 인계 `그림-에셋-인계-v1.md`(v1.1).
숫자(코인·허용 오차·빠르기·세기·보장)는 모두 **임시값(대표 결정 대기)** 이고 `src/claw/claw-rules.js` `CLAW_TUNING` 한곳에 있습니다.

## 1. 사용자에게 달라지는 점
- 허브에 다섯째 카드 「온라인 인형뽑기 · 동동이 인형가게」. PC 지도는 오른아래 자리, 「다음 체험 준비 중」은 아래 가운데 작은 팻말로.
- `/claw/` 3D 가게를 동동이로 걸어 다니다 기계 앞(2m 안)에서 「한 판」. ☰ 「기계」 탭 「가기」로 버튼만으로도 기계 앞까지 감.
- 기계 3종(설계 v3 추천안 짝):
  - 숲속 = **집게(물리)**: 십자 단추 누르고 있기(옆 단추로 밀면 방향 바뀜, 20초), 「👁 옆에서 보기」, 「뽑기」. 집게발이 실제로 인형을 조여 들어 올리고, 구멍에 떨어진 인형 = 성공 / 들었다 놓침 = 아까움 / 못 듦 = 실패.
  - 도시 = **타이머**: 「▶ 시작」 → 숫자 0.01초씩 → 「✋ 멈춤」. 손가락 닿은 순간 시각으로 재고, 화면에 멈춘 숫자가 10.00일 때만 성공(±0.10은 아까움).
  - 별빛 = **열쇠**: 큰 단추 누르고 있기 → 열쇠 오른쪽, 떼면 고정 → 다시 누르고 있기 → 위로, 떼면 꽂음. 구멍 맞으면 그 칸 인형이 나옴(희귀 칸은 구멍이 작음).
- 기계마다 첫 판 전 규칙 카드(코인은 「시작하기」를 눌러야 씀), 할 일 칩 「ⓘ 규칙」. 규칙 글은 조절값에서 만든다(보이는 규칙 = 판정 규칙).
- 무료 코인: 서울 0시마다 +10(최대 30), 한 판 1개. 사는 단추·바꾸는 곳 없음. 도감(8칸, 기계별 보기·자세히), 코인 탭(오늘 받음·다음 지급·최근 기록 5줄). 이 기기에 저장(`claw-world:v1`)·이어하기.
- 보장: 같은 기계 5번 연달아 실패 → 집게는 「힘센 집게」 한 판(꼭 성공은 아님), 열쇠는 구멍이 넓어짐(그림도), 타이머는 끔(설계 추천).
- 같은 가게 다른 손님: 걷는 모습·이름표, 기계 위 「○○ 뽑는 중」, 그 기계는 「기다리기」(동시에 못 씀), 집게 움직임·타이머 숫자·열쇠 자리·결과를 내 화면에서도 그림, 희귀 이상 성공 소식(10초에 1번, 내가 뽑는 중엔 안 띄움). 채팅·음소거·신고(공용).

## 3. 다르게 한 곳 / 개발 결정(대표 미확인)
- 조작 중에는 **내 화면에서만 내 동동이를 숨김**(다른 손님 화면에는 기계 앞에 서 있음). 카메라가 정면 위라 모자가 유리 상자 아래쪽을 가렸다.
- 집게 조작 카메라는 그림 추천값보다 낮춤(높으면 위 간판 상자가 레일 쪽 집게를 가림, 특히 세로 화면). 타이머·열쇠는 그림 추천값 그대로.
- 「👁 옆에서」는 설계의 작은 단추(52px) 대신 할 일 칩(44px) 자리: 360px 폭에서 십자 단추와 겹쳤다.
- 물리 인형 무게: 그림 크기대로 키우면 무게가 세제곱으로 늘어 성공률 0~20%였음 → 무게는 시안 크기 기준 × 희귀도(1·1.15·1.35·1.6). node 시험 위 인형 겨누기 약 25~40%(대부분 작은 까치), 설계값 세기 그대로.
- 서버는 **1서버만**(기존 정원 30): 서버 규모·비용 대표 미결정이라 늘리지 않음.
- 구경: 집게는 물리를 다시 돌리지 않고 뽑는 사람의 집게 자리·결과만 받아 정해진 움직임으로 다시 그림(설계 v2 §5 추천과 같은 방향, 결과가 나온 뒤 약 5초 늦게 보임). 같은 기계 동시 사용은 화면에서만 막음(서버 판정 없음 — 거의 같은 순간 두 사람이 누르면 둘 다 들어갈 수 있음, 각자 화면은 자기 판이 먼저).
- 허브 아이콘은 이모지 금지 규칙 때문에 있는 그림으로 임시. 게임 안 아이콘(🕹·🪙·⏱·🔑·👁)은 공통 대체 글자 방식(월드아트 아이콘 오면 저절로 바뀜).

## 4. 손님 인형(치이카와 자리) 공개판 분리 — 결함 고침
- 찾은 것: `claw-guest.js`의 `import.meta.glob`은 조건문 안에 있어도 빌드 때 펼쳐져, **설정을 끈 공개 빌드에도 비공개 폴더의 그림 파일이 dist에 나왔다**(가짜 시험 파일로 재현, 배포 검사는 잡아냄).
- 고침: `vite.config.js` `clawPrivateGuard` — `VITE_CLAW_PRIVATE=1`이 아니면 `private/claw/` 파일을 빈 모듈로 읽음. 고친 뒤 가짜 파일이 있어도 공개 빌드 깨끗(검사 통과), 설정 켠 빌드는 검사가 잡음. 배포 스크립트도 설정이 켜져 있으면 거부·빌드 뒤 검사.
- 개발용 확인: 가짜 손님 인형이 별빛 기계 칸·도감·결과 카드에 나오고 뽑힘. 시험 파일은 지웠음.
