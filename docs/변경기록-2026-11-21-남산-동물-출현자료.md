# 남산 동물 출현 구역·안전 범위 (2026-11-21)

상위 업무의 1/3단계 자료다. 구역은 기획 추천안이며 대표 미확인이다. 게임에 동물을 연결하거나 출현·반응·화면을 구현한 것은 아니다.

- 코스 거리 기준 출발 0~120m 고양이·까치, 120~650m 다람쥐·까치·멧토끼, 650~900m 고양이·까치, 900m~코스 끝 정상 접근로·광장 까치·고양이. 900m 이후 접근로도 빠지지 않도록 정상 구역에 포함한 추천안이다.
- 길 가장자리에서 1~5m. 그림의 성곽 선과 계단 측벽, 차로와 버스 순환선, 전망탑, 약수터·물확과 물길·돌탑, 자물쇠 난간 주변을 비운다. 높이는 `G.ground(x,z)`다.
- 시설 위치는 그림을 만든 뒤 확정되므로 고정된 좌표 대신 실제 그린 성곽 선과 시설 배치를 받아 판정한다. 지형이나 시설 배치가 달라지면 다시 만든다. 빠진 인자는 오류로 처리한다.

## 월드개발 연결 방법

1. `namsanAnimalZones(G)`로 코스 끝에 맞춘 구역을 받는다. 5분 칸·방 이름·최대 3마리와 동물 동작은 기존 공통 동물 로직을 연결한다. 대표 미확인 추천안을 확정 결정으로 표시하지 않는다.
2. 그림을 구성한 후 `createNamsanAnimalLanes(G,{wallLines:data.walls.map(w=>wallLine(G,w)).filter(Boolean),plan:ia.root.userData.plan})`을 한 번 부른다. 실제 사용한 벽과 실제 시설 계획이어야 한다.
3. `halfWidth(s)`, `laneLimit(s,side)`는 후보 범위다. 종별 최소 거리도 1m 이상, 최대 5m로 적용한다. 각 출현점과 배회 목적지는 `allows(s,v)`, 이동 전체는 `legAllows({s,v},{s,v})`로 검사한다. 표본만으로는 굽이나 시설 사이를 보장하지 못하므로 최종 검사를 생략하지 않는다. `toWorld(s,v)`가 `G.ground`를 적용한 `{x,y,z}`를 준다. 기존 종별 길 건너기 동작은 검사에 실패하면 안전한 자리에 머무르거나 새 목적지를 고른다.
4. **주의:** 관악산 `animal-zones.js`의 `zoneSpawns`, `wanderAt`은 현재 관악산 전용 `animal-lanes.js`를 직접 불러온다. 남산에 그대로 호출하지 말고, 남산 판정 함수를 주입할 수 있게 연결 담당이 공통 부품을 확장해야 한다. 관악산 기본값을 유지하고 양쪽 회귀 검사를 한다.
5. 본 자료는 실제 화면에 연결되지 않았다. PC·휴대폰에서 출현과 이동, 땅과의 접촉, 4종 반응, 멀티 공유 및 메모리를 후속 단계에서 직접 점검한다. 그려진 지형은 화면 품질에 따라 격자 보간을 쓰므로 `G.ground`와 화면의 실제 땅 높이 차이도 연결 시 확인한다.

검사: `tests/namsan-animal-lanes.test.mjs`는 실제 코스·성곽·버스·시설 배치로 구역, 안전 범위, 금지 대상, 지면 높이와 각 구역의 후보 존재를 확인한다. 시설 배치는 시험용 입력으로 계산했으며, 실제 게임의 조명·소품 배치 결과는 연결 시 전달한다.
