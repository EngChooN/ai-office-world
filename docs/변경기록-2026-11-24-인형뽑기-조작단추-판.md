## 1. 무엇이 바뀌나

| | 전 | 후 |
|---|---|---|
| 조작 중 진짜 단추 | 오른쪽 아래 76px 빨간 동그라미(기계 그림 단추와 똑같이 생김) | 화면 아래 가운데 **넓은 판** |
| PC(마우스 기기) | 「Space」 표시가 공통 틀에 가려 안 보임 | 520×84 판 + 왼쪽 「스페이스」 키캡 + 작은 설명(「방향키·WASD로 옮기고…」) |
| 휴대폰 세로 | 같은 동그라미 | 화면 폭 판(358×80). 집게는 왼쪽 십자 판이 있어 오른쪽 152×112 세로 판 |
| 휴대폰 가로 | 같은 동그라미 | 가운데 420×68 판(집게 300×68, 십자 판 오른쪽) |
| 기계 그림 속 단추를 누르면 | 아무 일 없음 | 알림 「기계 그림 단추는 장식이에요 · 아래 「멈춤」 판을 눌러요」(PC는 「… 단추나 Space를 눌러요」), 2.5초에 한 번 |
| 집게 남은 시간 | 단추 둘레 고리 | 판 바로 아래 막대(5초 남으면 빨강 깜빡) |

- 세 기계(집게·타이머·봉) 모두 같은 판. 열쇠 기계도 봉과 같은 판.
- 판 글: 집게 「뽑기」, 타이머 「시작」(초록)→「멈춤」, 봉 「오른쪽」→「안쪽」, 열쇠 「오른쪽」→「위로」. 작은 설명은 손가락 기기면 키·마우스 말을 빼고 씀.
- PC·휴대폰 구분은 화면 크기가 아니라 입력 방식(`(hover:hover) and (pointer:fine)` + 휴대폰 판정). 기존 kbd 규칙과 같은 조건.
- 걷는 동안의 달리기 단추, 기계 앞 「한 판」 단추는 그대로 오른쪽 아래 동그라미(공통 틀 그대로).

## 2. 기계 그림·숫자·인형을 가리지 않게

- 1440×900·휴대폰 세로는 판이 기계 아래 받침에만 걸려 그대로입니다.
- 1280×720·1920×1080(가로로 긴 PC)·휴대폰 가로는 기계가 화면 아래까지 차서 판이 그림 단추·인형을 가렸습니다. 그래서 **판이 가릴 때만** 게임 그림을 판 높이만큼 위로 올리고 그만큼 넓게 봅니다(`main.js` `barReserve` → 카메라 `setViewOffset` + 시야각). 기계·옆보기·화면 크기마다 한 번 계산, 결과 카드 동안은 그 값을 유지해 카메라가 튀지 않습니다.
- 확인 기준(점검 스크립트): 판(테두리 7px 포함)이 기계 그림 단추·타이머 숫자판·보이는 인형(집게 더미 칸마다, 타이머 큰 인형, 봉 상자) 어느 것과도 겹치지 않음.
