## 2. 콘텐츠별 자리

| | 흡연장 | 등산 | 크리스마스 |
|---|---|---|---|
| 상태 알약 | 👥 칩(`multi-ui.js`)이 「옥상 1서버 · 👥 2」 | 진행 알약(어디쯤 · 고도 + 스테미너 막대, 누르면 예전 진행 카드) · 시점 칩 늘 보임 · 둘째 줄 함께 걷기 칩·👥 | 장소·사람 칩 + 트리 수(「1서버 · 👥 2/30 · 🎄 0/120」) |
| 위 오른쪽 | 💬 · ☰ | 💬 · ☰ | 🗺 지도 · 💬 · ☰ |
| 큰 단추 | 꺼내기 → 불 → 꾹 들이마시기 / 꽁초 버리기, 맛 고를 때는 고른 맛 | 도장(걷기·멈추기·읽기…) | 그 자리 놀이 첫 단추(던지기 등), 없으면 달리기 |
| 작은 단추 | 서 있을 때 인사·재떨이로 / 피우는 중 재 털기·묘기·버리기 / 캔·일어나기 | 달리기·쌍안경·카메라 | 나머지 놀이 단추 + 달리기 |
| 할 일 칩 | 닿을 거리 대상(벤치·난간·자판기)·불 빌리기·받기·대답 칩 | 간식 먹기 n/5 · 들르기 | 한 판 하기 · 눈덩이 수 |
| ☰ 탭 | 상황 · 금연 수첩 · 옷 · 소리 · 설정 | 지도 · 수첩 · 배낭 · 쉬기 · 설정 (+ 시각·소리·라디오 빠른 줄) | 우체통 · 옷 · 캐럴 · 소리 · 설정(광장 사람·서버) |

- 흡연장: 수첩 카드·소리·설정·「상황」·⋯ 단추와 예전 채팅 상자를 없앰. 한숨·기지개(+인사)는 말하기 줄 칩. 도장(한 대 다 피움)은 가운데 카드 7초.
- 등산: 아래 탭 줄·꼬리표(시각·소리·라디오) 숨김 → ☰. 앉기·차 마시기는 「쉬기」 탭. 지도는 지도 창 대신 「지도」 탭(M 키도), 스탬프 수첩은 「수첩」 탭(J 키·완등 뒤에도 탭이 따라 열림).
- 크리스마스: 오른쪽 둥근 단추 4개(📬·🔊·🎵·👕) 숨김 → ☰. 지도 창은 메뉴와 같은 자리(세로 아래·가로 오른쪽). 선물·눈사람 꾸미기 창도 창 하나 규칙에 듦.

## 3. 시안과 다르게 한 것(이유)

1. **빠른 말 칩 높이 44px**(시안 32px): 이 저장소 규칙 「단추 44px 이상」과 기존 검사(`capture-hiking-chat`)를 따름.
2. **등산 위 왼쪽 둘째 줄**(함께 걷기 연결 칩·👥 동행 목록): 시안에 자리가 없었으나 없애면 서버 바꾸기·같이 등산하기 목록을 열 길이 없어짐. 알약 아래 작은 줄로 둠(세로 「막힘없는 화면」이 시안보다 낮은 주 이유).
3. **흡연장 맛 고를 때** 큰 단추 = 고른 맛, 작은 단추 = 다른 맛 3개 + 그만(시안에 없는 단계).
4. **크리스마스 「설정」 탭** = 광장 사람·서버 고르기(크리스마스에는 따로 설정 창이 없었음). 위 알약을 눌러도 이 탭이 열림.
5. 이모트 한숨·기지개는 말하기 줄 칩(작은 단추 3개를 넘지 않게).
