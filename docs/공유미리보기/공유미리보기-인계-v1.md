| 파일 | 규격 |

- 짜임: 왼쪽 두 줄 제목(작은 「온라인」 72px + 큰 낱말 136~190px, 크림색 글자 + 굵은 테두리), 그 아래 칩 2~3개, 한 줄 문구. 오른쪽에 손 흔드는 동동이(등산복·회사원 옷·산타 옷), 배경은 각 페이지 theme-color(허브·등산 `#173f36`, 흡연장 `#2a2f45`, 크리스마스 `#1d2a4a`).
- 안전 영역: 위아래 30px·좌우 60px 안에 글자와 동동이(시안에서 「안전 영역 보기」).
- 동동이는 지금 허브 임시 평면 그림입니다. 정식 2D 동동이가 있으면 그것으로 바꿔 그립니다.
- 120px 폭에서도 큰 낱말이 읽히는지 확인합니다(시안 ④).

## 3. 월드개발 — 태그 넣기 (4개 HTML `<head>`)

```html
<meta name="description" content="…">
<link rel="canonical" href="https://engchoon.github.io/ai-office-world/hiking/">
<meta property="og:type" content="website">
<meta property="og:site_name" content="온라인 메타버스">
<meta property="og:locale" content="ko_KR">
<meta property="og:url" content="https://engchoon.github.io/ai-office-world/hiking/">
<meta property="og:title" content="…">
<meta property="og:description" content="…">
<meta property="og:image" content="https://engchoon.github.io/ai-office-world/og/og-hiking.png">
<meta property="og:image:type" content="image/png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="…">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="…">
<meta name="twitter:description" content="…">
<meta name="twitter:image" content="https://engchoon.github.io/ai-office-world/og/og-hiking.png">
<meta name="twitter:image:alt" content="…">
<link rel="apple-touch-icon" sizes="180x180" href="/og/icon-hiking-180.png">
<link rel="icon" href="/og/favicon-hiking.svg" type="image/svg+xml">
```

- **`meta content` 주소는 반드시 `https://engchoon.github.io/ai-office-world/…` 전체 주소.** Vite는 `<link href>`만 base(`/ai-office-world/`)를 붙여 주고 `<meta content>`는 안 바꿉니다. 상대 주소면 카카오·X가 그림을 못 가져옵니다.
- og:url·canonical은 끝 `/`까지 정확히. 주소 옵션(`?multi=` 등)은 넣지 않습니다.
- 흡연장·크리스마스 HTML은 `<head>`에 로딩 화면 스타일이 길게 있으니 `<title>` 바로 아래에 붙입니다.
- 검사 제안: `tests/`에 4페이지 모두 위 태그가 있고 이미지 주소가 `https://`로 시작하는지 보는 단위 테스트 하나.
- 배포 뒤 확인: 카카오 공유 디버거(developers.kakao.com → 도구 → 공유 디버거)에서 4주소 「캐시 초기화」 후 미리보기. 카카오는 한 번 긁은 그림을 오래 기억합니다.

## 4. 확인한 것 / 못 한 것

- 확인: 시안을 브라우저로 그려 1200×630·400·240·120px 캡처를 봤고, 글자·동동이가 안전 영역 안이며 120px에서도 큰 제목이 읽힘.
- 못 함: 실제 카카오톡·아이폰 메시지에서의 모양(배포 전이라 불가). 카톡 모의 화면은 비슷하게 그린 것.
- 알려진 한계: 썸네일을 정사각으로 가운데만 자르는 앱에서는 동동이가 아니라 제목 가운데가 보입니다. 큰 카드로 보여 주는 카톡·아이폰 메시지를 우선한 짜임입니다.
